## New tests

`tests/unit/test_slicer_strategies_mutation_gaps.py` (11 tests):

1. `test_page_empty_strip_with_no_files_has_no_fallback` — kills #2: a 0-row strip must take the page path (empty artifact, no `"fallback"` param), not fall back to smart.
2. `test_fixed_tail_exactly_min_height_is_not_merged` — kills #6: a tail of exactly `min_height` rows stays its own slice (H=7500 → 3 slices).
3. `test_gutter_variance_threshold_is_strict` — kills #11: rows with variance exactly at `gutter_variance` are not gutters (100/104 rows at threshold 4.0; float-exactness verified: `torch.var` yields exactly 4.0).
4. `test_gutter_run_centre_is_floored` — kills #12: an odd-length run (9 rows) cuts at `(s+e)//2`, not ceil.
5. `test_gutter_min_rows_boundary` — kills #13 and #14: a 7-row run is below the 8-row threshold, an 8-row run is exactly at it.
6. `test_simple_gutter_strip_exactly_max_height_is_one_slice` — H == `max_height` is one uncut slice (pin; mutant #16 was already killed by the 60k test).
7. `test_simple_gutter_cut_exactly_at_window_max_is_used` — kills #17: a gutter centred exactly on the window's `hi` is a candidate.
8. `test_simple_gutter_picks_the_cut_closest_to_target` — kills #20: with candidates at `pos+1500` and `pos+4000` (target `pos+3000`), the cut closest to *target* wins, not to `pos`.
9. `test_slice_with_one_uneven_row_is_not_blank` — kills #22: one non-uniform row (alternating 0/255) makes a slice non-blank even if 2999 rows are uniform.
10. `test_source_file_starting_exactly_at_slice_start_is_excluded` — a file whose `y0` equals a slice's `y1` maps only to later slices (pin; mutant #24 was already killed by the page test).
11. `test_finalize_records_the_strip_dimensions` — kills #25: `strip_width`/`strip_height` must reflect the strip (W=720, H=2000).
12. `test_source_file_ending_exactly_at_slice_start_is_excluded` — round 2; a file whose `y1` equals a slice's `y0` maps only to later slices (`target_height=2000` puts a cut on the page boundary). The existing page test already kills that mutant; this pins it on `fixed`.
13. `test_blank_flag_uses_the_configured_tolerance` — round 2, kills #38: one pixel 11 above the row median makes a slice non-blank at `uniform_tol=10` (and uniform at 11).

Appended to `tests/unit/test_slicer_compare.py`: `test_summarize_median_height_is_an_int` — kills #30 (median of an even count is a float; the summary keeps it an int).

## Equivalent mutants

None among the 43. (Considered and rejected as equivalent before writing: `strict=True` → `strict=False` in the
`zip(starts, ends)` of `gutter_cut_rows` — the +1/−1 change array always produces matched counts; dropping the `c`
tie-break in `min(candidates, key=…)` — `cut_rows` is ascending, so `min` already picks the smallest on a tie;
`(y0, height, forced)` → `(y0, height, True)` in the fixed-tail merge — `boundaries[-2]` is always a forced cut
there; flipping the ±1 change array in `gutter_cut_rows` (`padded[1:] − padded[:-1]` → `padded[:-1] − padded[1:]`)
— starts and ends swap exactly, so every run centre is unchanged.)
