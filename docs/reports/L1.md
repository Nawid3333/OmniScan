## Deviations

1. **The card's style references are gone.** `src/omniscan/acquire/download.py`,
   `acquire/extractpics.py` and `tests/unit/test_acquire_extractpics.py` no longer exist (the
   acquisition subsystem was removed by card RM1; see PRODUCT_SPEC §8's superseded note). I imitated
   the same patterns from `src/omniscan/update/download.py` (injected `httpx.Client`, streaming
   `.part` + `os.replace`, non-raising error mapping) and `update`'s CLI client factory. Everything
   else in the card (fixtures, §7 decision, interfaces) was followed as written.
2. **`.gitignore` `library/` → `/library/`** (one line). The unanchored rule meant for the user's
   library data root also swallowed the new `src/omniscan/library/` package, so the card's files
   could not even be committed (the U2a comment above that rule already states such data-root
   patterns are anchored; `models/` was fixed the same way in U2a). `work/`, `output/`, `samples/`
   stay unanchored — no current collision, but they would bite a future `omniscan/work` package.
3. **`match_score` prefix bound 1.6 → 1.75.** The card's own acceptance test pins
   `"Solo Leveling"` vs `"Solo Leveling: Ragnarok"` at ≥ 0.85, but after normalisation that pair is
   20 vs 12 chars (1.67×) — a 1.6× bound gives 19.2, so the rule would never fire for the card's
   pinned example and the SequenceMatcher ratio alone is 0.75. 1.75 keeps the intent (a subtitle is
   close; an unrelated long title is not) and satisfies the pinned test. Pinned in
   `test_match_score_prefix_rule` as `[0.85, 1.0)`.
4. **`cover_source` of a downloaded cover is the provider key** (`anilist`/`mangadex`/`jikan`),
   matching the lowercase `user` value the card prescribes for user covers; the `credit` string
   carries the human-readable attribution (`MyAnimeList (via Jikan)` for Jikan).
5. **`--size small` derives the small URL** from the stored large `cover_url` (the `Candidate`
   interface carries only one URL): AniList `/cover/large/` → `/cover/medium/`, MangaDex
   `.512.jpg` → `.256.jpg`, MyAnimeList `<base>l.jpg` → `<base>t.jpg`.
6. **MangaDex `titles`** = the display-title chain (en-of-`title`, en-of-`altTitles`, first `title`
   value, first alt title) plus every `altTitles` value, stripped, de-duplicated, order kept — the
   card's "all of those plus every altTitles value" taken literally.
