# C3 — Detection stage: RT-DETR wrapper, VRAM group, `DetectStage`, `omniscan detect`

## Changes
- `src/omniscan/detect/model.py` — `RawDet`, `Detector` (load + `detect`): tiles (uint8 `[3,h,w]`) → GPU resize (bilinear, antialias) → /255 (no mean/std) → RT-DETR-v2 forward → HF `post_process_object_detection` for the scaling back to tile pixels →
  `RawDet` lists (unknown labels dropped, boxes clipped, highest score first). `load` calls `torch.cuda.set_device(device)` first (MIOpen launches kernels on the *current* device, which is the iGPU on this PC).
- `src/omniscan/gpu/groups.py` — `VISION_GROUP`, `build_vram_manager(cfg)` (lazy `Detector` import so `omniscan --help` stays light).
- `src/omniscan/detect/stage.py` — `DetectStage` (tiles overlapping non-blank, non-filtered slices only; batches of `detect.batch_size`; merge; regions; `regions.json`).
- `src/omniscan/cli.py` — real `detect` command; `_run_stages` builds a VRAM manager only when a stage has a `gpu_group` and releases it in `finally`.
- Tests: `test_detect_tiles.py`, `test_detect_postprocess.py`, `test_detect_model.py`, `test_detect_stage.py`, `test_gpu_groups.py`, an invalidation test in `test_stages_ingest_slice.py`, CLI/doc updates; README + USER_GUIDE.
- `scripts/probe_detector.py` uses `resolve_device()` instead of `cuda:0`.

## Tests
Full suite in the worktree: 2000 passed (incl. the `gpu` tests); ruff and pyright clean. GPU: preprocessing equivalence vs the HF image processor (mean abs diff 0.0001); fp32 batch of 8: 64.5 tiles/s.

## Deviations
- **fp32 instead of fp16 (director decision).** The card said `.half()` on CUDA. The builder found that RT-DETR fp16 fails with `miopenStatusUnknownError` at batch sizes 1–3 (only batch 8 works, 142.7 tiles/s vs 64.6 fp32). All vision models now run in fp32
  (`docs/DECISIONS.md`); the GPU test calls `detect` with 1, 2, 3 and 8 tiles as the regression test.
- The builder ran out of its turn budget after the final checks; the director removed its scratch files (`tmp_probe/`, `pytest*.txt`, `pyright*.txt`), wrote this report and committed.
