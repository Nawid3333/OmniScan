# X2 — Scan artefacts for the synthetic Korean pages

## Changes

- `tests/fixtures/scan_artifacts.py` (new): one deterministic `degrade(image, seed, *, blur_px=0.6,
  noise_sigma=4.0, halftone=False, rotate_deg=0.0, jpeg_quality=60) -> Image.Image` that returns an
  RGB image of the same size, never touching the input. Steps always run in the card's order:
  1. `convert("RGB")`; 2. `GaussianBlur(blur_px)` when `blur_px > 0`; 3. per-channel Gaussian noise
  from `np.random.Generator(np.random.PCG64(seed))`, σ=`noise_sigma`, rounded and clipped to
  `uint8`; 4. halftone dot screen — every pixel multiplied by `1 - 0.08 * d(x, y)` with
  `d = 0.5 + 0.5 * sin(2πx/6) * sin(2πy/6)`, fully vectorised (no Python loops), rounded and
  clipped; 5. `Image.rotate(rotate_deg, BICUBIC, expand=False, fillcolor=(255, 255, 255))` when
  `rotate_deg != 0`; 6. JPEG round trip through `io.BytesIO` at `jpeg_quality`.
  Validation before any work: `jpeg_quality` outside 1..100, negative `blur_px` or `noise_sigma`
  → `ValueError`. Pure function of its arguments (same call → identical pixels; the RNG is only
  drawn when `noise_sigma > 0`, so turning it off cannot shift the other steps).
- `scripts/make_korean_chapter.py` (modified): new optional flags `--scan-artifacts` (applies
  `degrade` to every page before it is written; help text notes `--truth-out` still describes the
  clean page and rotation makes it approximate), `--jpeg-quality INT` (default 60), `--noise FLOAT`
  (default 4.0), `--blur FLOAT` (default 0.6), `--halftone` (flag), `--rotate FLOAT` (default 0.0).
  Page *i* uses degradation seed `args.seed + i`. Without the flag the other options are ignored
  and the write path is the identical quality-92 save call as before, so today's output stays
  byte-identical. `write_page` now takes the `Image.Image` to save (was a `KoreanPage`) so the
  degraded image goes through the same save call; `--truth-out` is untouched and still built from
  the clean page.
- `tests/unit/test_scan_artifacts.py` (new): 17 CPU-only tests covering all 8 acceptance-test
  groups on the card (size/mode/determinism/seed/jpeg-only baseline, noise σ level on a flat patch,
  JPEG quality ordering on a checkerboard-over-gradient, blur softening a 1-px line, halftone
  statistics on/off, rotation at 0°/5°/10° incl. white corner fill, ValueError validation, and the
  generator end-to-end via `subprocess`: byte-identical to the documented recipe without the flag,
  different + valid 800×1400 JPEG with it, deterministic across runs, extra options wire through).
- `docs/USER_GUIDE.md` untouched: `make_korean_chapter.py` is not documented there
  (`tests/unit/test_docs.py` green unchanged).

## Deviations

- Rounding/clipping to `uint8` only runs when noise or halftone is active. Blur, rotation and the
  JPEG codec already emit `uint8`, so the no-noise paths skip a pointless float round trip (and the
  blur-only path stays bit-exact through it).
- `write_page`'s signature changed from `KoreanPage` to `Image.Image` (script-internal helper, not
  used by any test or other module). Required so the degraded image is written by the same
  quality-92 save call that guarantees byte-identical output without the flag.
- Test 1's jpeg-only baseline uses a vertical gradient image (worst case for 8×8 DCT blocking),
  which is a stricter check than the card's minimum.

## Questions

- None blocking. One note for the later card that uses these artefacts in the golden test: the
  halftone screen is axis-aligned (0° screen angle), so moiré against the JPEG grid is milder than
  on real prints — thresholds tuned on it stay slightly optimistic.
