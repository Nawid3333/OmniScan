# X1 — Synthetic Korean pages with exact ground truth

## Changes

- `tests/fixtures/korean_pages.py` (new): deterministic generator for synthetic Korean webtoon pages.
  - `FONTS_DIR`, `KOREAN_LINES` (the 12-sentence corpus), `SFX_LINES`, `font_path()`.
  - `LineTruth`, `RegionTruth`, `KoreanPage` dataclasses exactly as specified on the card.
  - `make_korean_page(seed, *, width, height, n_bubbles, n_free, n_sfx, font, background)`: one
    `numpy.random.Generator(PCG64(seed))` drives everything; PIL renders all ink. Backgrounds:
    `flat`, `gradient` (two RNG colours + Gaussian noise σ=6) and `noise` (8×8 random blocks).
    Bubbles are ellipses or rounded rectangles, white 80 % / dark 20 %, 3 px outline, with sampled
    outline polygons (48 points for ellipses, 16 for rounded rects — clockwise, all inside the box).
  - Layout: equal vertical row slots (≥ 40 px to every page edge and between neighbours); a row holds
    one region or two side by side (RNG; pairs only for bubbles/free text; SFX always alone, in the
    bottom rows); reading order is row-major, so the region tuple is in reading order by construction.
  - Line breaking is greedy at spaces against 0.72 × bubble width (ellipses) / 0.85 × (rounded) /
    0.9 × slot width (free text); ellipses whose interior cannot hold the text fall back to a rounded
    rectangle (an ellipse is geometrically impossible there, e.g. a narrow paired bubble with two
    lines). Bubble widths/positions are RNG-jittered inside their slots; vertical jitter is bounded
    so same-row boxes keep ≥ 60 % vertical overlap (keeps the reading-order invariant stable).
  - Truth boxes come from rendering each line alone on a full-page transparent layer (same font,
    position, fill, stroke as the page), thresholding alpha and taking the bbox — `text_mask` is the
    pixel difference of `image` vs `clean`, and `clean` is the page right after bubbles are drawn.
  - `to_regions_artifact(page)`: `RegionsArtifact` with ids `r0001…`, `lang="ko"`, `engine="truth"`,
    `score=1.0`, `confidence=1.0`, per-line `OcrLine`s, bubble polygons and text colours.
- `scripts/make_korean_chapter.py` (new): writes `001.jpg …` (quality 92) into
  `<library_root>/<series>/<chapter>/` (defaults `KoreanDemo` / `Chapter 1`, 3 pages, seed 7; page
  *i* = `make_korean_page(seed + i, n_bubbles=4, n_free=1, n_sfx=1 if i % 2 else 0)`), prints one
  line per page plus a next-step hint, and writes a list of `RegionsArtifact` JSON objects to
  `--truth-out PATH` only when given. Adds the repo root to `sys.path` so it also runs as a plain
  subprocess (`python scripts/make_korean_chapter.py`).
- `tests/unit/test_korean_pages.py` (new): 73 tests covering all 11 acceptance-test groups on the
  card (determinism, mask/clean consistency, geometry invariants over 12 seeds × 3 backgrounds,
  reading order, counts/kinds/ValueError, text content, bubble fit and colours, font checks
  incl. `.notdef` vs `가` and `FileNotFoundError`, artifact round-trip, script run via `subprocess`
  into a tmp library root, and the `IngestStage` pipeline smoke test with strip size 800×4200).

## Deviations

- `_slots` rejects impossible layouts up front (`ValueError` naming the region count, page size and
  the rows needed/available). The card only demands this for over-full requests; the check also
  fires for e.g. `n_bubbles=30` because ~15 equal rows would leave less height than the smallest
  possible bubble.
- When an ellipse cannot contain its text with the required margin (narrow paired column + a long
  sentence broken into 2–3 lines), that bubble silently falls back to a rounded rectangle. The RNG
  still chose the shape; the fallback only fires when the ellipse is geometrically impossible.
- Font size starts at the RNG value in 26–34 and may shrink toward 26 for fit (still inside the
  documented range). Same for SFX (90–130, shrink toward 90).
- `SFX_LINES` is a public constant on the module (the card defines the SFX tuple inline in prose).
- `scripts/make_korean_chapter.py` inserts the repo root into `sys.path` (with `# noqa: E402`)
  because `tests.fixtures` is not an installed package; without it the card's subprocess invocation
  could not import the generator.

## Questions

- None blocking. One observation for the next cards: bubble `polygon` samples the *outline* of the
  shape, so typesetters should inset by the outline width if they need a strictly interior box.
