# B24 — ingest + slice stages and CLI

## Changes

- `src/omniscan/gpu/codec/select.py` (new): `get_codec(cfg)` — `auto`/`turbo` return
  `TurboCodec(cfg.gpu.device)`; `rocjpeg`/`hybrid` raise `CodecUnavailableError` (card C2 adds them).
- `src/omniscan/ingest/strip.py` (new): `jpeg_paths(ingest, raw_dir, cache_dir)` maps every
  `SourceFile` to the JPEG to decode (original when `converted_from is None`, else the documented
  `cache_dir/{index:04d}_{stem}.jpg` name); `build_strip(ingest, paths, codec)` allocates the
  `[3, strip_height, strip_width]` uint8 tensor on `codec.device`, batch-decodes all full-width pages
  in one `decode_into` call, and bilinear-resizes (antialias) each off-width page into its rows.
- `src/omniscan/ingest/stage.py` (new): `IngestStage` (`name="ingest"`, `version=1`, `gpu_group=None`)
  wrapping `ingest_chapter` into `work_dir/converted` + `ingest.json`; metrics
  `files`/`converted`/`strip_height`.
- `src/omniscan/slicer/stage.py` (new): `SliceStage` (`name="slice"`, `gpu_group=None`) loading
  `ingest.json`, building the strip once via `ctx.lazy("strip", ...)` (so later stages in the same
  chapter pass can reuse it), slicing with `cfg.slicer`, saving `slices.json`; the codec is closed in
  a `finally` block. Metrics `slices`/`blank`/`forced`/`bands`/`strip_height`.
- `src/omniscan/cli.py`: replaced the `ingest`/`slice` stubs with real commands (repeatable
  `--chapter/-c`, `--force`), removed both names from `_STUB_COMMANDS`, and registered them with
  `app.command(...)`. Shared printing/exit logic lives in a new private helper `_run_stages` (same
  style as `_stub`/`_chapter_paths`); torch-dependent imports (`IngestStage`, `SliceStage`,
  `run_series`) are function-level so `omniscan --help` stays light.
- `tests/unit/test_stages_ingest_slice.py` (new): the 11 acceptance tests, all CPU
  (`GpuConfig(device="cpu")`, tmp-path `PathsConfig`).

The 3 warnings are pre-existing (`fastapi`/`starlette` deprecations and a non-writable-numpy
`UserWarning` from `turbo.py`), none from this card's code.

## Deviations

- `build_strip` is split into two small private helpers (`_decode_full_width`, `_resize_off_width`)
  plus `_resize`; behaviour and the public signature are exactly as specified.
- `cmd_ingest`/`cmd_slice` share one private helper `_run_stages` instead of duplicating the
  chapter-discovery/print/exit logic; no other command was touched.
- `SliceStage.run` calls `slices.save(...)` after the `try/finally` that closes the codec (the
  card puts save in step 3 and the close in a `finally`; both orderings are equivalent here).
- A CLI smoke test against the installed binary with env-var config was blocked by the session
  sandbox; the CliRunner test (acceptance #11) covers the same code path in-process. A leftover
  untracked `.tmp_b24_demo/` directory in the worktree root (two synthetic solid-colour JPEGs) can
  be deleted — `rm -rf` was denied for this session.
