# B3 — Ingest: discover chapter files, normalise to JPEG, compute strip layout

## Changes
- `src/omniscan/ingest/convert.py` (new): `ConvertedImage` dataclass, `needs_conversion(path)`, `convert_to_jpeg(src, cache_dir, index, quality)`. Header-only probing (`Image.open` without `.load()`); `needs_conversion` flags non-`.jpg/.jpeg` suffixes, any non-RGB mode (covers alpha `RGBA/LA/PA` + `P`-with-transparency, `CMYK`, grayscale `L`) or an EXIF Orientation tag ≠ 1. Conversion: `ImageOps.exif_transpose`, alpha composited over opaque white RGB, CMYK/other modes `convert("RGB")`, saved as `cache_dir/{index:04d}_{stem}.jpg` with `quality=95, subsampling=0 (4:4:4), optimize=True`, no EXIF in output. Always writes on re-run (idempotent/resumable per card: newer source data must win).
- `src/omniscan/ingest/layout.py` (new): `dominant_width` (Counter, tie → larger width, `ValueError` on empty) and `stack_layout` (cumulative `y0/y1`, scaled height `round()` with minimum 1).
- `src/omniscan/ingest/__init__.py` (new): `IngestResult` + `ingest_chapter` wiring `list_images` → `convert_to_jpeg` → `dominant_width` → `stack_layout` → `SourceFile`s → `IngestArtifact`; re-exports the convert/layout API.
- `tests/fixtures/images.py` (new) + `tests/fixtures/__init__.py`, `tests/__init__.py` (new, needed so `from tests.fixtures import ...` resolves under pytest's default import mode): synthetic `plain_jpeg`, `rotated_jpeg` (pixels stored at swapped dims + EXIF Orientation 6, so `exif_transpose` yields the logical size), `png_with_alpha` (gradient alpha, first 8 columns fully transparent so a whole JPEG block stays exactly white after compositing), `cmyk_jpeg`, `grayscale_jpeg`, `webp_image`.
- `tests/unit/test_ingest_convert.py`, `tests/unit/test_ingest_layout.py`, `tests/unit/test_ingest.py` (new): the 15 acceptance cases from the card, plus a contiguity check on `stack_layout`.

## Deviations
- None functionally. One implementation note: `needs_conversion` treats "mode != RGB" as the conversion trigger for non-suffix reasons (alpha modes, `CMYK`, and grayscale `L` are all covered by it), matching the card's plain-baseline-RGB-JPEG definition, which is stricter than the enumerated examples in the docstring bullet.
- `exif_transpose` is guarded against returning `None` (no-op) — Pillow ≥ 9.4 semantics, handled defensively.
- `tests/__init__.py` was created (card permitted it if missing) because pytest's default import mode needs the package root for `from tests.fixtures import ...`.

## Questions
- None blocking. For a later card: `convert_to_jpeg` writes only baseline JPEGs; if a source ever needs >4 GB of EXIF-heavy WebP/AVIF, the same helper is reusable, but the caller decides the cache dir lifetime (currently the caller owns `cache_dir` cleanup).
