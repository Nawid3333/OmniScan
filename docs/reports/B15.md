# B15 — Watermark fixed-position mask per series

## Changes
- `src/omniscan/watermark/__init__.py` (new): package docstring.
- `src/omniscan/watermark/store.py` (new): `WatermarkRegion` (pydantic v2, `extra="forbid"`) and
  `WatermarkStore` — CRUD over `<series work dir>/watermarks.json`. `list()` returns `[]` for a missing
  file/dir and creates nothing; `add()` validates the fractions (ValueError naming the violated bound),
  assigns `max(existing) + 1`, and persists atomically (tmp + `Path.replace`, the
  `core.schemas.Artifact.save` pattern); `remove()` raises `KeyError(index)` for unknown indices and never
  renumbers.
- `src/omniscan/watermark/resolve.py` (new): `resolve_watermark_regions` — outer loop over regions, inner
  over `ingest.files`; x scaled by `source_file.scale`, y interpolated across the file's own `[y0, y1)`
  span; degenerate results (x1<=x0 or y1<=y0 after `round`) are silently omitted; no mutation of inputs.
- `src/omniscan/cli.py` (modified): new `watermark` sub-app (`add`, `list`, `remove`) mounted via
  `app.add_typer(watermark_app, name="watermark")`. `add` takes the four fractions as required options with
  click range validation (min=0.0, max=1.0) plus `--note`; ValueError → `watermark: <msg>` on stderr, exit 2.
  `list` renders a rich table (index, x0-x1, y0-y1 at 3 decimals, note). `remove` maps `KeyError` →
  `watermark: no region <index> for <series>` on stderr, exit 2. No existing commands touched.
- `tests/unit/test_watermark_store.py` (new), `tests/unit/test_watermark_resolve.py` (new): the 15
  acceptance tests from the card.

`add` (success message, index assigned), `list` (table renders fractions at 3 decimals + note),
`add` with x0==x1 → `watermark: x0_frac 0.5 must be < x1_frac 0.5`, exit 2; `add --x1 1.5` → click range
