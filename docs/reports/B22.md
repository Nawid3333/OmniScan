  - `names.py` — `safe_filename` (forbidden ASCII punctuation + control chars → `_`, strip spaces/dots, empty → `_`).

## Deviations
1. **`fmt` parameter type: `list[PackFormat]` (str-Enum) instead of `list[Literal["cbz", "pdf"]]`.** The card's
   exact annotation cannot be registered by the pinned typer: `list[Literal[...]]` hits typer's
   `"List types with complex sub-types are not currently supported"` assertion at `app.command("pack")(cmd_pack)`
   registration time (typer 0.27.2), which crashes the *whole CLI at import* (existing tests fail too).
   `list[StrEnum]` is typer's supported equivalent and preserves the specified behaviour exactly: repeatable
   `--format/-f`, help text `cbz or pdf; repeatable. Default: cbz.`, `<cbz|pdf>` choices, default `cbz`,
   order-preserving de-duplication. See Questions.
