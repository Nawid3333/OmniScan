# B9 — Glossary store (SQLite + YAML, alias/particle matcher)

## Goal
A per-series glossary store: SQLite for the working copy (`series.db`, alongside where reference-mode and story
memory will later live), YAML for the human-editable review/export file (`glossary.yaml`), and a matcher that
finds glossary terms inside Korean source text even when a Korean particle (조사) is attached directly to the
term with no space (e.g. `지훈이` = `지훈` + `이`, `학교에서` = `학교` + `에서`). This is what later lets the
post-check step (card C5) verify a locked term's translation actually appears in the output, and what lets the
translation prompt builder pull only the glossary subset relevant to a chapter.

`src/omniscan/glossary/store.py`:
```python
class GlossaryStore:
    def __init__(self, db_path: Path) -> None: ...
    # Opens sqlite3.connect(db_path), PRAGMA journal_mode=WAL, PRAGMA foreign_keys=ON, creates the
    # `glossary` table if absent (id INTEGER PRIMARY KEY AUTOINCREMENT, plus one column per GlossaryEntry
    # field other than id; store `aliases` as a JSON-encoded TEXT column via json.dumps/json.loads).

    def add(self, entry: GlossaryEntry) -> GlossaryEntry:
        """entry.id must be None (raise ValueError otherwise). Inserts a row, returns a copy of entry with
        id set to the new rowid (use entry.model_copy(update={"id": new_id}))."""

    def get(self, entry_id: int) -> GlossaryEntry | None: ...

    def update(self, entry: GlossaryEntry) -> None:
        """entry.id must not be None (raise ValueError otherwise). Raises KeyError(entry.id) if no row with
        that id exists. Overwrites every column from entry."""

    def delete(self, entry_id: int) -> None:
        """Raises KeyError(entry_id) if no row with that id exists."""

    def list(self, *, status: Literal["proposed", "locked", "rejected"] | None = None) -> list[GlossaryEntry]:
        """All entries ordered by id ascending; filtered by status when given."""

    def find_by_source(self, source: str) -> GlossaryEntry | None:
        """Exact match on the `source` column (case-sensitive — CJK has no case; do not lowercase)."""

    def close(self) -> None: ...  # safe to call twice
    def __enter__(self) -> GlossaryStore: ...
    def __exit__(self, *exc: object) -> None: ...
```

`src/omniscan/glossary/yaml_io.py`:
```python
def export_yaml(store: GlossaryStore, path: Path) -> None:
    """Write every entry (store.list(), all statuses, id ascending) as a YAML list of plain dicts
    (entry.model_dump(mode="json"), so datetimes/etc. serialise cleanly — GlossaryEntry has none today, but
    keep this future-proof) via yaml.safe_dump(..., sort_keys=False, allow_unicode=True). Atomic write: dump
    to `path.with_suffix(path.suffix + ".tmp")` then `Path.replace`."""

def import_yaml(store: GlossaryStore, path: Path, *, mode: Literal["merge", "replace"] = "merge") -> int:
    """Read a YAML list of dicts (each validated as GlossaryEntry via GlossaryEntry.model_validate).
    mode="replace": delete every existing row in `store`, then insert every entry from the file fresh
    (ignoring any `id` present in the file — always assign new ids via `store.add`).
    mode="merge": for each entry in the file, look up `store.find_by_source(entry.source)`; if found, call
    `store.update` with that row's id and the file entry's other fields (file wins on conflicting fields,
    except `id` which always stays the existing row's id); if not found, `store.add` a fresh copy (id=None).
    Returns the number of entries written (inserted + updated)."""
```

`src/omniscan/glossary/match.py`:
```python
KOREAN_PARTICLES: tuple[str, ...] = ("이가", "은는", "을를", "의", "아", "야", "도", "에게", "에서", "에", "이", "가", "은", "는", "을", "를")
# ^ ordered longest-first within reason so a longer particle is tried before a shorter prefix of it matches
#   instead (e.g. try "에게" before "에"); the two 2-char pairs "이가"/"은는"/"을를" are single conventional
#   pairings some texts glue together — treat them as one particle each, in addition to their component halves
#   also being tried separately.


@dataclass(frozen=True, slots=True)
class Match:
    entry_id: int
    source: str      # the glossary term matched (entry.source or one of its aliases)
    start: int        # character offset into the searched text
    end: int          # end offset, exclusive; end - start may exceed len(source) when a particle was stripped
    particle: str | None  # the particle consumed after the term, if any


def find_terms(text: str, entries: Sequence[GlossaryEntry]) -> list[Match]:
    """For every entry (checking entry.source, then each of entry.aliases, longest candidate string first
    so a longer alias wins over a shorter one starting at the same position), scan `text` left to right for
    every occurrence of that candidate string. At each occurrence, look at what immediately follows in `text`:
    if it exactly matches one of KOREAN_PARTICLES (longest particle first), extend the match to include it
    and set `particle` to that string; otherwise `particle=None` and the match ends at the bare term. Matches
    do not overlap: once a span [start, end) is consumed, scanning resumes at `end`, and only the
    highest-priority match starting at a given position wins the position (entries list order breaks ties
    when candidate strings tie in length; the entries.source is always tried before its aliases for the same
    entry). Returns matches in left-to-right `start` order."""


def term_present(text: str, entry: GlossaryEntry) -> bool:
    """True if entry.target appears verbatim in `text` (plain substring check — this is for English output,
    which has no particle-gluing to worry about)."""
```

## Definitions (no interpretation needed)
- SQLite columns map 1:1 to `GlossaryEntry` fields except `aliases` (JSON TEXT) — every other field is a
  plain column of the matching SQL type (`TEXT`, `INTEGER`, `REAL` for `first_seen_chapter`).
- `find_terms` is a **greedy, non-overlapping, leftmost-first** scan: process `text` left to right; at each
  index, if any candidate (from any entry) starting exactly there is longer than any other candidate also
  starting there, the longer one wins; ties broken by `entries` list order (earlier entry wins), then by
  `entry.source` before its own aliases. This must be deterministic and independent of dict/set iteration
  order — do not rely on Python's default hashing for tie-breaking.
- Particle stripping only ever extends a match by **one** particle, never chains two.
- `import_yaml(mode="merge")` matching key is `source` only (not `type`) — if the store already has a
  `source`, the file's row updates it in place regardless of type.

## Acceptance tests
`tests/unit/test_glossary_store.py` (use `tmp_path / "series.db"`):
1. `add` on an entry with `id=None` returns a copy with a positive integer `id`; the original passed-in object
   is unchanged (pydantic models here are not mutated in place).
2. `add` on an entry with `id` already set raises `ValueError`.
3. `get` returns the exact entry (all fields, including a non-empty `aliases` list) after `add`; `get` on a
   missing id returns `None`.
4. `update` changes fields (e.g. `status: "proposed" -> "locked"`) and `get` reflects it; `update` with
   `id=None` raises `ValueError`; `update` with an unknown id raises `KeyError`.
5. `delete` removes the row (`get` afterwards is `None`); `delete` on an unknown id raises `KeyError`.
6. `list()` returns entries ordered by id; `list(status="locked")` returns only locked ones.
7. `find_by_source` returns the right entry for an exact match and `None` for no match (and does not
   accidentally do a substring match — an entry with source `"지훈"` must not match a lookup for `"지훈이"`).
8. Two entries with the same `source` but different `type` can both be added (no uniqueness constraint on
   `source` alone at the store level — matching/merge logic decides what "the same term" means, not the
   schema).
9. `close()` twice does not raise; a `with GlossaryStore(...) as s:` block closes on exit.

`tests/unit/test_glossary_yaml_io.py`:
10. `export_yaml` then `import_yaml(mode="replace")` into a **fresh** store round-trips every field of every
    entry (compare field-by-field, ignoring `id` since replace reassigns ids).
11. `import_yaml(mode="merge")` on a store that already has an entry with `source="지훈"` and a YAML file with
    an updated `target` for the same source: after import, `find_by_source("지훈").target` is the new value,
    and the row count is unchanged (updated in place, not duplicated).
12. `import_yaml(mode="merge")` on a YAML file containing a `source` not already in the store adds a new row;
    return value equals the total number of entries processed.
13. `export_yaml` output is valid YAML that a human can hand-edit (round-trip a manually-tweaked copy back
    through `import_yaml` and confirm the tweak took effect).

`tests/unit/test_glossary_match.py`:
14. `find_terms("지훈이 학교에 갔다", [entry(source="지훈"), entry(source="학교")])` finds `"지훈"` with
    `particle="이"` and `"학교"` with `particle="에"`, correct `start`/`end` offsets.
15. A term with no particle attached (followed by a space or end of string) matches with `particle=None`.
16. An alias matches the same as a bare source: `entry(source="지훈", aliases=["훈이형"])` — text containing
    `"훈이형"` produces a `Match` with `source="훈이형"`.
17. Overlap/priority: two entries where one's source is a prefix of another's (e.g. `"학"` and `"학교"`) —
    at a position where both could start, the longer one (`"학교"`) wins.
18. `term_present("Jihoon went home", entry(target="Jihoon"))` is `True`; `term_present("He went home",
    entry(target="Jihoon"))` is `False`.
19. `find_terms` on text with no matches returns `[]` without raising.
