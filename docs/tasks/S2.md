## Why
One slicer is not right for every series (owner spec 2026-09-20). The current one (`smart`: uniform bands + dynamic-programming cut planning) stays the default; three more **strategies** are added behind one function and selectable per series (`<library>/<Series>/series.toml`, section `[slicer]`, key `strategy` — the loader `core.config.series_config` is already merged), plus a **compare mode** that runs all strategies on one chapter and reports where each would cut, so the user (and later the GUI's debugger) can pick the best one. `page` is the existing page-mode code, `fixed` and `simple_gutter` are baselines (the second is the row-variance gutter script from the owner's notes).

## Interfaces (exact)
```python
# slicer/strategies.py
STRATEGIES: tuple[str, ...] = ("smart", "page", "fixed", "simple_gutter")

def slice_with_strategy(strip: torch.Tensor, cfg: SlicerConfig, source_files: list[SourceFile] | None = None, *, strategy: str | None = None) -> SlicesArtifact: ...
def slice_fixed(strip: torch.Tensor, cfg: SlicerConfig, source_files: list[SourceFile] | None = None) -> SlicesArtifact: ...
def slice_simple_gutter(strip: torch.Tensor, cfg: SlicerConfig, source_files: list[SourceFile] | None = None) -> SlicesArtifact: ...

# slicer/compare.py
@dataclass(frozen=True, slots=True)
class StrategySummary:
    strategy: str; slices: int; min_height: int; median_height: int; max_height: int; forced: int; blank: int; cuts: tuple[int, ...]   # cuts = the y of every internal boundary
def compare_strategies(strip: torch.Tensor, cfg: SlicerConfig, source_files: list[SourceFile] | None = None, strategies: Sequence[str] = STRATEGIES) -> dict[str, SlicesArtifact]: ...
def summarize(strategy: str, artifact: SlicesArtifact) -> StrategySummary: ...
```
`strip` is a uint8 `[3, H, W]` tensor (CPU or GPU — write the code so that it works on both; row statistics are computed with torch ops, **never a Python loop over rows or pixels**; a Python loop over *runs/cuts* is fine).

## Definitions (exact)
- `slice_with_strategy(..., strategy=None)` uses `cfg.strategy`; an unknown name → `ValueError(f"unknown slicer strategy {name!r}; choose one of smart, page, fixed, simple_gutter")`.
- **All strategies** return a `SlicesArtifact` with `strip_width`, `strip_height`, `slices` that tile `[0, H)` exactly (contiguous, no overlap), `params = {**cfg.model_dump(), "strategy": <name>}`, and for **every** slice: `blank` = all rows uniform, computed as `slice_strip` does it (`row_stats(strip, cfg.uniform_tol).uniform[y0:y1].all()`), and `source_files` = indices of the `source_files` overlapping `[y0, y1)` (empty list when `source_files` is None) — exactly like `slice_strip`. `bands` is `[]` for `page`, `fixed` and `simple_gutter` (only `smart` finds bands).
- **`smart`** = the existing `slice_strip(...)` (its params gain the `strategy` key; nothing else changes — all existing slicer tests must still pass).
- **`page`** = `slice_by_pages(source_files, W, H)` then the common post-processing above (blank flags). With `source_files` None or empty **and** `H > 0` it falls back to `smart` and records `params["fallback"] = "smart"`.
- **`fixed`**: `pos = 0`; while `H - pos > cfg.target_height`: cut at `pos + target_height` (that slice has `forced_cut=True`), `pos` = the cut; the remainder is the last slice; **if the last slice is shorter than `cfg.min_height` and there is more than one slice it is merged into the previous one** (the previous slice keeps its `forced_cut` flag from its own cut; the merged slice ends at H). Examples (target 3000, min 1500): H=10000 → `[0,3000) [3000,6000) [6000,10000)`; H=9000 → `[0,3000) [3000,6000) [6000,9000)`; H=2000 → one slice `[0,2000)`; H=0 → no slices.
- **`simple_gutter`** (the owner's script, generalised to both directions):
  1. `luma = strip.float().mean(0)` (`[H, W]`); `var = luma.var(dim=1, unbiased=False)` (per row); a row is a *gutter row* when `var < cfg.gutter_variance`.
  2. *Gutter runs* = maximal runs of consecutive gutter rows with length `>= cfg.gutter_min_rows`; the run's **cut row** is `(start + end) // 2` (`end` exclusive). Find runs with tensor ops (e.g. `diff` on the padded boolean row mask, then a Python loop over the resulting run list).
  3. `pos = 0`; while `H - pos > cfg.max_height`: `lo = pos + min_height`, `hi = pos + max_height`, `t = pos + target_height`; among the cut rows `c` with `lo <= c <= hi` choose the one with the smallest `|c - t|` (tie → the smaller `c`); if there is none, cut at `t` and mark that slice `forced_cut=True`. The remainder after the loop is the last slice (no merge rule here: it is at most `max_height` tall).
  Golden (built in the test, see test 3): a 100 px wide, 10 000 row strip of random noise (`torch.randint(0,256,(3,10000,100), generator seeded 0)`) with white rows `2900:2940`, `5000:5100`, `8000:8050` and `SlicerConfig(min_height=1500, target_height=3000, max_height=6000)` gives the gutter cut rows `[2920, 5050, 8025]` and the slices `[0,2920) [2920,5050) [5050,10000)`, none forced.
- **Stage:** `SliceStage.run` calls `slice_with_strategy(strip, ctx.cfg.slicer, ingest.files)`; its metrics dict is unchanged. (The per-series override reaches it through `ctx.cfg`.)
- **Compare:** `compare_strategies` returns `{strategy: artifact}` in the order of `strategies` (a strategy that raises `ValueError`, e.g. an unknown name, propagates). `summarize`: heights are `y1 - y0` of the slices (`median_height` = `int(statistics.median(...))`, all 0 for no slices), `forced` = number of `forced_cut` slices, `blank` = number of blank slices, `cuts` = `tuple(s.y1 for s in slices[:-1])`.
- **CLI** `omniscan slice-compare SERIES [-c/--chapter NAME] [--json]`: builds the chapter's strip exactly as `SliceStage` does (`IngestStage` first if `ingest.json` is missing — reuse `_run_stages`-style code or the helpers `cmd_slice` uses; use `ctx.cfg`, so a `series.toml` is honoured), calls `compare_strategies(...)` for all four strategies and prints a table `strategy  slices  min  median  max  forced  blank` (one row per strategy) **or** with `--json` `{"series", "chapter", "strip_height", "strategies": [ {StrategySummary fields…} ]}`; nothing is written to the work directory (no `slices.json`). Without `--chapter` the first chapter of the series is used; an unknown series/chapter → message on stderr, exit 1.

## Acceptance tests (CPU only; strips are tiny synthetic tensors)
1. **Dispatcher**: `strategy=None` follows `cfg.strategy`; explicit `strategy=` wins; unknown → the exact `ValueError`; `smart` output equals `slice_strip(...)` output apart from `params["strategy"]`; **all four** strategies tile `[0,H)` exactly (property test over `random_strip(seed)` from `tests/fixtures/strip_layouts.py`, ≥ 20 seeds), have `y0 < y1`, consecutive indices from 0, `params["strategy"] == name`.
2. **fixed**: the four examples of the definition; forced flags (`True` on every cut slice except a merged tail keeps its own flag); blank flag is computed (a solid-white 5000-row strip → all slices blank); `source_files` mapping.
3. **simple_gutter**: the golden above (cut rows, slices, no forced); no gutter at all (pure noise, H=10000) → forced cuts at `t`: 10000−0 > 6000 → cut 3000; 10000−3000 > 6000 → cut 6000; 10000−6000 = 4000 → stop; slices `[0,3000) [3000,6000) [6000,10000)`, the first two `forced_cut=True`, the last not; a gutter outside `[lo, hi]` is ignored; two gutters equally far from `t` → the smaller cut row; a gutter run shorter than `gutter_min_rows` is ignored; `gutter_variance` respected (rows with variance just below/above); a strip shorter than `max_height` → one slice; the code does not loop over rows in Python (assert with a 60 000-row strip finishing in reasonable time is enough — no timing assertion needed).
4. **page**: three source files (heights 1000/2000/1500, strip 4500) → three slices at exactly the file boundaries with `source_files == [i]` each and blank flags from the strip; `source_files=None` or `[]` → falls back to `smart` with `params["fallback"] == "smart"`; source files that do not tile the strip raise the existing `ValueError` from `slice_by_pages` (propagated).
5. **Stage**: `SliceStage` with `cfg.slicer.strategy = "page"` (via a tmp `Config` and a fake ingest, follow `tests/unit/test_slicer_slice.py`/the existing stage tests) writes `slices.json` whose `params["strategy"] == "page"`; a `series.toml` with `[slicer] strategy = "fixed"` changes what `make_context(...).cfg` gives to the stage; the stage version is 3 and its config hash changes with the strategy (`config_subset` differs).
6. **Compare**: `compare_strategies` order and keys; `summarize` on hand-made artifacts (heights, median with even/odd counts, forced/blank counts, cuts tuple; empty artifact → zeros and `()`); `strategies=("fixed",)` returns only that one.
7. **CLI** (`typer.testing.CliRunner`, monkeypatch the strip loader so no GPU is needed — follow how `tests/unit/test_cli.py` or `test_pipeline_cli.py` fake heavy parts): table output has one row per strategy; `--json` parses and has 4 entries with the summary fields; a series with `series.toml` `[slicer] target_height = 2000` is honoured; no files are written to the work dir; unknown series → exit 1. `tests/unit/test_docs.py` stays green with the new USER_GUIDE text.
8. `uv run --frozen pytest -q -m "not gpu"` stays green, including every existing slicer test and the mutation-gap tests.
