## Goal
`omniscan detect SERIES` writes `regions.json` (a `RegionsArtifact`, `text` empty) for every chapter: the chapter strip is
cut into overlapping tiles, `ogkalu/comic-text-and-bubble-detector` (RT-DETR-v2: `bubble`, `text_bubble`, `text_free`)
runs on the GPU in batches, detections are merged across tiles and turned into regions by the existing pure functions in
`detect/postprocess.py`. The WIP has the tile planner, the post-processing, the config and the shared strip loader but
**no tests** and no model wrapper, VRAM group, stage or CLI command. This card adds those and tests everything.
Nothing here reads text; OCR (C4) comes later. Unit tests run on CPU with a fake model; one `@pytest.mark.gpu` test loads
the real model.

## Part 1 — `detect/model.py`
```python
Box = tuple[float, float, float, float]

@dataclass(frozen=True, slots=True)
class RawDet:
    """One detection in the pixels of the tile it was found in."""
    cls: DetClass          # from omniscan.detect.postprocess
    score: float
    box: Box               # (x0, y0, x1, y1), tile pixels

class Detector:
    def __init__(self, model: Any, processor: Any, device: torch.device, *, threshold: float,
                 input_size: int = 640) -> None: ...
    @property
    def device(self) -> torch.device: ...
    @classmethod
    def load(cls, cfg: DetectConfig, device: torch.device) -> Detector: ...
    def detect(self, tiles: Sequence[torch.Tensor]) -> list[list[RawDet]]: ...
```
- `load`: `RTDetrV2ForObjectDetection.from_pretrained(cfg.repo, revision=cfg.revision)`, `.to(device).eval()`; on a CUDA/HIP
  device call `.half()` (measured: fp16 gives the same detections as fp32 and is ~2.4× faster), otherwise stay fp32.
  `processor = AutoImageProcessor.from_pretrained(cfg.repo, revision=cfg.revision)` is used ONLY for
  `post_process_object_detection`. `threshold = cfg.threshold`.
- `detect(tiles)`: every tile is `uint8 [3, h, w]` (any device; move it with `.to(self.device)`). Steps, exactly:
  1. `x = tile.unsqueeze(0).float()`, `F.interpolate(x, size=(input_size, input_size), mode="bilinear",
     antialias=True, align_corners=False)`, then `/ 255.0` — **no mean/std normalisation**. Stack all tiles into one
     `[N, 3, S, S]` batch, cast to the model dtype (`next(model.parameters()).dtype`).
  2. `with torch.inference_mode(): outputs = model(pixel_values=batch)`.
  3. `processor.post_process_object_detection(outputs, threshold=self.threshold, target_sizes=[(h_i, w_i), ...])` — this
     scales the boxes back to each tile's own pixel size. Map `label` → class name with `model.config.id2label`; labels
     whose name is not one of `bubble`, `text_bubble`, `text_free` are ignored. Boxes are clipped to `[0, w] × [0, h]`.
  4. One `RawDet` list per input tile, in input order, each sorted by descending score. An empty `tiles` returns `[]`.
  `detect` must never call `.cpu()` per detection: convert each image's result tensors with one `.tolist()` per tensor.
- Never `.numpy()`/`.cpu()` on the tiles themselves; the strip stays on the GPU.

## Part 3 — `detect/stage.py`
```python
class DetectStage:
    name: ClassVar[str] = "detect"
    version: ClassVar[int] = 1
    gpu_group: ClassVar[str | None] = VISION_GROUP
```
- `inputs(ctx)` = `[ctx.paths.artifact("ingest.json"), ctx.paths.artifact("slices.json"), *list_images(ctx.paths.raw_dir)]`;
  `outputs(ctx)` = `["regions.json"]`; `config_subset(cfg)` = `cfg.detect.model_dump()`.
- `run(ctx, models)`: `detector = models["detector"]`. Missing `ingest.json` or `slices.json` →
  `FileNotFoundError("<file> missing — run the slice stage first")`.
  1. `ingest = IngestArtifact.load(...)`, `slices = SlicesArtifact.load(...)`, `strip = load_strip(ctx, ingest)`.
  2. `active = [(s.y0, s.y1) for s in slices.slices if not s.blank and not s.filtered]`;
     `all_tiles = plan_tiles(ingest.strip_width, ingest.strip_height, cfg.tile_px, cfg.overlap)`;
     `tiles = keep_tiles(all_tiles, active)` (if `active` is empty there are no tiles and the artifact has no regions).
  3. For batches of `cfg.detect.batch_size` tiles (in order): crop `strip[:, t.y0:t.y1, t.x0:t.x1]` (views, no copy),
     `raw = detector.detect(crops)`, and convert each result with `tile_det_to_strip(tile, d.cls, d.score, d.box)`.
  4. `merged = merge_detections(dets, nms_iou=..., contain_thr=..., edge_penalty=...)` from `cfg.detect`;
     `regions = build_regions(merged, slices.slices, strip_width=..., strip_height=..., merge_bubble_text=..., direction=cfg.detect.reading_direction)`.
  5. `RegionsArtifact(regions=regions).save(ctx.paths.artifact("regions.json"))`.
  6. Return metrics (all `float`): `tiles` (used), `tiles_skipped`, `raw_detections`, `merged_detections`, `regions`.
- The stage never converts the strip to numpy or PIL.

## Part 4 — CLI
```
omniscan detect SERIES [--chapter/-c CHAPTER]... [--force]
```
Same options and help text style as `slice`; runs `[IngestStage(), SliceStage(), DetectStage()]` through `_run_stages`.

any stage in `stages` has `gpu_group is not None`**, pass `gpu=gpu` to `run_series`, and call `gpu.release()` in a
`finally` (so the models leave VRAM when the command ends). `ingest`/`slice` must not build a manager (no torch import cost,
no Ollama eviction) — test it.

## Definitions (exact — no interpretation)
- Class names are exactly `"bubble"`, `"text_bubble"`, `"text_free"`; `DetClass` in `postprocess.py` is the type.
- All boxes are `(x0, y0, x1, y1)` floats before `build_regions` and half-open integer `BBox` after.
- "Tile pixels" = coordinates inside the tile crop; "strip pixels" = the chapter strip (see `docs/ARCHITECTURE.md`).
