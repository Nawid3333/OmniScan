## Why
Our synthetic pages are perfectly clean, so every threshold tuned on them (`detect.threshold`, `ocr.drop_conf`, the golden test's limits) is optimistic. Real raws are JPEGs with compression blocks, sensor/paper noise, soft edges, halftone screens and a slight skew. This card adds one deterministic function that degrades a page in these ways, and a switch in the chapter generator. **Nothing in the existing fixture output may change** (defaults stay byte-identical; the golden test `tests/unit/test_e2e_synthetic.py` must stay green untouched).

## `tests/fixtures/scan_artifacts.py`
```python
def degrade(
    image: Image.Image,
    seed: int,
    *,
    blur_px: float = 0.6,
    noise_sigma: float = 4.0,
    halftone: bool = False,
    rotate_deg: float = 0.0,
    jpeg_quality: int = 60,
) -> Image.Image
```
Returns an RGB image of the **same size**; pure function of its arguments (same inputs → identical pixels; different `seed` → different pixels when `noise_sigma > 0`). Steps in this order:
1. `image.convert("RGB")`.
2. Blur: if `blur_px > 0`, `ImageFilter.GaussianBlur(radius=blur_px)`.
3. Noise: if `noise_sigma > 0`, add per-pixel Gaussian noise (independent per channel) drawn from `np.random.Generator(np.random.PCG64(seed))` with standard deviation `noise_sigma` (in 0..255 units), then round and clip to `[0, 255]` (`uint8`).
4. Halftone: if `halftone`, multiply every pixel by `1 - 0.08 * d(x, y)` where `d = 0.5 + 0.5 * sin(2π x / 6) * sin(2π y / 6)` (a 6-pixel dot grid, `x`/`y` are pixel column/row indices; vectorised numpy, no Python loops over pixels); round, clip.
5. Rotation: if `rotate_deg != 0`, `Image.rotate(rotate_deg, resample=Image.Resampling.BICUBIC, expand=False, fillcolor=(255, 255, 255))`.
6. JPEG round trip: save to `io.BytesIO` as JPEG with `quality=jpeg_quality` (Pillow default subsampling) and load it back, `convert("RGB")`. `jpeg_quality` outside `1..100` → `ValueError`; negative `blur_px` or `noise_sigma` → `ValueError`.

## `scripts/make_korean_chapter.py`
New options (all optional): `--scan-artifacts` (flag; applies `degrade` to every page image before it is written), `--jpeg-quality INT` (default 60, only used with the flag), `--noise FLOAT` (default 4.0), `--blur FLOAT` (default 0.6), `--halftone` (flag), `--rotate FLOAT` (default 0.0). Page `i` uses seed `args.seed + i` for the degradation.
Without `--scan-artifacts` the written files must be byte-identical to today's output (the other options are ignored). The truth JSON (`--truth-out`) is unchanged (it describes the clean page; rotation makes it approximate — mention that in the option's help text).

## Acceptance tests (`tests/unit/test_scan_artifacts.py`, CPU only, small images ≤ 200×200)
Unless a test names a value, call `degrade` with `noise_sigma=0, blur_px=0, jpeg_quality=100` so that only the effect under test is active.
1. Same size and mode `RGB` for several sizes; determinism (two calls with the same arguments give identical `tobytes()`); a different seed changes the pixels (noise on); `noise_sigma=0, blur_px=0, jpeg_quality=100, halftone=False, rotate_deg=0` returns an image whose mean absolute difference to the input is ≤ 2.0 (JPEG q100 only).
2. Noise level: on a flat `(128,128,128)` 200×200 image with `blur_px=0, jpeg_quality=100, noise_sigma=8.0` the standard deviation of the output (over all channel values) is between 5.5 and 9.5 (JPEG chroma subsampling removes a little of the colour noise) and the mean between 126 and 130; with `noise_sigma=0` (and the other options as above) the std is ≤ 1.0.
3. JPEG: on a checkerboard-with-gradient test image (generate it in the test) the mean absolute difference to the input with `jpeg_quality=20` is larger than with `jpeg_quality=95` (both with noise 0, blur 0).
4. Blur: a 1-pixel-wide black vertical line on white (100×100): after `blur_px=2.0` (noise 0, q100) the line's minimum pixel value is > 60 (it got lighter) and the column next to it is darker than 250; with `blur_px=0` the line's minimum stays < 20.
5. Halftone: on a flat `(200,200,200)` image (noise 0, blur 0, q100) `halftone=True` gives a per-pixel std ≥ 3.0 and a mean between 184 and 196 (the multiplier averages `1 - 0.08 * 0.5 = 0.96` → about 192); `halftone=False` gives std ≤ 1.0.
6. Rotation: a white image with a black square, `rotate_deg=0` keeps the square's position; `rotate_deg=5` moves the centroid of the dark pixels by ≤ 3 px for a square centred in the image (rotation about the centre) but changes the pixels; the corners of a `rotate_deg=10` result contain pure-white fill (≥ 250) where the original was black (draw a black frame border in the input).
7. Validation errors: `jpeg_quality=0` and `101`, `blur_px=-1`, `noise_sigma=-1` raise `ValueError`.
8. Generator: with `--scan-artifacts` the pages written by `make_korean_chapter.py` (call its `main` through `subprocess` or import; use a temp `--library-root`, `--pages 1`, a fixed `--seed`) differ from the ones without the flag and are valid JPEGs of 800×1400; two runs with the same arguments produce identical files; without the flag the file bytes equal the bytes produced by the same command on `main` — assert this by comparing against `make_korean_page(seed + 1, n_bubbles=4, n_free=1, n_sfx=1)` saved with quality 92 in the test (the generator's documented recipe).
9. `tests/unit/test_e2e_synthetic.py` and the whole suite stay green.
