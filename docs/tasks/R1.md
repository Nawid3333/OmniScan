## Goal
`omniscan run SERIES` takes a series from raw chapters to exported English slices. All stages become resumable `Stage` objects (translate and judge get thin adapters) and are executed in **three passes over all chapters**, so each model group is loaded once instead of once per chapter:
1. **vision** — `ingest, slice, detect, ocr` (GPU model group `vision`);
2. **text** — `translate, judge` (local Ollama models occupy VRAM, so the torch models are released first; cloud-only profiles need no GPU handover);
3. **render** — `inpaint, inpaint_lama, typeset, export` (`inpaint_lama` loads the LaMa group only when it runs).
The queue (`omniscan queue`) uses the same machinery, so a queued job can run any of the ten stages.

## Part 1 — `pipeline/stages.py`
```python
STAGE_ORDER: tuple[str, ...] = ("ingest", "slice", "detect", "ocr", "translate", "judge", "inpaint", "inpaint_lama", "typeset", "export")
PASS_OF: dict[str, str]                # "ingest"/"slice"/"detect"/"ocr" -> "vision"; "translate"/"judge" -> "text"; the rest -> "render"

class TranslateStage:                  # satisfies core.stage.Stage
    name: ClassVar[str] = "translate"; version: ClassVar[int] = 1
    gpu_group: str | None              # instance attribute
    def __init__(self, client: ChatClient, profiles: Sequence[TranslationProfile]) -> None
class JudgeStage:                      # satisfies core.stage.Stage
    name: ClassVar[str] = "judge"; version: ClassVar[int] = 1
    gpu_group: str | None
    def __init__(self, client: ChatClient, judge_cfg: JudgeConfig) -> None

def build_stage(name: str, cfg: Config, *, client: ChatClient | None = None) -> Stage
```
- `build_stage` returns a fresh stage object: `IngestStage`, `SliceStage`, `DetectStage`, `OcrStage`, `InpaintStage`, `LamaStage`, `TypesetStage`, `ExportStage` (imports inside the function), `TranslateStage(client, profiles)` with `profiles` = the **enabled** profiles of
  `load_profiles(default_profile_paths())`, `JudgeStage(client, load_judge_config(default_judge_paths()))`. Unknown name → `ValueError(f"unknown stage {name!r} (known: ...)")`; `translate`/`judge` with `client is None` → `ValueError("stage 'translate' needs a chat client")`.
- **`TranslateStage`**: `inputs(ctx)` = `[ocr.json]` plus `series.db` when `SeriesPaths.db.is_file()` (the glossary — a locked term changes the translations); `outputs(ctx)` = `[f"translations/{p.name}.json" for p in profiles]`; `config_subset(cfg)` = `{"profiles": [p.model_dump() for p in profiles]}`;
  `run(ctx, models)`: entries = the glossary entries when the db exists (`GlossaryStore(...)`, all entries, never create the db) else `[]`; for each profile call `translate_chapter(client, ctx.paths, profile, entries, force=True)` (the runner already decided the stage is stale; a dot-prefixed partial file of an interrupted run is still resumed by it);
  metrics: `profiles` (count) and `regions` (sum of `usage["regions"]` of the returned runs, `0` when none). Exceptions propagate (the runner records the failure).
  `gpu_group` = `OLLAMA_GROUP` when any profile needs the local GPU — `endpoint == "local"` and the model name does NOT end with `":cloud"` — else `None`.
- **`JudgeStage`**: `inputs(ctx)` = `[ocr.json, *sorted(non-dot translations/*.json), series.db if present]`; `outputs` = `["final.json"]`; `config_subset(cfg)` = `judge_cfg.model_dump()`; `run`: `judge_chapter(client, ctx.paths, judge_cfg, entries, force=True)`; metrics from its `JudgeStats`
  (`regions`, `judged`, `auto_picked`, `untranslated`, `violations_left`, `requests`) as floats; `gpu_group` = `OLLAMA_GROUP` when `judge_cfg.endpoint == "local"` and the model does not end with `":cloud"`, else `None`.

## Part 2 — `pipeline/runner.py`
```python
def plan_passes(stages: Sequence[str]) -> list[tuple[str, list[str]]]
@dataclass(slots=True)
class PipelineResult:
    outcomes: dict[str, list[StageOutcome]]      # chapter -> outcomes in execution order
    failed: dict[str, str]                       # chapter -> "<stage>: <error>" of the first failure
    aborted: str | None                          # "rate limit" when an Ollama rate limit stopped the run
    @property
    def ok(self) -> bool                         # no failure and not aborted
def run_pipeline(cfg: Config, series: str, chapters: Sequence[str] | None = None, *, stages: Sequence[str] | None = None,
                 lama: bool = True, force: bool = False, client: ChatClient | None = None, gpu: GpuScheduler | None = None,
                 report: Callable[[str, StageOutcome], None] | None = None) -> PipelineResult
```
- `plan_passes(stages)`: every name must be in `STAGE_ORDER` (else `ValueError`); duplicates collapse; the result is ordered by `STAGE_ORDER` and split into **consecutive runs sharing the same `PASS_OF` label**: `plan_passes(STAGE_ORDER)` →
  `[("vision", ["ingest","slice","detect","ocr"]), ("text", ["translate","judge"]), ("render", ["inpaint","inpaint_lama","typeset","export"])]`; `["export", "ingest"]` → `[("vision", ["ingest"]), ("render", ["export"])]`; `[]` → `[]`.
- `run_pipeline`: `names = stages if given else STAGE_ORDER`; when `lama` is false `"inpaint_lama"` is removed from `names`. `active` = the given chapters, else `SeriesPaths.from_config(cfg, series).chapters()` (none at all → `ValueError(f"no chapters found for series {series!r}")`).
  For every pass in `plan_passes(names)`: build the stage objects with `build_stage` (a pass whose stages include `translate`/`judge` needs `client`); run `run_series(stage_objects, cfg, series, active, gpu=gpu, force=force)`; every outcome is passed to `report(chapter, outcome)` **after its pass finished** (in chapter order, then stage order);
  a chapter with a `failed` outcome is recorded in `failed` (first failure only) and **removed from `active`** for the remaining passes. If a failed outcome's `error` starts with `"OllamaRateLimitError"` the run stops immediately: `aborted = "rate limit"`, no further pass.
  `outcomes[chapter]` accumulates over passes. Nothing is caught except through the runner's own failure recording; unexpected exceptions propagate.
- The runner never builds a VRAM manager or a client itself.

## Part 3 — queue executor and CLI
- `queue/executor.py`: `stage_executor(cfg)` keeps its signature; `_run(job)`: unknown stage names → `PermanentJobError(f"stage {name!r} is not implemented yet")` (same text as today, the check now uses `STAGE_ORDER`); no chapters → `PermanentJobError` as today; otherwise
  `run_pipeline(cfg, job.series, job.chapters, stages=job.stages, force=job.force, client=<OllamaClient(cfg.ollama, get_secrets()) only when the stages include translate/judge>, gpu=<build_vram_manager(cfg) when any built stage has a gpu_group — build lazily>)`; a result that is not `ok` raises
  `RuntimeError("; ".join(f"{chapter}: {message}" ...))` (rate-limit abort → `RuntimeError("Ollama rate limit reached")`, which the worker retries under its normal attempt rules); the VRAM manager, if built, is released in a `finally`. Keep `STAGE_TABLE` importable as a mapping of the ten stage names for the existing tests if they need it, but the execution path uses `run_pipeline`.
  Because `run_pipeline` needs to know whether a manager is required before running, expose in `pipeline/runner.py`: `def needs_gpu(names: Sequence[str], cfg: Config, client: ChatClient | None) -> bool` = `True` when any stage built for `names` has a `gpu_group` (build the stages with `build_stage` and inspect).
- `queue/store.py`: `KNOWN_STAGES` gets `"inpaint_lama"` between `"inpaint"` and `"typeset"`.
- CLI: `omniscan run SERIES [--chapter/-c CHAPTER]... [--stage/-s NAME]... [--no-lama] [--force]`: `--stage` repeatable (default: all); unknown stage → `run: unknown stage 'x' (known: ...)` on stderr, exit 2; no chapters → `run: no chapters found for series 'X'`, exit 2.
  Build a client only when a text-pass stage is selected (`OllamaClient(get_config().ollama, get_secrets())` — reference `get_config`/`get_secrets`/`OllamaClient` through the `omniscan.cli` namespace so tests can monkeypatch them) and a VRAM manager when `needs_gpu(...)` (via `omniscan.gpu.groups.build_vram_manager`, released in a `finally`).
  Output: one line per stage outcome as printed by `_run_stages` (`{series}/{chapter} {stage}: {status} ({seconds:.2f}s)` and the indented error line for failures), then a summary `{n_ok} chapter(s) ok, {n_failed} failed`. Exit 0 when `ok`; 3 with `run: Ollama rate limit reached — re-run later` when aborted; 1 otherwise.
