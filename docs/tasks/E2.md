## Part 1 — `eval/truth.py`
```python
@dataclass(frozen=True, slots=True)
class TruthBox:
    page: int                 # page number from the SVG file name (E06P01 -> 1); it is the int of the raw file's stem ("01.jpg" -> 1)
    bbox: BBox                # strip space
    lines: tuple[str, ...]    # the flowPara texts, stripped, non-empty, document order
    @property
    def text(self) -> str: ...            # " ".join(lines)

def parse_svg(svg: str, *, file_width: int, file_height: int, file_y0: int, scale: float) -> tuple[list[TruthBox-like tuples], int]
def load_truth(check_dir: Path, lang: str, ingest: IngestArtifact) -> tuple[list[TruthBox], TruthStats]
```
`parse_svg` returns `(boxes, dropped)` where `boxes` is a list of `(bbox, lines)` for one page (you may return `TruthBox`es with `page=0`; `load_truth` sets the real page), `dropped` counts boxes that were removed (see below).
- Parse with `xml.etree.ElementTree`. Walk the tree recursively so that the transforms of ancestor `<g>` elements are composed (outer first). For every `flowRoot` (any namespace prefix): the box is its `flowRegion/rect` (`x,y,width,height`); the lines are the texts of its `flowPara` children (`"".join(el.itertext()).strip()`, empty ones dropped). A `flowRoot` without rect or without any non-empty line is skipped (not counted as dropped).
- Transform attribute: a space/comma separated list of `matrix(a,b,c,d,e,f)`, `translate(x[,y])`, `scale(x[,y])`, `rotate(deg[,cx,cy])` (a missing `y` in translate is 0, in scale equals x). SVG semantics: the list is applied to a point **right to left** (`translate(1000,1500) scale(0.5)` scales first). No transform = identity. Unknown syntax → identity.
- Geometry: transform the four rect corners, take the min/max → SVG-space bounds. The SVG root has `width` and `height` (plain numbers, possibly with a `px` suffix): `sx = file_width / svg_width`. **The lettered low-res pages are the SVG page scaled by `sx` and cropped at the TOP** by `crop_top = max(0, round(svg_height * sx) - file_height)` rows (verified on real data: 34 rows for 1200×1660 files vs 2481×3503 SVGs). Page pixels: `x = svg_x * sx`, `y = svg_y * sx - crop_top`.
  Clamp the box to `[0, file_width] × [0, file_height]`; if the clamped box has zero width or zero height it is **dropped** (counted). Then strip space: `x * scale`, `y * scale + file_y0`. Rounding: `x0, y0` floor, `x1, y1` ceil, each with a 1e-6 tolerance (`floor(v + 1e-6)`, `ceil(v - 1e-6)`).
- `load_truth(check_dir, lang, ingest)`: for every non-filtered `SourceFile` `f` of `ingest.files` with a stem that is an integer `n`, read `check_dir / lang / f"E??P{n:02d}.svg"` (glob `E*P{n:02d}.svg`; missing → skip that page, count it in `TruthStats.pages_without_truth`). Return all boxes (with `page=n`) in file order then document order, and `TruthStats(pages, pages_without_truth, dropped)`.
  A second function `load_english_pages(check_dir, ingest) -> dict[int, str]` returns, per page number, the lines of the `en` SVG of that page joined by `" "` in document order (only boxes that survive parsing; no geometry needed — you may reuse `parse_svg` with the same arguments).

## Part 2 — `eval/metrics.py`
```python
def normalize(text: str) -> str                          # NFKC, lower-case, keep only characters whose unicode category starts with "L" or "N"
def levenshtein(a: str, b: str) -> int                   # classic edit distance (insert/delete/substitute = 1)
def cer(truth: str, read: str) -> float                  # levenshtein(normalize(truth), normalize(read)) / len(normalize(truth)); ValueError when normalize(truth) is empty
def chrf(hypothesis: str, reference: str, max_n: int = 6, beta: float = 2.0) -> float
```
`chrf`: both texts normalised as above; for every `n` in `1..max_n` build the character n-gram `Counter`s; skip an order when either side has no n-gram of that length; `match = sum((hyp & ref).values())`, `p_n = match / total_hyp`, `r_n = match / total_ref`; `P` and `R` are the means over the used orders; no used order → `0.0`;
`F = 0.0 if P + R == 0 else (1 + beta²) · P · R / (beta² · P + R)`.
Golden values (computed with a reference implementation): `normalize("Hello, World! 안녕... 하세요?  ABC-12") == "helloworld안녕하세요abc12"`; `cer("안녕하세요","안녕하세여") == 0.2`; `cer("첫째 줄","첫째줄") == 0.0`; `cer("안녕","안녕하세요") == 1.5`; `cer("abc","xyz") == 1.0`; `cer("Hello!","hello") == 0.0`;
`chrf("The cat sat on the mat","The cat sat on the mat") == 1.0`; `chrf("The cat sat on the mat","The cat sits on a mat")` ≈ `0.434395` (abs 1e-5); `chrf("abc","xyz") == 0.0`; `chrf("ab","ab") == 1.0`; `chrf("Hello, world!","hello world") == 1.0`; `chrf("I must have fallen asleep","I must have fallen asleep with the window open")` ≈ `0.575235` (abs 1e-5).

## Part 3 — `eval/score.py`
```python
@dataclass(frozen=True, slots=True)
class BoxResult:  page: int; bbox: BBox; text: str; detected: bool; read: str; cer: float | None   # cer only when detected

@dataclass(frozen=True, slots=True)
class EvalReport:
    chapter: str; series: str
    truth_boxes: int; ignored_boxes: int; dropped_boxes: int; pages: int; pages_without_truth: int
    regions: int; assigned_regions: int
    detected_boxes: int
    recall: float | None; precision: float | None          # None when the denominator is 0
    cer_macro: float | None; cer_micro: float | None; cer_boxes: int
    chrf_mean: float | None; chrf_pages: int               # None without final.json / without scorable pages
    missed: list[BoxResult]; worst_cer: list[BoxResult]    # missed: largest 10 by bbox area; worst_cer: 10 highest cer
    def to_json(self) -> str: ...                          # json.dumps of the dataclass tree (bboxes as [x0,y0,x1,y1]); indent 2, ensure_ascii False

def score_chapter(series: str, chapter: str, ingest: IngestArtifact, regions: RegionsArtifact, final: FinalArtifact | None,
                  truth: list[TruthBox], english_pages: dict[int, str], stats: TruthStats) -> EvalReport
```
Definitions (exact):
- **Ignored boxes:** truth boxes whose `normalize(text)` is empty (only punctuation such as "…?!") are removed from every metric and counted in `ignored_boxes`.
- **Predicted regions:** all regions of `ocr.json` except `kind == "watermark"`. `center = ((x0 + x1) / 2, (y0 + y1) / 2)`.
- **Assignment:** a region is assigned to the truth box with the **smallest area** that contains its center (`x0 <= cx <= x1` and `y0 <= cy <= y1`, inclusive); ties → the lowest index in `truth`; none → unassigned.
- `detected_boxes` = truth boxes with at least one assigned region; `recall = detected_boxes / truth_boxes` (after ignoring); `precision = assigned_regions / regions`.
- **CER:** for a detected truth box the read text is the assigned regions' `text` joined by `" "` in `(bbox.y0, bbox.x0)` order; `cer(box.text, read)`. `cer_macro` = mean over detected boxes, `cer_micro` = sum of edit distances / sum of `len(normalize(truth))` over the same boxes; `cer_boxes` = their count.
- **Translation (`chrf_mean`, only when `final` is given):** per page number `n` of `english_pages`: the file of page `n` covers strip rows `[y0, y1)`; hypothesis = the `final.json` texts of the `translatable(regions.regions)` whose center row lies in `[y0, y1)`, in the order `translatable` returns them, joined by `" "` (regions without a final line are skipped);
  reference = `english_pages[n]`. A page is scored when the reference is non-empty **and** the hypothesis is non-empty **or** the reference is non-empty and the hypothesis is empty (score 0.0); it is skipped when the reference is empty. `chrf_mean` = mean of `chrf(hyp, ref)` over scored pages, `chrf_pages` their count.
- `missed` = undetected truth boxes sorted by area descending, at most 10; `worst_cer` = detected boxes sorted by `cer` descending, at most 10.
