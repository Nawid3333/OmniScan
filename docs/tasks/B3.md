# B3 — Ingest: discover chapter files, normalise to JPEG, compute strip layout

**Owner:** builder (`glm-5.3-flash:cloud`) · **Branch:** `B3` · **Worktree:** `~/projects/omniscan-wt/B3`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Goal
Given a chapter's raw image files, produce an `IngestArtifact`: every file's final (post-EXIF, post-alpha-flatten)
JPEG bytes are guaranteed available on disk, and each file's position in the vertically-stitched **strip** (after
scaling every image to one common **strip width**) is computed. No GPU, no torch — this runs on the CPU with Pillow.

class ConvertedImage:

    sha256: str           # sha256 of jpeg_path's bytes
    width: int            # final pixel width, after EXIF orientation is applied
    height: int           # final pixel height, after EXIF orientation is applied
    converted: bool        # True iff a new file was written (source was not already a plain baseline RGB JPEG)

def needs_conversion(path: Path) -> bool:
    """True if `path` is not already usable as-is: suffix not .jpg/.jpeg, or (once opened) mode has an alpha
    channel, or mode == 'CMYK', or an EXIF Orientation tag is present and != 1."""
    ...

def convert_to_jpeg(src: Path, cache_dir: Path, index: int, quality: int = 95) -> ConvertedImage:
    """If `needs_conversion(src)` is False: ConvertedImage points at `src` itself (converted=False), width/height
    from PIL, sha256 = hash_file(src). Otherwise: open with Pillow, apply ImageOps.exif_transpose, if mode has
    alpha compose onto an opaque white RGB background (PIL 'RGBA'/'LA'/'PA' -> paste using the alpha channel as
    mask over a new 'RGB' white canvas of the same size), elif mode == 'CMYK' convert('RGB'), elif mode not in
    ('RGB',) convert('RGB'). Save as JPEG at `cache_dir / f"{index:04d}_{src.stem}.jpg"` with quality=quality,
    subsampling=0 (4:4:4), optimize=True; no EXIF written to the output (already baked in via exif_transpose).
    cache_dir is created if missing. Return ConvertedImage(jpeg_path=<that path>, sha256=hash_file(that path),
    width, height, converted=True)."""
    ...

# layout.py
def dominant_width(widths: Sequence[int]) -> int:
    """The most frequent width; ties broken by the larger width."""
    ...

def stack_layout(sizes: Sequence[tuple[int, int]], strip_width: int) -> list[tuple[float, int, int]]:
    """sizes = [(width, height), ...] in reading order. For each, scale = strip_width / width; scaled_height =
    round(height * scale), minimum 1. Returns [(scale, y0, y1), ...] where y0/y1 stack cumulatively starting at 0
    (y1 of item i == y0 of item i+1), same length and order as `sizes`."""
    ...

# __init__.py
@dataclass(frozen=True, slots=True)
class IngestResult:
    artifact: IngestArtifact
    converted_paths: list[Path]  # the ConvertedImage.jpeg_path for every file, in order (for the caller to decode)

def ingest_chapter(raw_dir: Path, series: str, chapter: str, cache_dir: Path, quality: int = 95) -> IngestResult:
    """list_images(raw_dir) -> for each (index, path): convert_to_jpeg(path, cache_dir, index, quality) ->
    dominant_width over all final widths -> stack_layout over all (width, height) -> build one SourceFile per
    file (name=path.name, sha256, width=original final width, height=original final height, y0, y1, scale,
    converted_from=path.suffix.lower() if converted else None, filtered=False) -> IngestArtifact(series, chapter,
    strip_width=dominant_width, strip_height=last y1, files=[...]). Raise ValueError if raw_dir has no images."""
    ...

## Definitions / edge cases
- "Plain baseline RGB JPEG" for `needs_conversion` purposes: Pillow reports `format == "JPEG"`, `mode == "RGB"`,
  and either no `exif` or `ImageOps.exif_transpose` would be a no-op (no Orientation tag, or tag value 1).
- Grayscale JPEGs (`mode == "L"`) count as needing conversion (convert to RGB) — a grayscale scanlation page must
  still become a plain RGB JPEG so every downstream tensor is `[3, H, W]`.
- `dominant_width`: use `collections.Counter`; on an empty sequence raise `ValueError`.
- Rounding in `stack_layout`: Python's `round()` (banker's rounding is fine, just be consistent — tests use values
  where this doesn't matter, e.g. exact halves are avoided).
- `ingest_chapter` must be **idempotent and resumable**: if `cache_dir / f"{index:04d}_{stem}.jpg"` already exists
  from a previous run, `convert_to_jpeg` must overwrite it (an ingest re-run has newer source data, e.g. the source
  file changed) — always write when `converted` is True, never skip based on existence.
- Do not decode/touch pixel data for a file that doesn't need conversion — only `Image.open(...).size` /
  `.mode` / `.format` / `.getexif()` (all header-only, no `.load()`).

## Synthetic fixtures (`tests/fixtures/images.py`)
Each returns bytes or writes to a given path; sizes are deliberately small (this is CPU/Pillow, not GPU):
- `plain_jpeg(path, size=(400, 300), color=(200, 60, 60))`: writes a baseline RGB JPEG, no EXIF.
- `rotated_jpeg(path, size=(300, 400), color=(60, 200, 60), orientation=6)`: writes an RGB JPEG **already stored
  landscape/portrait-swapped** with an EXIF `Orientation` tag (6 = rotate 90° CW on display) such that after
  `exif_transpose` the logical size becomes `size` (i.e. write the raw pixel data at the swapped dimensions).
- `png_with_alpha(path, size=(200, 200))`: RGBA PNG, semi-transparent gradient alpha.
- `cmyk_jpeg(path, size=(200, 200))`: CMYK-mode JPEG.
- `grayscale_jpeg(path, size=(200, 200))`: mode "L" JPEG.
- `webp_image(path, size=(250, 180))`: plain RGB WebP.

## Acceptance tests (`uv run pytest tests/unit/test_ingest_*.py`)
`test_ingest_convert.py`:
1. `plain_jpeg` → `needs_conversion` False; `convert_to_jpeg` returns `converted=False`, `jpeg_path == src`,
   sha256 equals `hash_file(src)`.
2. `rotated_jpeg(orientation=6)` → `needs_conversion` True; after conversion, `width, height == size` (the logical,
   post-rotation size), the output file is a new file in `cache_dir`, and re-opening it with Pillow has no EXIF
   Orientation tag needing further rotation (visually already upright).
3. `png_with_alpha` → converted True, output mode is RGB (open the result and check `.mode == "RGB"`), a fully
   transparent corner pixel becomes white `(255, 255, 255)`.
4. `cmyk_jpeg` and `grayscale_jpeg` → both `needs_conversion` True, output mode RGB.
5. `webp_image` → converted True (suffix not .jpg/.jpeg), output width/height match the source.
6. Re-running `convert_to_jpeg` on the same `(src, cache_dir, index)` after the source file's content changed
   (rewrite `src` with a different color) produces a file whose sha256 differs from the first run's.

`test_ingest_layout.py`:
7. `dominant_width([800, 800, 800, 1000])` == 800; a tie `[800, 800, 1000, 1000]` == 1000 (larger wins).
8. `stack_layout([(800, 1000), (1600, 2000), (800, 500)], strip_width=800)` ==
   `[(1.0, 0, 1000), (0.5, 1000, 2000), (1.0, 2000, 2500)]`.
9. `stack_layout` heights are always `>= 1` even for a pathological `(width=10000, height=1)` scaled down hugely.

`test_ingest.py` (uses the fixtures above written into `tmp_path`):
10. A chapter of 3 plain JPEGs of the same width → `IngestArtifact.strip_width` equals that width, no file has
    `converted_from` set, `y0/y1` are contiguous and start at 0, `strip_height` equals the sum of heights.
11. A chapter mixing a plain JPEG, a `png_with_alpha`, and a `rotated_jpeg` → the PNG and rotated files have
    `converted_from` set to their original suffix (`.png`, `.jpg` — rotated is still a .jpg source but converted
    because of EXIF, so `converted_from == ".jpg"`), the plain JPEG does not.
12. File order in `IngestArtifact.files` matches `list_images` order (natural sort), and `SourceFile.index`
    is `0, 1, 2, ...` in that order.
13. Round-trip: `result.artifact.save(work_dir / "ingest.json")` then `IngestArtifact.load(...)` equals the
    original.
14. Empty `raw_dir` raises `ValueError`.
15. `result.converted_paths` all exist on disk and are openable as JPEG (`Image.open(p).verify()` or format check).
