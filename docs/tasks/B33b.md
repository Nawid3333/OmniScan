## Part 1 — `acquire/extractpics.py`
```python
API_BASE = "https://api.extract.pics/v0"

class ExtractPicsClient:
    """extract.pics REST client implementing `Extractor`."""
    def __init__(
        self,
        api_key: str,
        *,
        client: httpx.Client | None = None,        # injected in tests; when None create httpx.Client(timeout=30.0) and close it in close()
        base_url: str = API_BASE,
        poll_interval_s: float = 2.5,
        timeout_s: float | None = None,            # None -> 180.0 for "basic", 300.0 for "advanced" (decided per extract call)
        max_retries: int = 3,
        requests_per_minute: int = 20,
        sleep: Callable[[float], None] = time.sleep,
        clock: Callable[[], float] = time.monotonic,
    ) -> None: ...
    def extract(self, url: str, *, mode: Mode = "basic") -> Extraction: ...
    def close(self) -> None: ...
    def __enter__(self) -> Self: ...
    def __exit__(self, *exc: object) -> None: ...
```
`extract(url, mode)` exactly:
1. `check_allowed(url)` first (DRM platforms raise `DrmPlatformError`; nothing is sent).
2. `POST {base_url}/extractions` with JSON body `{"url": url, "mode": mode}` and headers `Authorization: <api_key>` (**raw key, no "Bearer"**), `Accept: application/json`, `User-Agent` = `omniscan.acquire.download.USER_AGENT`. Success = status 200 or 201; the id is `body["data"]["id"]`.
3. Poll `GET {base_url}/extractions/{id}` every `poll_interval_s` (via `sleep`) until `data.status == "done"`. Status `pending` or `running` → keep polling. **Any other status** → `ExtractError(f"extraction {id} ended with status {status!r}")` (append the body's `message` when present). If `clock() - start > timeout_s` → `ExtractError(f"extraction {id} timed out after {timeout_s:.0f}s")` (the id is in the message so the user can retrieve it later).
4. On `done`: images = `data["images"]` (list of objects with `"url"`); build `ExtractedImage(url)` in list order, **dropping exact duplicate URLs (first occurrence wins)** and entries without a string `url`; `Extraction(id=..., page_url=data.get("url") or url, images=tuple(...), credits=credit_cost(1, mode))`.
5. Errors (a helper `_send(method, path, **kw) -> httpx.Response` does the retrying for both POST and GET):
   - **401** → `AuthError("extract.pics rejected the API key")` (never retried).
   - **402** → `QuotaError("extract.pics reports no credits left")` (never retried).
   - **429** → wait `int(Retry-After)` seconds (header parsed as an integer, capped at 60; missing/invalid → `5 * (attempt + 1)`), then retry, at most `max_retries` retries; still 429 → `QuotaError("extract.pics rate limit still exceeded after N retries")`.
   - **5xx** and `httpx.TransportError` (timeouts, connection errors) → retry with `sleep(0.5 * 2**attempt)`, at most `max_retries` retries, then `ExtractError` with the status or exception text.
   - **422** → `ExtractError(message + ": " + first error text)` taken from `{"message": ..., "errors": {"url": ["..."]}}` (fall back to the raw text when the body is not JSON).
   - **404** while polling → `ExtractError(f"extraction {id} not found")`.
   - any other 4xx → `ExtractError(f"extract.pics answered HTTP {status}: {first 200 chars of the body}")`.
   - A `200/201` whose body is not JSON or lacks `data`/`id`/`status` → `ExtractError("unexpected response from extract.pics: ...")` (first 200 chars).
6. **Client-side rate limiter** (the API allows 25 requests/minute and polling counts): before *every* HTTP request call `_throttle()` which keeps a deque of the last request times from `clock()`; when it already holds `requests_per_minute` entries younger than 60 s, `sleep(60 - (now - oldest))` (then drop expired entries) before sending. `requests_per_minute` must be ≥ 1 (else `ValueError`).
7. The API key must never appear in an exception message, `repr()` of the client or a log line (give the class a `__repr__` that shows only the base URL). Do not log request headers.

## Part 2 — `acquire/pagerun.py`
```python
@dataclass(frozen=True, slots=True)
class PageSelection:
    kept: tuple[str, ...]                    # URLs in document order
    dropped: tuple[tuple[str, str], ...]     # (url, reason) in document order

def select_pages(urls: Sequence[str], *, min_run: int = 3, min_share: float = 0.5) -> PageSelection: ...
```
Exact algorithm (apply the steps in this order; a URL dropped by an earlier step is not examined by later ones):
1. **Duplicates:** an exact repeat of an earlier URL → reason `"duplicate"`.
2. **Format:** take the last path segment of `urlsplit(url).path`; if it has a suffix (`PurePosixPath(name).suffix.lower()`) that is **not** in `{".jpg", ".jpeg", ".png", ".webp"}` → reason `f"not a page format ({suffix})"` (so `.svg`, `.gif`, `.ico`, `.avif` are dropped). URLs without any suffix are **kept** at this step.
3. **Non-page URLs:** `filters.url_looks_like_page(url)` false → its reason (unchanged text).
4. **Thumbnails:** if the file name matches `re.search(r"(\d{2,4})x(\d{2,4})", name)` and **both** numbers are ≤ 400 → reason `"thumbnail size in name"`.
5. The remaining URLs are the *candidates*. **Run detection:** group candidates by the key `(host, directory, pattern)` where `host = urlsplit(url).netloc.lower()`, `directory` = the path without its last segment, `pattern` = the last segment with every run of digits replaced by `#`. Let `G` be the largest group (ties: the group whose first member comes first in the document). If `len(G) >= min_run` **and** `len(G) / len(candidates) >= min_share` → keep only the members of `G`; every other candidate is dropped with reason `"not part of the page run"`. Otherwise keep all candidates (there is no dominant run, e.g. hashed file names).
6. `kept` and `dropped` keep document order; every input URL appears in exactly one of them.

## Definitions
- "Document order" = order in the input sequence.
- The fixture's page URLs differ only in `E06P00 … E06P10` → pattern `en_Pepper-and-Carrot_by-David-Revoy_E#P#.jpg` in the same directory.

12. Duplicates: `[a, a, b, c, d]` (three-page run in one directory `a.jpg`-style names `001.jpg`…) → the second `a` is dropped as `"duplicate"`.
13. Hashed names (`https://cdn.test/img/3fa9c2.jpg`, `.../91bb07.jpg`, `.../c0de11.jpg`, `.../ab12cd.jpg`) → the patterns `#fa#c#.jpg`, `#bb#.jpg`, `c#de#.jpg`, `ab#cd.jpg` are all different, every group has 1 member < `min_run` → all four are kept.
14. `min_share`: 3 run pages + 5 unrelated jpgs in five other directories → run share 3/8 < 0.5 → all 8 kept; the same with `min_share=0.3` → only the run kept.
15. Tie: two groups of 3 (different directories) → the one that appears first in the document wins.
16. Extensionless URLs are kept at step 2 (and then normally dropped by the run rule when a run exists); a URL with a query string (`.../001.jpg?w=800`) is grouped by its path only; upper-case suffix `.JPG` is accepted; thumbnails: `photo-150x150.jpg` dropped, `page-1080x1920.jpg` kept.
17. Empty input → empty `PageSelection`; `select_pages` never reorders and every input URL is in exactly one of `kept`/`dropped` (property-style test over a few generated lists).
