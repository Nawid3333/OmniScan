## Why this test exists
Every stage has unit tests, but nothing checks that the whole chain keeps **pages apart and in order**. A codec race once made exported page 3 appear three times; 2 000 CPU tests did not notice. This test runs the real pipeline on 3 known pages and compares the exported result with the exact truth.
It is the safety net for every later change to codec, slicer, detector, OCR, inpainting, typesetting and export.

## The test (all in one module; marker `@pytest.mark.gpu`; skip — never download — when the detector, OCR or LaMa weights are not cached, exactly as `test_lama_stage.py` does)
**Setup** (module-scoped fixture, runs the pipeline ONCE, ~1–2 minutes is fine):
1. `pages = [make_korean_page(seed, n_bubbles=4, n_free=1, n_sfx=0) for seed in (101, 102, 103)]`; write them as `001.jpg … 003.jpg` (quality 92) into `<tmp>/library/E2E/Chapter 1/`. A `Config` whose `paths` point into `tmp_path_factory` (library, work, output, db) but whose models directory/cache is the real one (as in the LaMa test); `gpu.device = "auto"`.
2. A **fake chat client** `DictionaryClient` (implements `ChatClient`): for every request it finds the Korean source text of each region in the user message, picks the closest key of `TRANSLATIONS` by `difflib.SequenceMatcher(None, a, b).ratio()` (OCR may misread a character) and answers in the format that request expects
   (`chat_json` JSON reply for the chat profiles; the plain-text reply for a translategemma-style profile — read `translate/run.py`). `TRANSLATIONS` maps each of the 12 `KOREAN_LINES` to a distinct English sentence of 3–8 words; write the 12 sentences yourself (no two alike; keep "hyung" for 형). It records every call. Ask the judge nothing: all profiles agree, so `final.json` is auto-picked (assert `judge` made 0 requests via its metrics).
3. `result = run_pipeline(cfg, "E2E", ["Chapter 1"], lama=True, client=client, gpu=<scheduler built as cmd_run does>)`.
4. Reassemble the export: concatenate `output/E2E/Chapter 1/NNNN.jpg` (sorted by name) vertically into one array `out` (H×W×3) and the three `page.clean` images into `clean`, the three `page.image` into `raw`, all uint8. Page `i` occupies rows `[i*1400, (i+1)*1400)`. Assert `out.shape == raw.shape` first (a failure here means slicing/export lost or added rows).

**Assertions** (each its own test function so a failure names the broken property; they share the fixture):
1. `test_all_ten_stages_done_then_skipped`: `result.ok`, and every chapter outcome of the first run has status `done` for the ten stages (in `STAGE_ORDER`); a second `run_pipeline` call with the same arguments reports `skipped` for all ten and makes no new client calls.
2. `test_detection_and_ocr_find_the_text`: load `ocr.json`; each truth region (all pages, truth boxes shifted by `i*1400` rows) is matched to the OCR region with the highest IoU if IoU ≥ 0.5. Across the chapter **≥ 80 % of the truth regions are matched**, and for the matched regions
   the mean character error rate between the truth text (`RegionTruth.text` with newlines replaced by spaces) and the OCR text is **≤ 0.10** (copy the small `_levenshtein/_cer` helpers from `test_ocr_pipeline.py`). Print the measured numbers into the report; set the thresholds only after you have measured, with a clear margin (do not tune them to the exact value).
3. `test_translations_follow_the_page_they_came_from`: for every matched region the line in `final.json` equals `TRANSLATIONS[<the truth line whose sentence the region shows>]` — the truth text of page *i*'s region, not of another page. (This is what catches page mixing and region-order bugs in the text path.)
4. `test_pages_stay_apart_and_clean_outside_the_text`: build a boolean `text_zone` over the whole strip = the union of the truth region boxes (shifted per page) grown by 24 px on every side (clip to the image). Outside it, `abs(out - clean)` must have mean **≤ 4.0** and the 99.9th percentile **≤ 60** (JPEG at quality 92 plus slicing seams; measure first, then choose thresholds with margin).
   Sanity mutation to run once and record in the report (do not commit it): swap the row blocks of pages 2 and 3 in `out` → this assertion must fail.
5. `test_english_is_drawn_where_the_korean_was`: for every matched region, look at its truth bbox grown by 6 px: the fraction of pixels with `max(abs(out - clean)) > 60` (text ink) is between **2 % and 60 %**, and the fraction of pixels with `max(abs(out - raw)) > 60` (changed compared to the original Korean) is **≥ 5 %** (the Korean is gone or covered). Choose margins after measuring; record the measured min/max in the report.
6. `test_export_json_matches_the_files`: `export.json` lists exactly the slice files on disk (names and sizes as in `ExportArtifact`), all with non-zero size.
