# B8 — Ollama client (local + cloud, retry/backoff, JSON schema)

**Owner:** GLM builder · **Branch:** `B8` · **Worktree:** `~/projects/omniscan-wt/B8`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Goal
A small, well-tested `httpx`-based client for Ollama's native `/api/chat` and `/api/ps` endpoints, used later by
translation and judge calls. It must pick local vs cloud endpoint, attach the cloud API key, retry transient
failures with backoff, and **fail fast and clearly** on Ollama Cloud's account-wide session-usage rate limit
(HTTP 429) rather than retrying it forever — this project has already lost a run to exactly that failure mode
(a build agent kept working past a 429 for 71 turns before anyone noticed), so this client is the one place that
must never let that happen silently again.

## Interfaces (exact — do not rename or change signatures)
```python
@dataclass(slots=True)
class ChatResponse:
    content: str
    model: str
    done: bool
    total_duration_ns: int | None
    prompt_eval_count: int | None
    eval_count: int | None
    raw: dict[str, Any]   # the full decoded JSON body, for anything callers need that isn't lifted above


@dataclass(slots=True)
class RunningModel:
    name: str
    size_vram: int
    expires_at: str | None


class OllamaError(RuntimeError):
    def __init__(self, message: str, *, status_code: int | None = None, body: str | None = None) -> None: ...
    status_code: int | None
    body: str | None


class OllamaRateLimitError(OllamaError):
    """Raised only when retries are exhausted on an HTTP 429. status_code is always 429."""


class OllamaClient:
    def __init__(
        self,
        cfg: OllamaConfig,
        secrets: Secrets,
        *,
        http: httpx.Client | None = None,
        sleep: Callable[[float], None] = time.sleep,
    ) -> None: ...

    def chat(
        self,
        model: str,
        messages: list[dict[str, Any]],
        *,
        cloud: bool = False,
        format: dict[str, Any] | Literal["json"] | None = None,
        options: dict[str, Any] | None = None,
        keep_alive: str | int | None = None,
        max_retries: int = 5,
    ) -> ChatResponse: ...

    def ps(self, *, cloud: bool = False) -> list[RunningModel]: ...

    def close(self) -> None: ...

    def __enter__(self) -> OllamaClient: ...
    def __exit__(self, *exc: object) -> None: ...
```

## Definitions (no interpretation needed)
1. **Endpoint selection:** `cloud=False` → `cfg.local_url`, no `Authorization` header. `cloud=True` →
   `cfg.cloud_url`, header `Authorization: Bearer <secrets.ollama_api_key.get_secret_value()>`. If `cloud=True`
   and `secrets.ollama_api_key is None`, raise `ValueError("OLLAMA_API_KEY is not set (needed for cloud=True)")`
   **before making any HTTP request** (verify this with a request counter in tests, not just by catching the
   error).
2. **`chat` request body:** `POST {base}/api/chat` with JSON body
   `{"model": model, "messages": messages, "stream": False, **({"format": format} if format is not None else {}),
   **({"options": options} if options is not None else {}), **({"keep_alive": keep_alive} if keep_alive is not
   None else {})}`. Timeout = `cfg.request_timeout_s` on every request (`httpx.Client(timeout=...)` if `http` is
   not supplied). `messages` is passed through byte-for-byte as given — callers embed `images: list[str]`
   (base64) directly in a message dict per Ollama's own format; this client does not touch image encoding.
3. **`chat` response parsing:** the decoded JSON body has `message.content` (→ `ChatResponse.content`),
   `model`, `done`, and optionally `total_duration`, `prompt_eval_count`, `eval_count` (map missing keys to
   `None`, not `0`). `raw` is the full decoded dict.
4. **Retry policy** (applies to `chat` and `ps`):
   - Retryable: `httpx.TransportError` (connection-level failures), HTTP status `429`, HTTP status `>= 500`.
   - Not retryable: any other HTTP status (400, 401, 403, 404, etc.) — raise `OllamaError` immediately after
     exactly one attempt, with `status_code` and `body` (response text, truncated to 2000 chars) set.
   - Backoff between attempts: `delay = min(1.0 * (2 ** attempt), 30.0)` seconds (`attempt` starts at 0 for the
     first retry), plus jitter `random.uniform(0, delay * 0.25)`. If the failing response was a 429 with a
     `Retry-After` header (seconds, integer), use `max(delay, float(header_value))` instead. Call
     `self._sleep(delay)` (the injected `sleep`, not `time.sleep` directly — this is what makes retry tests
     fast).
   - `max_retries` is the **total number of attempts** (so `max_retries=5` means up to 5 HTTP calls, 4 sleeps
     between them). When attempts are exhausted: if the last failure was a 429, raise `OllamaRateLimitError`;
     otherwise raise `OllamaError`. Both carry the last response's `status_code`/`body`.
5. **`ps`:** `GET {base}/api/ps` (same retry policy, `max_retries=5` fixed — no parameter). Parse
   `response.json().get("models", [])` into `RunningModel(name=m["name"], size_vram=m.get("size_vram", 0),
   expires_at=m.get("expires_at"))`.
6. **`close`:** closes the internally-created `httpx.Client` if this instance created one (i.e. `http=None` was
   passed to `__init__`); if a `http.Client` was injected by the caller, `close()` does not close it (the caller
   owns its lifecycle). Safe to call twice.

## Acceptance tests (`tests/unit/test_llm_ollama.py`, using `httpx.MockTransport` — no real network, no new
dependency since it ships inside `httpx`)
1. Happy path: a `MockTransport` handler returns one 200 response with a realistic `/api/chat` JSON body (incl.
   `message.content`, `model`, `done`, `total_duration`, `prompt_eval_count`, `eval_count`); `chat()` returns a
   `ChatResponse` with every field correctly mapped, and `raw` equals the decoded body.
2. `chat(cloud=True)` sends the request to `cfg.cloud_url` (not `local_url`) with header
   `Authorization: Bearer <the test's api key>` present and correct.
3. `chat(cloud=True)` with no `ollama_api_key` in `Secrets` raises `ValueError` and the transport handler is
   never invoked (assert a call counter stayed at 0).
4. Transient failure then success: handler returns 500, then 500, then 200 across 3 calls; `chat()` returns
   successfully; assert exactly 3 calls were made and `sleep` (the injected stub) was called exactly twice with
   positive values.
5. 429 exhausting all retries: handler always returns 429; `chat(max_retries=3)` raises `OllamaRateLimitError`
   with `status_code == 429`; assert exactly 3 calls were made (not more, not fewer).
6. `Retry-After: 7` header on a 429 (with `max_retries=2`, so exactly one retry happens): assert the sleep stub
   was called with a value `>= 7.0`.
7. Non-retryable 404: handler returns 404 with a JSON error body; `chat()` raises `OllamaError` with
   `status_code == 404` after exactly 1 call (0 sleeps).
8. `format={"type": "object", "properties": {...}}` passed to `chat()` appears verbatim in the captured request
   JSON body's `"format"` key (inspect the `httpx.Request` the mock handler received).
9. `keep_alive=0` passed to `chat()` appears as `"keep_alive": 0` in the request body; omitting it means the key
   is absent from the body entirely (not `null`).
10. `ps()` parses a realistic `/api/ps` response (2 models, one with `size_vram=0`) into two `RunningModel`
    entries with the right fields, including a model missing `expires_at` mapping to `None`.
11. `close()` on a client that created its own `httpx.Client` internally actually closes it (assert
    `client.is_closed`); calling `close()` twice does not raise. A client constructed with an injected `http=`
    does not close that instance.
12. `OllamaClient` used as a context manager (`with OllamaClient(...) as c:`) closes on exit.
