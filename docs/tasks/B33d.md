## Part 1 — `acquire/run.py`
```python
@dataclass(frozen=True, slots=True)
class ChapterOutcome:
    name: str
    status: Literal["ok", "review", "failed", "skipped"]
    pages: int
    credits: int                       # credits charged for this chapter (0 for skipped/failed extractions)
    findings: tuple[Finding, ...]
    error: str | None

def acquire_chapters(
    plan: AcquirePlan,
    series_dir: Path,
    extractor: Extractor,
    *,
    client: httpx.Client | None = None,          # passed to download_chapter
    max_credits: int | None = None,
    page_run: bool = True,
    apply_filters: bool = True,
    on_event: Callable[[ChapterOutcome], None] | None = None,   # called once per chapter as soon as its outcome is known (also for skipped ones)
) -> list[ChapterOutcome]: ...
```
Behaviour (exact), for every `PlanItem` of `plan.items` in order:
1. `state == "done"` → `ChapterOutcome(name, "skipped", pages=<read_accepted pages or 0>, credits=0, findings=(), error="already acquired")`.
2. `max_credits` given and `spent + item.credits > max_credits` → this and **every later todo item** become `skipped` with `error="credit budget reached"`; nothing is extracted for them.
3. `extractor.extract(item.source.url, mode=plan.mode)`. `AuthError` or `QuotaError` → record `failed` for the chapter with the message, mark **all later todo items** `skipped` with `error="stopped: <message>"` and stop (the exception is not re-raised; the caller sees the outcomes). Other `ExtractError` → this chapter `failed` (`credits=0`), continue with the next. `DrmPlatformError` → same as `ExtractError` for that chapter (the CLI refuses DRM URLs earlier, this is the safety net).
4. `spent += extraction.credits`. Image URLs = all `extraction.images` URLs; with `page_run` they go through `select_pages(...)` (else all are kept). Write `<chapter_dir>/acquire_selection.json` = `{"page_url": ..., "kept": [urls], "dropped": [{"url","reason"}, ...]}` (indent 2, UTF-8, `ensure_ascii=False`) **before** downloading, so the record exists even if the download fails. No kept URL → `failed`, `error=f"no page images found ({n} image(s) on the page were filtered out)"`.
5. `download_chapter([ImageRef(url, referer=item.source.url) ...], chapter_dir, client=client, apply_filters=apply_filters)`; `AcquireError` → `failed` with its message (partial files stay so a re-run resumes; **no** `accepted.json`).
6. Completeness: `pages, findings = inspect_chapter(chapter_dir)`; `median` = median page count over the `accepted.json` files of the *other* chapters in `series_dir` when at least 3 exist, else `None`; `previous` = the page count of the nearest earlier accepted chapter in reading order (`core.paths.list_chapters` order) or `None`; `findings += check_pages(pages, median_pages=median, previous_pages=previous)`. `verdict(findings)`: `"failed"` → `failed` (no `accepted.json`, `error` = the first error finding's message); `"ok"`/`"review"` → `write_accepted(chapter_dir, status, findings, len(pages), source_url=item.source.url)` and the outcome carries that status.
7. `on_event` is called for every outcome. The function returns all outcomes in plan order. It never raises for per-chapter problems.

## Part 2 — `acquire/cli.py` (typer app `acquire_app`)
Common **source options** (at most one group; error otherwise, exit 2): `--urls FILE` (`-` = stdin; parsed with `read_url_list`), `--link URL` (repeatable; names `Chapter {n}` by position starting at `--first-number`, default 1), `--template URL --first N --last M [--name "Chapter {n}"]` (`template_chapters`); with none of them the series' `sources.toml` (`sources_path(cfg.paths.library_root, series)` + `load_sources`) is used; a missing file → message `no chapter sources: give --urls, --link, --template or create <path>` and exit 2. `ValueError`s from parsing → message on stderr, exit 2.
Common options: `--select SPEC` (`select_chapters`, default all), `--mode basic|advanced` (default `basic`), `--force` (re-acquire chapters already marked done), `--json`.

- **`omniscan acquire plan SERIES …`** — offline. Prints a table (`#`, name, state, credits, url) and `N chapter(s): T to do, D done — estimated credits: C (mode M)`; `--json` prints `to_json(plan)` (plus `"series"`). Also checks `check_allowed` for every selected URL: a DRM platform → message naming it, exit 2 (also for `plan`).
- **`omniscan acquire run SERIES …`** — `[--max-credits N] [--yes] [--no-page-run] [--no-filter]`. Order: parse sources → select → DRM check (refuse the whole run, exit 2) → build the plan → **print `NOTICE` from `acquire.drm`** and the plan table with the credit estimate → nothing to do (`todo == 0`) → say so, exit 0 → confirmation (`--yes`, or `typer.confirm("Spend up to C credit(s)?")`; declined or non-interactive stdin without `--yes` → `aborted`, exit 2) → API key from `get_secrets().extractpics_api_key` (missing → `EXTRACTPICS_API_KEY is not set; put it in ~/.config/omniscan/secrets.env` on stderr, exit 2; **never print the key**) → `make_extractor(api_key)` (a module-level function returning `ExtractPicsClient(api_key)`; tests monkeypatch it) → `acquire_chapters(...)` with `on_event` printing one line per chapter (`✓ Chapter 3: 24 pages` / `? Chapter 4: 9 pages (review: few_pages)` / `✗ Chapter 5: <error>` / `- Chapter 6: skipped (<why>)` — use plain ASCII markers `ok`, `review`, `FAILED`, `skipped` in front instead of the symbols if the console encoding could fail) → summary `ok N, review N, failed N, skipped N — credits used C` → exit 1 when any chapter failed, else 0. `--json` prints only the final JSON (`{"series","mode","outcomes":[{name,status,pages,credits,error,findings:[...]}],"credits_used"}`) on stdout, progress lines go to stderr.
  The `httpx.Client` for the image downloads is created here (`follow_redirects=True`, timeout 30) and closed at the end; the extractor is closed if it has `close()`.
- **`omniscan acquire check SERIES [--json]`** — offline completeness report over the chapter folders already in the library (`list_chapters`): for each chapter `inspect_chapter` + `check_pages(pages, median_pages=<median of the other chapters' image counts if ≥ 3 chapters>, previous_pages=<image count of the previous chapter>)`, then `check_numbering([chapter names])` for the series. Prints per chapter `name: N pages — ok|review|failed` followed by indented findings, then the series findings; `--json`: `{"series", "chapters": [{"name","pages","verdict","findings":[…]}], "series_findings": [...]}`. Exit 1 when any chapter is `failed`, else 0. Unknown series (no folder) → exit 1.

## Acceptance tests (CPU, no network; fakes only)
Helpers: a `FakeExtractor` (records calls; scripted per URL: images list, or an exception), an `httpx.MockTransport` that serves JPEGs generated with Pillow (noise images ≥ 800×1200 so they exceed the 8 000-byte "tiny file" filter), page URLs like `https://cdn.test/c1/001.jpg`.
1. **Happy path** (`run.py`): three chapters, the fake extractor returns for each the 5 page URLs plus `logo.svg`, an icon and a thumbnail → downloads land as `0001.jpg…` in `series_dir/<name>/` in page order, `acquire_selection.json` lists kept and dropped with reasons, `accepted.json` exists with status `ok`, outcomes `ok` with `pages == 5`, `credits == 1` each, `on_event` called 3 times in order, the referer sent for the images is the chapter page URL (inspect the recorded requests).
2. `state == "done"` chapters are `skipped` and never extracted; `force=True` in `build_plan` makes them run again (assert with the fake's call log).
3. **Credit budget**: `max_credits=2` with 4 todo chapters (basic) → two acquired, two `skipped` with `credit budget reached`; advanced mode (2 credits each) with `max_credits=3` → only one chapter runs.
4. **Failures**: `ExtractError` on chapter 2 → `failed` and chapters 1/3 fine; `AuthError` on chapter 2 → chapter 2 `failed`, chapter 3 `skipped` with `stopped: …`; `QuotaError` likewise; a DRM URL smuggled into a plan → `failed` for that chapter only; a page list that filters down to nothing → `failed` with the exact message (counts included); an image 404 → `AcquireError` → `failed`, partial files remain, **no** `accepted.json`; a re-run after fixing the transport completes the chapter without re-downloading the files already there (`download_chapter` resume).
5. **Completeness**: a chapter with 4 pages when three accepted chapters have 20 pages → status `review` with `few_pages`; a chapter of zero valid images → `failed`; the median rule needs ≥ 3 accepted chapters (2 accepted → no `few_pages` finding); `previous` = nearest earlier accepted chapter.
6. **CLI `plan`**: with `--template https://x.test/c/{n} --first 1 --last 5 --select 2-4` → table with 3 rows and `estimated credits: 3`; `--json` parses (`to_json` shape + `series`); `--mode advanced` → 6 credits; `--urls` file with comments and named lines; `--link` twice; two source groups at once → exit 2; nothing given and no `sources.toml` → the exact message, exit 2; a chapter with `accepted.json` is `done` (0 credits); a DRM URL → exit 2 naming the platform.
7. **CLI `run`** (`monkeypatch` `omniscan.acquire.cli.make_extractor` to return the fake, `get_secrets` to return an object with a fake key `SecretStr("test-key")`, the image client to use the mock transport — expose a small module-level factory the test can patch): prints the `NOTICE` and the estimate before running; `--yes` runs; without `--yes` and with `input="n\n"` → `aborted`, exit 2 and the extractor was never called; `input="y\n"` runs; missing key → exit 2, message, no extractor call, and `"test-key"` never appears in stdout/stderr in any test; a failed chapter → exit 1 and the summary line; `--json` output is valid JSON on stdout only; `--max-credits 1` on 3 chapters.
8. **CLI `check`**: a library with chapters of 20, 20, 20, 5 pages (Pillow files; one text file named `.jpg`) and names `Chapter 1, 2, 3, 5` → the 5-page chapter is `review` (`few_pages`), the unreadable file → `failed` for its chapter, the series finding `chapter 4 is missing`, exit codes as specified; `--json` parses; an unknown series → exit 1.
9. `omniscan --help` still lists `acquire`; `omniscan reference` still works as a stub; `tests/unit/test_docs.py` and the whole suite (`-m "not gpu"`) stay green.
