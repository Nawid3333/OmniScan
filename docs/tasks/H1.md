## Part 1 — `hw/detect.py`
```python
Backend = Literal["cuda", "rocm", "mps", "xpu", "cpu"]

@dataclass(frozen=True, slots=True)
class GpuInfo:
    index: int
    name: str
    vendor: Literal["nvidia", "amd", "apple", "intel", "other"]
    backend: Backend               # "cuda" (NVIDIA), "rocm" (AMD via HIP), "mps", "xpu", else "cpu"
    vram_gb: float                 # total memory in GiB (rounded to 0.1); for mps: the unified memory available to the GPU (use total RAM)
    integrated: bool               # heuristic below
    device: str                    # the torch device string to use, e.g. "cuda:1", "mps"

@dataclass(frozen=True, slots=True)
class HardwareInfo:
    os: str                        # "windows" | "linux" | "macos" | other sys.platform
    arch: str                      # "x64" | "arm64" | platform.machine() lower-cased
    cpu_name: str; cpu_cores_physical: int; cpu_cores_logical: int
    ram_gb: float                  # total RAM in GiB, 0.1 precision
    gpus: tuple[GpuInfo, ...]      # torch-visible accelerators, best first (discrete before integrated, then more VRAM first)
    torch_build: Literal["cuda", "rocm", "mps", "cpu"]   # what THIS torch was built for
    best_device: str               # what resolve_device("auto") would pick, "cpu" when no usable GPU
    onnxruntime_providers: tuple[str, ...]   # from onnxruntime if importable (get_available_providers()), else ()
    disk_free_gb: float            # free space where the models live (paths.models_dir; nearest existing parent)

def detect_hardware(models_dir: Path | None = None) -> HardwareInfo
def classify_vendor(name: str) -> Literal["nvidia", "amd", "apple", "intel", "other"]
def is_integrated(name: str, vram_gb: float, vendor: str) -> bool
```
- `classify_vendor`: case-insensitive substring: `nvidia|geforce|rtx|gtx|quadro|tesla` → nvidia; `amd|radeon|instinct` → amd; `apple|m1|m2|m3|m4|m5` → apple (word-boundary for the `m<digit>` forms); `intel|arc|iris|uhd` → intel; else other.
- `is_integrated`: Apple → False (unified memory counts as one GPU); Intel names containing `uhd|iris` → True (Arc is discrete); AMD: True when the name contains `radeon(tm) graphics` or `radeon graphics` or ends with `graphics` **and** `vram_gb <= 4.0`... simplify to: AMD and (`"radeon(tm) graphics"` in the lower-cased name or `"radeon graphics"` in it or `"radeon 8"` followed by `m` pattern `radeon\s*\d{3}m`) → True; otherwise False. NVIDIA → False.
- `detect_hardware` uses `torch` lazily (`import torch` inside; never fail when torch is missing or broken: then `gpus=()`, `torch_build="cpu"`, `best_device="cpu"`). For CUDA/ROCm: iterate `torch.cuda.device_count()`, `torch.cuda.get_device_properties(i)` (`name`, `total_memory`); `torch_build = "rocm"` when `torch.version.hip` is truthy, `"cuda"` when `torch.version.cuda`; each GPU's backend follows `torch_build` (an AMD GPU under a CUDA build is still listed, backend `"cuda"`... no: backend is the torch build's, vendor is by name). MPS: `torch.backends.mps.is_available()` → one `GpuInfo(name="Apple GPU", vendor="apple", backend="mps", vram_gb=ram_gb, integrated=False, device="mps")`. XPU: `hasattr(torch, "xpu") and torch.xpu.is_available()` → list `torch.xpu.device_count()` devices with `get_device_properties(i).name/total_memory`.
  `best_device`: reuse `omniscan.gpu.device.resolve_device("auto")` inside try/except → `str(device)`; on error `"cpu"`.
- CPU: `platform.processor()` or `psutil` info; on Windows use `platform.processor()`, fall back to `platform.machine()`. Cores from `psutil.cpu_count(logical=False/True)` (fallback 1). RAM from `psutil.virtual_memory().total`. Disk: `psutil.disk_usage(<nearest existing parent of models_dir or the home dir>).free`.
- Sorting of `gpus`: not integrated first, then descending `vram_gb`, then index.

## Part 3 — `hw/assess.py`
```python
Level = Literal["ok", "slow", "warn", "incompatible"]

@dataclass(frozen=True, slots=True)
class Compatibility:
    level: Level
    device: str | None             # where it would run: "cuda:1", "mps", "cpu", None when incompatible
    messages: tuple[str, ...]      # human readable reasons (empty for a clean "ok")

def assess(entry: ModelEntry, hw: HardwareInfo) -> Compatibility
```
Rules, evaluated in this order (first match decides `level`, all applicable messages are collected):
1. `format == "cloud"` → `ok`, device `None` → level `ok` with messages from `notes` (if any), never incompatible.
2. Choose the **candidate GPU**: the first GPU (in `hw.gpus` order) that is not integrated **and** whose `backend` is allowed by `entry.backends` (empty = allowed); if there is none but an integrated one is allowed, use it and add the message `"only an integrated GPU (<name>) is available"`.
3. GPU path: candidate exists and (`min_vram_gb is None` or `candidate.vram_gb >= min_vram_gb`) → `ok`, device = `candidate.device`. If the VRAM is too small: message `f"needs {min_vram_gb:g} GB of GPU memory, your {name} has {vram_gb:g} GB"` and fall through to the CPU path.
4. CPU path (reached when no GPU candidate or too little VRAM): if `entry.backends` is non-empty and does not contain `"cpu"`, or `cpu_ok` is false → `incompatible`, device `None`, message `"needs a supported GPU (cuda/rocm/mps); none found"` (or the previous VRAM message kept). Else, if `min_ram_gb` and `hw.ram_gb < min_ram_gb` → `incompatible` with `f"needs {min_ram_gb:g} GB of RAM, you have {ram_gb:g} GB"`. Else the level follows `cpu_speed`: `fast`→`ok`, `ok`→`slow`, `slow`→`warn`... precisely: `fast` → `ok`; `ok` → `slow`; `slow` → `warn`; `unusable` → `incompatible`; device `"cpu"`; message `"runs on the CPU"` plus `" (slow)"` for `slow`/`warn`.
5. Regardless of the path: if `format` is `ollama` the model is served by Ollama: use the same VRAM rule but the device string is `"ollama"`; disk: when `hw.disk_free_gb < size_mb/1024 * 1.2` add `f"needs about {x:.1f} GB of free disk space, {free:g} GB free"` and raise the level to at least `warn`.

## Part 4 — CLI
- `omniscan hardware [--json]`: text: OS/arch, CPU (name, cores), RAM, torch build, best device, then one line per GPU `#0 NVIDIA GeForce RTX 4070  12.0 GB  cuda  device cuda:0` (mark `(integrated)`), onnxruntime providers, free disk at the models folder. `--json`: `dataclasses.asdict` of `HardwareInfo` (tuples as lists), UTF-8, stable key order.
- `models list`: the text table gets a last column `fit` with `ok`/`slow`/`warn`/`incompatible`; below the table, for every model whose level is not `ok` and whose status is not installed, one indented line with its messages. `models list --json`: every model object gets `"compatibility": {"level", "device", "messages"}` and the top level gets `"hardware": <the HardwareInfo dict>`. `models download` prints the messages of a non-`ok` model as a warning line before downloading (`incompatible` → refuse with exit 1 unless `--force` is given; add that flag).
