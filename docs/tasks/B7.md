# B7 — Web debug tool: OCR view

**Owner:** GLM builder · **Branch:** `B7` · **Worktree:** `~/projects/omniscan-wt/B7`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first. Also read the existing viewer from card B5: `src/omniscan/web/app.py`, `webui/src/{api.ts,strip.ts,App.svelte,SlicerView.svelte}`.

## Goal
Add a second view to the B5 web tool that draws every OCR **region** of a chapter on top of the stacked raw pages:
box colour by kind, confidence and reading order as a label, a dashed outline for low-confidence regions, a yellow
marker where the two OCR engines disagree (`ocr_alt` differs from `text`), and a side panel with the full detail of a
clicked region. The OCR stage (card C4) does not exist yet — this card is built against the `RegionsArtifact` schema
that already exists in `core/schemas.py` and a hand-written `ocr.json`, exactly like B5 was built before real data
existed. Read-only, no editing.

## Existing contracts you build on (read, do not modify)
`src/omniscan/core/schemas.py` (the JSON you will receive is exactly `RegionsArtifact.model_dump_json()`):
- `BBox {x0, y0, x1, y1}` (ints, strip space, half-open).
- `OcrLine {bbox, polygon: [[x, y], ...] | null, text, score, engine}`.
- `Region {id, slice_index, kind, bbox, bubble_bbox: BBox | null, polygon: [[x, y], ...] | null, reading_order,
  lang, orientation, lines: OcrLine[], text, confidence, ocr_alt: string | null, text_color: [r, g, b] | null,
  stroke_color: [r, g, b] | null, mask_ref: string | null}` with `kind` one of
  `"bubble_text" | "free_text" | "sfx" | "watermark"`, `lang` one of `"ko" | "zh" | "ja" | "en"`, `orientation`
  `"h" | "v"`.
- `RegionsArtifact {schema_version: number, regions: Region[]}`; on disk as `ocr.json` in the chapter work dir.
- Coordinates are **strip space**. `webui/src/strip.ts` already converts a strip-space y into the stacked-raw-image
  view (`stripYToStackY`); the strip is the raw pages scaled to a common width, so a page with `scale != 1` has its
  strip-space x = natural x * `scale`.

## Part 1 — Backend (`src/omniscan/web/app.py`)
Add exactly one route next to the existing `ingest`/`slices` routes, using the existing `artifact_bytes` helper:
```python
@app.get("/api/series/{series}/chapters/{chapter}/ocr")
def get_ocr(series: str, chapter: str) -> Response:
    """The chapter's ocr.json, byte-for-byte as written by the OCR stage."""
    return artifact_bytes(chapter_paths(series, chapter), "ocr.json")
```
(404 with `{"detail": "ocr.json not found"}` when absent comes for free from `artifact_bytes`.)

## Part 2 — Frontend

`webui/src/api.ts` — add (matching the schema above exactly):
```typescript
export interface BBox { x0: number; y0: number; x1: number; y1: number; }
export type RegionKind = "bubble_text" | "free_text" | "sfx" | "watermark";
export interface OcrLine { bbox: BBox; polygon: [number, number][] | null; text: string; score: number; engine: string; }
export interface Region {
  id: string; slice_index: number; kind: RegionKind; bbox: BBox; bubble_bbox: BBox | null;
  polygon: [number, number][] | null; reading_order: number; lang: "ko" | "zh" | "ja" | "en";
  orientation: "h" | "v"; lines: OcrLine[]; text: string; confidence: number; ocr_alt: string | null;
  text_color: [number, number, number] | null; stroke_color: [number, number, number] | null; mask_ref: string | null;
}
export interface RegionsArtifact { schema_version: number; regions: Region[]; }
export async function getOcr(series: string, chapter: string): Promise<RegionsArtifact>;  // same style as getSlices
```

`webui/src/strip.ts` — add (pure functions, no DOM):
```typescript
export interface StackBox { x: number; y: number; width: number; height: number; }

/** The file that owns strip row `yStrip`: the LAST file whose y0 <= yStrip; the FIRST file if yStrip is above
 * every file's y0. Precondition: files is non-empty. */
export function fileAtStripY(files: SourceFile[], yStrip: number): SourceFile;

/** Map a strip-space box into the stacked raw-image view.
 *   y      = stripYToStackY(files, box.y0)
 *   height = max(0, stripYToStackY(files, box.y1) - y)
 *   file   = fileAtStripY(files, box.y0)
 *   s      = file.scale > 0 ? file.scale : 1
 *   x      = box.x0 / s            (strip x -> that page's natural x)
 *   width  = (box.x1 - box.x0) / s
 * (The x scale of the page that contains the box's TOP edge is used for the whole box.) */
export function stripBoxToStackBox(files: SourceFile[], box: BBox): StackBox;
```
(import `BBox` from `./api` as a type).

`webui/src/ocr.ts` — pure helpers (no DOM, no Svelte):
```typescript
export const LOW_CONFIDENCE = 0.5;
export function kindColor(kind: RegionKind): string;
//   bubble_text -> "#1f6feb" (blue), free_text -> "#d97706" (orange), sfx -> "#9333ea" (purple), watermark -> "#6b7280" (gray)
export function disagrees(region: Region): boolean;      // region.ocr_alt !== null && region.ocr_alt !== region.text
export function isLowConfidence(region: Region, threshold = LOW_CONFIDENCE): boolean;  // region.confidence < threshold
export function filterRegions(regions: Region[], visibleKinds: ReadonlySet<RegionKind>): Region[];  // keeps input order
export function summarize(regions: Region[]): { total: number; lowConfidence: number; disagreements: number };
```

`webui/src/OcrView.svelte` — props `{ series: string; chapter: string }`. Same layout technique as `SlicerView.svelte`
(read it; copy the stacked-`<img>` container + absolutely positioned `<svg>` approach — a small amount of duplicated
layout code is fine, do NOT refactor `SlicerView.svelte`). On mount / prop change fetch `getIngest` and `getOcr`; any
failure (e.g. 404) shows an inline message, for a missing OCR artifact: `no ocr.json yet — run ocr first`.
- Controls above the view: one checkbox per `RegionKind` (all checked by default, labelled with the kind name and
  coloured with `kindColor`), and a one-line summary from `summarize(...)` of the currently visible regions, e.g.
  `12 regions · 2 low-confidence · 1 disagreement`.
- For every visible region, in the SVG overlay: a `<rect>` at `stripBoxToStackBox(files, region.bbox)` with stroke
  `kindColor(region.kind)`, stroke-width 2, fill the same colour at 0.08 opacity; `stroke-dasharray="6 3"` when
  `isLowConfidence(region)`. When `disagrees(region)`: an additional `<rect>` inflated by 3px on every side, stroke
  `#eab308` (yellow), stroke-width 3, no fill. When `region.bubble_bbox` is not null: a thin dotted gray `<rect>`
  (`stroke-dasharray="2 3"`, stroke `#9ca3af`, width 1, no fill) at its mapped box. A `<text>` label just above the box
  reading `` `${region.reading_order} · ${region.confidence.toFixed(2)}` `` (append ` ≠` when it disagrees), font-size 13,
  fill `kindColor(region.kind)`.
- Region rects must receive clicks (`pointer-events: all` on the region `<rect>`s; the `<svg>` itself may stay
  `pointer-events: none`). Clicking a region selects it (its stroke-width becomes 4); clicking the same region again
  or a "clear" button in the panel deselects.
- A side panel (`position: fixed; right: 0; top: 0; width: 320px; height: 100vh; overflow: auto; background: white`)
  shown only while a region is selected: `id`, `kind`, `lang`, `orientation`, `reading_order`, `confidence` (3 decimals),
  `slice_index`, then `text`, then `ocr_alt` (only if not null, labelled `alt`), then one entry per `lines[]`:
  `engine`, `score` (3 decimals), `text`.

## Acceptance tests

**Backend** (append to `tests/unit/test_web_app.py`, reuse that file's existing helpers/fixtures for building a
`Config` and a tmp work tree):
1. `GET /api/series/{s}/chapters/{c}/ocr` with an `ocr.json` written via `RegionsArtifact(...).save(...)` (2 regions)
   → `200` and the body bytes equal the file's own bytes exactly.
2. Same route with no `ocr.json` → `404`.
3. A series or chapter value containing `..` segments on this route → clean `404` (no exception, no file leak) — same
   style as the existing traversal test.

**Frontend** (vitest, pure functions only — no DOM):
4. `stripBoxToStackBox` with one file (`scale=1`, `y0=0`, `y1=1000`, `height=1000`, `width=800`) and box
   `{x0:100,y0:50,x1:300,y1:150}` → `{x:100, y:50, width:200, height:100}`.
5. One file with `scale=0.5` (natural `width=1600`, `height=2000`, strip rows `y0=0..y1=1000`): box
   `{x0:100,y0:100,x1:300,y1:200}` → `x=200`, `width=400`, `y=200`, `height=200` (x divided by scale, y proportional).
6. Two files (each `scale=1`, `height=1000`, strip rows `0..1000` and `1000..2000`): box with `y0=1200`, `y1=1300` →
   `y=1200`, `height=100` (second file sits below the first's 1000px).
7. `fileAtStripY`: returns the last file whose `y0 <= y`; `y` above every file's `y0` (e.g. `-5`) returns the first file.
8. `disagrees`: `ocr_alt=null` → false; `ocr_alt === text` → false; differing → true.
9. `isLowConfidence`: `0.49` → true, `0.5` → false (strict `<`), custom threshold respected.
10. `filterRegions` keeps only visible kinds and preserves input order; an empty set returns `[]`.
11. `kindColor` returns four distinct strings; `summarize` counts total/lowConfidence/disagreements correctly on a
    hand-built list.
