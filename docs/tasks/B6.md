# B6 — Promo filter (file-level + slice-level, perceptual hash)

**Owner:** GLM builder · **Branch:** `B6` · **Worktree:** `~/projects/omniscan-wt/B6`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Goal
Detect scanlator promo/ad pages and mid-strip promo slices by comparing them against example images the user
supplies, using a perceptual hash (no new dependency — implemented on top of Pillow, which is already a
dependency). Matches are never deleted: they are copied into a `_filtered/` folder for review and recorded in
`filter.json`. A restore path lets a human override a decision. This card does not wire itself into a full
pipeline run (there is no end-to-end runner yet) — it is a standalone, fully tested module + CLI command, in the
same spirit as how B4 (slicer) was built decoupled from ingest.

## Interfaces (exact — do not rename or change signatures)
`src/omniscan/filter/hashing.py`:
```python
def dhash(image: Image.Image, hash_size: int = 8) -> int:
    """Difference hash. Convert to grayscale ('L'), resize to (hash_size+1, hash_size) with
    Image.Resampling.LANCZOS, then for each of the hash_size rows compare each of hash_size adjacent
    column pairs (col[x] > col[x+1]) left to right, top to bottom, packing bits MSB-first into an
    int of hash_size*hash_size bits. Deterministic for the same input image."""

def hamming(a: int, b: int) -> int:
    """Popcount of a ^ b (int.bit_count())."""

def similarity(a: int, b: int, bits: int = 64) -> float:
    """1.0 - hamming(a, b) / bits, clamped to [0.0, 1.0]."""
```

`src/omniscan/filter/decide.py`:
```python
@dataclass(frozen=True, slots=True)
class ExampleHash:
    name: str   # relative path, e.g. "global/end_card_1.jpg" or "<series>/promo_2.jpg"
    hash: int


def load_examples(promo_examples_dir: Path, series: str) -> list[ExampleHash]:
    """dhash every *.jpg/*.jpeg/*.png (case-insensitive suffix) directly under
    promo_examples_dir/'global' and promo_examples_dir/series, non-recursively. Skips missing directories
    (returns [] if neither exists). `name` = "<dirname>/<filename>" where dirname is 'global' or the
    series name, using forward slashes always (even on Windows)."""


def best_match(img_hash: int, examples: Sequence[ExampleHash]) -> tuple[ExampleHash, float] | None:
    """Highest-similarity example and its score; None if examples is empty."""


def decide_files(
    paths: ChapterPaths, ingest: IngestArtifact, examples: Sequence[ExampleHash], threshold: float = 0.90
) -> list[FilterDecision]:
    """One FilterDecision(target="file", index=source_file.index, method="phash") per entry in ingest.files,
    in ingest.files order. dhash the raw file at paths.raw_dir / source_file.name. decision="filtered" when
    best_match score >= threshold (matched_example=that example's `name`), else decision="keep"
    (matched_example=None, score=0.0 if examples is empty else the best score found). For every "filtered"
    decision, copy the raw file byte-for-byte (shutil.copy2) into paths.filtered_dir / source_file.name,
    creating paths.filtered_dir if needed. Never deletes or modifies the source file."""


def decide_slices(
    paths: ChapterPaths,
    chapter: str,
    strip: Image.Image,
    slices: SlicesArtifact,
    examples: Sequence[ExampleHash],
    threshold: float = 0.90,
) -> list[FilterDecision]:
    """One FilterDecision(target="slice", index=slice_.index, method="phash") per entry in slices.slices, in
    slices.slices order. Crop strip to the box (0, slice_.y0, strip.width, slice_.y1) and dhash that crop.
    Same threshold rule as decide_files. For every "filtered" decision, save the crop as
    paths.filtered_dir / f"{chapter}_slice_{slice_.index:04d}.jpg" at quality=95, creating paths.filtered_dir
    if needed."""


def effective_decision(artifact: FilterArtifact, target: Literal["file", "slice"], index: int) -> str | None:
    """The decision of the LAST entry in artifact.decisions matching (target, index) in list order
    ("last write wins" — this is how restore overrides an earlier "filtered"); None if no entry matches."""


def restore(paths: ChapterPaths, target: Literal["file", "slice"], index: int) -> FilterDecision:
    """Load filter.json from paths.artifact("filter.json") (raise FileNotFoundError with a clear message if
    absent), append a new FilterDecision(target=target, index=index, decision="restored", score=1.0,
    matched_example=None, method="manual"), save the artifact back (atomic, via FilterArtifact.save), return
    the new decision. Does not touch any file already copied into paths.filtered_dir — restore is a metadata
    override only, per the "never delete" policy."""
```

## Definitions (no interpretation needed)
- `hash_size=8` → a 64-bit hash; `similarity`'s default `bits=64` matches this exactly. Do not use a different
  hash size anywhere else in this card.
- A JPEG re-encode of the same image at a different quality must have `similarity(...) >= 0.95` against the
  original in a round-trip test — this is the near-duplicate tolerance dHash is chosen for.
- `threshold` is a plain function/CLI parameter, not a config field — do not add anything to
  `src/omniscan/core/config.py`.
- `decide_files` / `decide_slices` never raise on missing `promo_examples` directories — an empty `examples`
  list simply means everything is kept.
- Re-running `decide_files`/`decide_slices` (e.g. after re-running the pipeline) is safe to call again; copies
  simply overwrite the same destination path with identical bytes.

## CLI (`src/omniscan/cli.py`)
Replace the `filter` stub with a small Typer sub-app mounted at `app.add_typer(filter_app, name="filter")`:
- `omniscan filter run <series> <chapter> [--threshold 0.90]`: loads `cfg.paths.promo_examples`,
  `ChapterPaths` for the series/chapter, `ingest.json` and `slices.json` via `paths.artifact(...)` +
  `Model.load`. If `ingest.json` is missing, print `f"filter: no ingest.json for {series}/{chapter} — run
  ingest first"` to stderr and exit 2 (same pattern as the other stub commands' `_stub` helper — reuse it or
  match its exit code). Assembles the strip for slice-level hashing by pasting each raw file into a single
  `PIL.Image` canvas in ingest order at its `y0` (simple `Image.new` + `.paste`, CPU-only, no GPU/codec
  dependency — this is only for hashing, not for production compositing). Runs `decide_files` then
  `decide_slices`, concatenates both decision lists, wraps in `FilterArtifact`, saves to
  `paths.artifact("filter.json")`. Prints one line: `f"filter: kept {n_keep}, filtered {n_file} file(s), {n_slice} slice(s)"`.
- `omniscan filter restore <series> <chapter> <file|slice> <index>`: calls `restore(...)`, prints the new
  decision.
Keep both under the existing `no_args_is_help=True` app style; match the existing command docstring style
(one-line, "Not implemented yet." pattern removed only for these two).

## Acceptance tests
`tests/unit/test_filter_hashing.py`:
1. `dhash` is deterministic: same image twice → identical hash.
2. `similarity(dhash(solid_red), dhash(solid_blue)) < 0.5` (very different images hash far apart).
3. `similarity(h, h) == 1.0` for any hash `h`.
4. A JPEG re-saved at a different quality (use `tests/fixtures/images.py`'s `plain_jpeg`, save the same pixel
   buffer twice at quality=95 and quality=60) has `similarity(...) >= 0.95` against itself.

`tests/unit/test_filter_decide.py` (use `tmp_path`; extend `tests/fixtures/images.py` with a small
`solid_color_jpeg`-style helper if useful, or reuse `plain_jpeg`):
5. `load_examples` returns `[]` when neither `global` nor `<series>` subdirectory exists under a tmp dir.
6. `load_examples` finds files in both `global/` and `<series>/`, with `name` in the exact `"global/x.jpg"` /
   `"<series>/y.jpg"` form.
7. `best_match([])` is `None`; on a small example set, picks the closest one and returns the correct score.
8. `decide_files`: 3 synthetic raw files where file index 1 is byte-identical to an example image → decision
   for index 1 is `"filtered"` with `matched_example` set; indices 0 and 2 are `"keep"`. The filtered file is
   copied into `paths.filtered_dir` with identical bytes (compare via hash or direct byte comparison).
9. `decide_files` with an empty `examples` list → every decision is `"keep"`, `paths.filtered_dir` is not
   created.
10. `decide_slices`: build a 3-slice strip image where the middle slice's crop is byte-identical (once
    re-encoded) to an example → only that slice is `"filtered"`; a JPEG crop is written to
    `paths.filtered_dir / f"{chapter}_slice_0001.jpg"` (adjust index to whatever the fixture uses) whose
    decoded pixels match the source crop within JPEG tolerance (mean channel diff <= 3).
11. Threshold boundary: construct two hashes with a known Hamming distance so similarity lands exactly at
    `threshold` → decision is `"filtered"`; one bit further away → `"keep"`.
12. `effective_decision`: given a `FilterArtifact` with `[filtered, restored]` entries for the same
    `(target, index)`, returns `"restored"` (last wins); returns `None` for a `(target, index)` with no
    entries.
13. `restore` on a fresh `filter.json` (written by a prior call in the test) appends a `"restored"` decision
    with `method="manual"` and persists it (reload from disk and confirm).
14. `restore` on a chapter with no `filter.json` raises `FileNotFoundError`.
15. `FilterArtifact` round-trips through `.save()` / `.load()` unchanged.
