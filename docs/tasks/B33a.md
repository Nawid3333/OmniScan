## Scope (read this twice)
This card builds the **source-agnostic plumbing** that a later card (B33b, the `omniscan acquire` command with the extract.pics client) sits on: given a list of image URLs for a chapter, download them in page order, resumably, drop non-chapter images, and refuse platforms that protect their pages with DRM.
It does **not** open web pages, does **not** parse HTML, does **not** know any site, and has **no** site-specific code. The list of image URLs comes from the caller. No network access in tests (`httpx.MockTransport` only).
The library copy of a chapter is the input of the whole pipeline, so the writer must be careful: never leave half-written files, never overwrite a file the manifest does not know about, never write outside `dest`.

## Part 1 — `acquire/drm.py`
```python
NOTICE = "You are responsible for having the right to download and process this content."
DRM_PLATFORMS: dict[str, str]           # host -> display name
class DrmPlatformError(ValueError): ...
def drm_platform(url: str) -> str | None
def check_allowed(url: str) -> None
```
`DRM_PLATFORMS` = `{"comic.naver.com": "Naver Webtoon", "page.kakao.com": "KakaoPage", "webtoon.kakao.com": "Kakao Webtoon", "lezhin.com": "Lezhin", "lezhinus.com": "Lezhin", "ridibooks.com": "Ridibooks", "bomtoon.com": "Bomtoon", "kuaikanmanhua.com": "Kuaikan"}`.
`drm_platform(url)`: host = `urlsplit(url).hostname` lower-cased (None → return None); a leading `www.` is removed; the platform is found when `host == key` or `host.endswith("." + key)`; otherwise None. `check_allowed(url)`: if a platform is found raise `DrmPlatformError(f"{name} protects its pages against extraction; OmniScan does not acquire from paid DRM platforms — import files you own with `omniscan import` instead")`.

## Part 2 — `acquire/filters.py`
```python
NON_PAGE_URL_TOKENS: tuple[str, ...] = ("logo", "banner", "avatar", "icon", "sprite", "emoji", "favicon", "watermark", "thumb", "/ads/", "/ad/", "advert")
def url_looks_like_page(url: str) -> tuple[bool, str]
def image_looks_like_page(width: int, height: int, size_bytes: int) -> tuple[bool, str]
```
- `url_looks_like_page`: scheme other than `http`/`https` → `(False, "not an http(s) url")`; otherwise the lower-cased URL **path** (`urlsplit(url).path`) is searched for the tokens **in tuple order**: first hit → `(False, f"url contains {token!r}")`; else `(True, "")`.
- `image_looks_like_page`, checks in this order, first failure wins: `width < 300` → `(False, "too narrow")`; `height < 100` → `(False, "too short")`; `width / height > 6.0` → `(False, "banner shape")`; `size_bytes < 8000` → `(False, "tiny file")`; else `(True, "")`.

## Part 3 — `acquire/sources.py`
```python
@dataclass(frozen=True, slots=True)
class ChapterSource:
    name: str
    url: str
def sources_path(library_root: Path, series: str) -> Path        # library_root / series / "sources.toml"
def load_sources(path: Path) -> list[ChapterSource]
```
`sources.toml` format (parse with `tomllib`):
```toml
[[chapter]]
name = "Chapter 1"
url = "https://example.org/a/1"

[template]
url = "https://example.org/a/{n}"    # str.format(n=n): "{n}" or "{n:03d}"
first = 2
last = 4
name = "Chapter {n}"                 # optional, default "Chapter {n}"
```
`load_sources`: a missing file → `FileNotFoundError`; explicit `[[chapter]]` entries first (file order), then the template chapters `n = first..last` inclusive. Validation, each a `ValueError` with the quoted message: a chapter without `name` → `"chapter #1: missing 'name'"` (1-based index), without `url` → `"chapter #1: missing 'url'"`; template without `url`/`first`/`last` → `"template: missing 'first'"` etc.; `first > last` → `"template: first (5) is greater than last (3)"`; more than 1000 template chapters → `"template: more than 1000 chapters"`;
url not starting with `http://` or `https://` → `"chapter #2: url must be http(s)"` (template: `"template: url must be http(s)"`); an unsafe name — empty after `.strip()`, containing `/` or `\`, or equal to `.` or `..` → `f"unsafe chapter name {name!r}"`; a duplicate name → `f"duplicate chapter name {name!r}"`. An empty file gives `[]`. Unknown keys and tables are ignored. Invalid TOML propagates `tomllib.TOMLDecodeError`.

## Part 4 — `acquire/download.py`
```python
USER_AGENT: str                          # a fixed browser-like string constant
SUPPORTED_FORMATS = {"JPEG": ".jpg", "PNG": ".png", "WEBP": ".webp"}
MAX_IMAGE_BYTES = 50 * 1024 * 1024
class AcquireError(RuntimeError): ...

@dataclass(frozen=True, slots=True)
class ImageRef:
    url: str
    referer: str | None = None

@dataclass(frozen=True, slots=True)
class DownloadResult:
    files: list[str]                     # file names written or already present, in position order
    downloaded: int
    skipped: int                         # already present per the manifest
    rejected: int                        # filtered out (URL or content), not saved

def download_chapter(refs: Sequence[ImageRef], dest: Path, *, client: httpx.Client | None = None, concurrency: int = 4,
                     retries: int = 3, backoff_s: float = 0.5, sleep: Callable[[float], None] = time.sleep,
                     apply_filters: bool = True, on_progress: Callable[[int, int], None] | None = None) -> DownloadResult
```
Behaviour (exact):
1. `position` of a ref = its 1-based index in `refs` (gaps in the written numbering are allowed). File name = `f"{position:0{w}d}{ext}"` with `w = max(3, len(str(len(refs))))` and `ext` from the **decoded format** (`SUPPORTED_FORMATS`), never from the URL. `dest` is created (parents too). Every file is written to `<name>.part` first and moved with `os.replace`; no `.part` file remains after the call, success or failure.
2. Every ref goes through `check_allowed(url)` first (raises `DrmPlatformError` before anything is requested — the whole call fails, nothing is written). With `apply_filters=True`, refs whose `url_looks_like_page` is false are **rejected without a request** (reason recorded).
3. **Manifest** `dest / "acquire.json"` (UTF-8, `json.dumps(..., indent=2, ensure_ascii=False)`), written atomically at the end of the call, also when the call raises `AcquireError`:
   `{"images": [{"position": 1, "url": "...", "file": "001.jpg", "sha256": "<hex>", "bytes": 1234, "width": 800, "height": 1200}], "rejected": [{"position": 3, "url": "...", "reason": "too narrow"}]}` — both lists sorted by `position`, and they contain the entries of earlier runs that are still valid (see 4) plus the new ones. An unreadable/invalid manifest is treated as empty.
4. **Resume:** a ref whose URL is in the manifest's `images` with the same `position`, and whose file exists with `stat().st_size == bytes`, is skipped (counted in `skipped`, no request). A ref whose URL is in `rejected` with the same position is skipped (counted in `rejected`, no request). Everything else is downloaded. Files in `dest` that the manifest does not know are never touched or deleted.
5. **Request:** GET with headers `User-Agent` and (when set) `Referer`; `follow_redirects` comes from the client you create (`httpx.Client(follow_redirects=True, timeout=30.0)`, closed by you when you created it; a client passed in is left open). Status 200 required. More than `MAX_IMAGE_BYTES` → failure `"too large"`.
   **Retries:** a `httpx.TransportError`, status 429 or status ≥ 500 is retried up to `retries` times (so `retries + 1` attempts): before retry number `k` (0-based) call `sleep(backoff_s * 2**k)`; for 429 with an integer `Retry-After` header call `sleep(min(that, 30))` instead. Any other status (404, 403, ...) fails at once without retry.
6. **Validation:** open the bytes with Pillow (`Image.open(io.BytesIO(data))`, `verify()`, then reopen for size); a decode error or a format not in `SUPPORTED_FORMATS` (GIF, HTML, ...) → failure `f"not a supported image ({format or 'undecodable'})"`. With `apply_filters=True` a decoded image that fails `image_looks_like_page(width, height, len(data))` is **rejected** (not saved, reason recorded).
7. **Failures** never stop the other images: after all refs were processed, if any failed, raise `AcquireError` whose message is `f"{n} of {total} image(s) failed: " + "; ".join(f"#{position} {message}" for ...)` (sorted by position, messages like `"HTTP 404"`, `"too large"`, `"not a supported image (GIF)"`, `"network error: <exception text>"`); the successful files and the manifest are kept, so a re-run continues.
8. Concurrency: a `ThreadPoolExecutor(max_workers=max(1, concurrency))` performs the requests; all file writes, manifest handling and `on_progress(done, total)` calls happen in the calling thread as results arrive (`done` counts finished refs including skipped and rejected ones; the last call is `(total, total)`). The result and the manifest must not depend on `concurrency`.
9. Returns `DownloadResult(files, downloaded, skipped, rejected)`; `files` lists the names of images present after the call (new and skipped) in position order.

## Acceptance tests (CPU, no network; `httpx.MockTransport`; test images made with Pillow from seeded numpy noise so JPEGs are > 8 kB; pass `sleep=recorder` so tests are instant)
1. **drm**: each platform in the table (also with `www.`, an uppercase host, a sub-domain such as `m.page.kakao.com`, a port) is recognised; `example.org`, `notlezhin.com` and `lezhin.com.evil.org` are not; `check_allowed` raises `DrmPlatformError` whose message contains the platform name and `omniscan import`; `NOTICE` is the exact string above; a URL without a host gives `None`.
2. **filters**: every rule with its boundary — `(300, 1000, 50000)` ok, `(299, 1000, 50000)` "too narrow", `(800, 100, 50000)` ok, `(800, 99, 50000)` "too short", `(600, 100, 50000)` ok (ratio exactly 6.0), `(601, 100, 50000)` "banner shape", `(728, 90, 50000)` "too short" (first failing check wins), `(800, 1200, 8000)` ok, `(800, 1200, 7999)` "tiny file"; URLs: `https://cdn.example.org/ch1/001.jpg` ok, `.../ch1/Logo.png` → contains `'logo'`, `.../thumbs/1.jpg` → `'thumb'`, `.../ads/x.jpg` → `'/ads/'`, a token only in the **query string** is ignored, `ftp://x/1.jpg` → "not an http(s) url"; the first matching token in tuple order is reported when several match.
3. **sources**: explicit chapters + template in the documented order; `{n:03d}` formatting; default template name; every error message listed above (one test each, `pytest.raises(ValueError, match=...)`); empty file; missing file; unknown keys ignored; the 1000-chapter cap (1000 ok, 1001 fails).
4. **download — happy path**: 5 refs (JPEG, PNG-bytes behind a `.jpg` URL, WEBP, ...) → files `001.jpg`, `002.png`, ... in position order with the extension from the content, manifest with exact fields and correct `sha256`/`bytes`/`width`/`height`, no `.part` files, `DownloadResult` counts; `on_progress` reaches `(5, 5)` and is monotonic; the same result with `concurrency=1` and `concurrency=4` (compare the manifest text).
5. **referer/user agent**: the handler asserts the `Referer` header equals the ref's referer and the `User-Agent` equals `USER_AGENT`; a ref without referer sends none.
6. **retries**: 500, 500, then 200 → success and `sleep` called with `[0.5, 1.0]`; 429 with `Retry-After: 2` → `sleep(2)`; `Retry-After: 999` → `sleep(30)`; a `httpx.ConnectError` then 200 → success; 404 → exactly one request and `AcquireError` mentioning `#<position> HTTP 404`; retries exhausted (always 500) → `retries + 1` requests then `AcquireError`; with one failing ref among three, the two good files and the manifest exist afterwards and `.part` is gone.
7. **resume**: a second identical call makes zero requests (`skipped == n`); after deleting one file only that ref is requested; after truncating one file (size differs from the manifest) it is re-downloaded; a file that is not in the manifest is untouched; a second run after a failed run downloads only what is missing.
8. **filters in action**: a `.../logo.png` ref is never requested and listed in `rejected` with its reason; a 200×500 image is downloaded, rejected as "too narrow", not written, listed in the manifest and **not requested again** on the next run (numbering keeps its gap: `001`, `003`); `apply_filters=False` keeps both.
9. **invalid content**: an HTML body, a GIF and a truncated JPEG → `AcquireError` with the `not a supported image (...)` message, nothing written for them; an oversized response (`> MAX_IMAGE_BYTES`, patch the constant down in the test) → `"too large"`.
10. **DRM**: a ref on a DRM platform → `DrmPlatformError` before any request (assert the handler was never called) and no `dest` files.
11. Invalid manifest JSON is ignored (everything is downloaded again); `dest` is created when missing (nested).
