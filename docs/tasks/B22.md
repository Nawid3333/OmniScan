# B22 — Packaging: CBZ and PDF from a chapter's output images

**Owner:** GLM builder · **Branch:** `B22` · **Worktree:** `~/projects/omniscan-wt/B22`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Goal
The final English slices end up as JPEGs in `output_root/<Series>/Chapter N/`. Readers want a single file per
chapter. This card adds standalone packaging — a CBZ (zip of the pages plus a `ComicInfo.xml`) and a PDF — and an
`omniscan pack` command. It only reads already-finished JPEG/PNG files; it does not depend on inpainting,
typesetting or the export stage existing yet, so it can be tested on synthetic images today.

`src/omniscan/packaging/names.py`:
```python
def safe_filename(name: str) -> str:
    """Replace every character in <>:"/\\|?* and every ASCII control character (code 0-31) with '_', then strip
    leading/trailing spaces and dots. If the result is empty return '_'. Nothing else is changed (Unicode such as
    Korean is kept as-is)."""
```

`src/omniscan/packaging/cbz.py`:
```python
def pack_cbz(
    images: Sequence[Path],
    dest: Path,
    *,
    title: str | None = None,
    series: str | None = None,
    number: str | None = None,
) -> None:
    """Write a CBZ (a zip file, stored WITHOUT compression: zipfile.ZIP_STORED — JPEGs are already compressed).
    Entries, in this order: every image as f"{i:04d}{path.suffix.lower()}" for i = 1..N in the order given (never
    sorted, never renamed otherwise), then "ComicInfo.xml" last. ComicInfo.xml is built with
    xml.etree.ElementTree and serialised with ET.tostring(root, encoding="utf-8", xml_declaration=True); root tag
    "ComicInfo"; children in exactly this order, each only if applicable: "Title" (if title is not None),
    "Series" (if series is not None), "Number" (if number is not None), "PageCount" (always, text = str(N)),
    "LanguageISO" (always, text = "en").
    Raises ValueError("no images to pack") if images is empty (dest is not created). Creates dest.parent if
    missing. Atomic: write to dest.with_suffix(dest.suffix + ".tmp"), then Path.replace(dest); on ANY exception
    remove the .tmp file (if it exists) and re-raise, leaving no partial dest."""
```

`src/omniscan/packaging/pdf.py`:
```python
def pack_pdf(images: Sequence[Path], dest: Path) -> None:
    """One PDF page per image, in the order given. Open every image with PIL and .convert("RGB") (so RGBA PNGs and
    grayscale JPEGs work), then first.save(tmp, format="PDF", save_all=True, append_images=rest, resolution=100.0).
    Same rules as pack_cbz for: ValueError("no images to pack") on empty input (dest not created), creating
    dest.parent, atomic tmp + replace, and removing the tmp file on any exception. Close every opened image."""
```

`src/omniscan/packaging/__init__.py`: re-export `pack_cbz`, `pack_pdf`, `safe_filename`.

## CLI (`src/omniscan/cli.py`)
Add (register with `app.command("pack")(cmd_pack)`, same style as `cmd_import`; do NOT add to `_STUB_COMMANDS` — the
existing `export` stub stays untouched, it is for the future composite/encode stage):
```python
def cmd_pack(
    series: Annotated[str, typer.Argument()],
    chapter: Annotated[
        list[str] | None,
        typer.Option("--chapter", "-c", help="Chapter folder name; repeatable. Default: all."),
    ] = None,
    fmt: Annotated[
        list[Literal["cbz", "pdf"]] | None,
        typer.Option("--format", "-f", help="cbz or pdf; repeatable. Default: cbz."),
    ] = None,
    out: Annotated[
        Path | None, typer.Option("--out", help="Output folder. Default: <output_root>/<series>/_packaged")
    ] = None,
) -> None:
    """Package finished chapters (output_root/<series>/<chapter>/*.jpg) into CBZ and/or PDF files."""
```
Behaviour: `cfg = get_config()`, `sp = SeriesPaths.from_config(cfg, series)`. Chapters = the `--chapter` values
if given, else `[p.name for p in list_chapters(sp.output_dir)]` (the `_`-prefix rule in `list_chapters` already
skips `_filtered` and `_packaged`). Formats = `fmt or ["cbz"]`, de-duplicated preserving order. Destination folder
= `out` or `sp.output_dir / "_packaged"`. For every chapter: `images = list_images(sp.chapter(chap).output_dir)`;
none → print `f"pack: no images in {series}/{chap}, skipped"` to stderr and continue. Otherwise, for each format
write `dest_dir / (safe_filename(f"{series} - {chap}") + "." + format)`: CBZ via `pack_cbz(images, dest,
title=chap, series=series, number=(f"{n:g}" if (n := chapter_number(chap)) is not None else None))`, PDF via
`pack_pdf(images, dest)`; print `f"pack: {dest}"` per file written. If nothing at all was written → exit code 2
(after printing `f"pack: nothing to pack for series {series!r}"` to stderr); otherwise exit 0.
Import `Literal` and `Path` at the top of `cli.py` only if not already imported there.

## Acceptance tests (`tests/unit/test_packaging.py`, everything under `tmp_path`, synthetic images only)
1. `safe_filename('a<b>c:d"e/f\\g|h?i*j')` → `'a_b_c_d_e_f_g_h_i_j'`; `"  .name. "` → `"name"`; `"..."` → `"_"`;
   `"한국어 - Chapter 1"` is unchanged.
2. `pack_cbz` with 3 JPEGs: `zipfile.ZipFile(dest).namelist() == ["0001.jpg", "0002.jpg", "0003.jpg",
   "ComicInfo.xml"]`; each image entry's bytes equal the source file's bytes; every `ZipInfo.compress_type ==
   zipfile.ZIP_STORED`; `testzip()` is `None`.
3. ComicInfo.xml parses (`ET.fromstring`): with `title="Chapter 1", series="S", number="1"` the child tags in order
   are `["Title", "Series", "Number", "PageCount", "LanguageISO"]`, `PageCount.text == "3"`,
   `LanguageISO.text == "en"`; with no metadata the tags are exactly `["PageCount", "LanguageISO"]`.
4. Input order is preserved (pass `[b.jpg, a.jpg]` → entry 1 has b's bytes) and suffixes are lower-cased (a source
   named `X.JPG` is stored as `0001.jpg`).
5. `pack_cbz([], dest)` raises `ValueError` and `dest` does not exist.
6. If one input path does not exist, `pack_cbz` raises `FileNotFoundError` and neither `dest` nor a `.tmp` file is
   left behind.
7. Packing twice to the same `dest` replaces it without error; no `.tmp` remains.
8. `pack_pdf` with 3 images of different sizes writes a file that starts with `b"%PDF"` and whose byte content
   matches `re.findall(rb"/Type\s*/Page(?![s\w])", data)` exactly 3 times (Pillow writes uncompressed page objects).
9. `pack_pdf` accepts an RGBA PNG (`png_with_alpha`) and a grayscale JPEG (`grayscale_jpeg`) without error.
10. `pack_pdf([], dest)` raises `ValueError`; no dest, no `.tmp`.
11. CLI (`typer.testing.CliRunner`, monkeypatch `omniscan.cli.get_config` to return a `Config` with tmp
    `output_root`): output tree `S/Chapter 1/{1.jpg,2.jpg}`, `S/Chapter 2/{1.jpg}`, `S/_filtered/x.jpg`.
    `pack S` → exit 0 and exactly `S - Chapter 1.cbz` and `S - Chapter 2.cbz` in `S/_packaged`;
    `pack S -f pdf -f cbz -c "Chapter 2"` → `S - Chapter 2.pdf` and `.cbz` written (and nothing for Chapter 1
    created by this invocation); a series with no output folder → exit 2 with the "nothing to pack" message.
12. The `Number` written for `"Chapter 12.5"` is `"12.5"` and for `"Chapter 3"` is `"3"` (via the CLI, read back from
    the CBZ's ComicInfo.xml).
