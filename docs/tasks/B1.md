### `src/omniscan/doctor.py`
```python
from dataclasses import dataclass
from typing import Literal
import httpx
from omniscan.core.config import Config, Secrets

Status = Literal["OK", "WARN", "FAIL"]


@dataclass(frozen=True, slots=True)
class CheckResult:
    name: str
    status: Status
    detail: str


def check_python() -> CheckResult: ...
def check_torch_gpu() -> CheckResult: ...
def check_rocm() -> CheckResult: ...
def check_rocjpeg() -> CheckResult: ...
def check_ollama_local(cfg: Config, http: httpx.Client) -> CheckResult: ...
def check_ollama_models(cfg: Config, http: httpx.Client) -> CheckResult: ...
def check_ollama_cloud(cfg: Config, secrets: Secrets, http: httpx.Client) -> CheckResult: ...
def check_secrets(secrets: Secrets) -> CheckResult: ...
def check_paths(cfg: Config) -> CheckResult: ...
def check_codec(cfg: Config) -> CheckResult: ...


def run_all_checks(cfg: Config, secrets: Secrets, http: httpx.Client | None = None) -> list[CheckResult]:
    """Run every check in the order listed above. If `http` is None, create one httpx.Client(timeout=5.0)
    and close it at the end. A check that raises an unexpected exception becomes FAIL with detail
    f"{type(exc).__name__}: {exc}" — run_all_checks itself never raises."""


REQUIRED_OLLAMA_MODELS: tuple[str, ...] = (
    "translategemma:12b",
    "gemma4:12b",
    "gemma4:31b-cloud",
    "glm-5.3-flash:cloud",
)
```

### `src/omniscan/cli.py`
- `app = typer.Typer(help="OmniScan — manhwa/manga translator", no_args_is_help=True)` (keep the name `app`; it is the
  console-script entry point `omniscan = "omniscan.cli:app"`).
- Global callback options: `--verbose/-v` (sets log level DEBUG) and `--quiet/-q` (sets WARNING); default INFO.
  The callback calls `setup_logging(level)`.
- Commands:
  - `version` — prints `omniscan.__version__` (keep existing behaviour).
  - `doctor [--json]` — runs `run_all_checks(get_config(), get_secrets())`.
    Without `--json`: print a rich table with columns `Check`, `Status`, `Detail` (status coloured: OK green,
    WARN yellow, FAIL red), then a summary line `N ok, N warn, N fail`.
    With `--json`: print exactly one JSON array of objects `{"name","status","detail"}` to stdout, nothing else.
    Exit code: 1 if any result is FAIL, else 0.
  - Stub commands, each taking one optional positional argument `series: str | None = None` and no other options:
    `acquire, ingest, slice, filter, detect, ocr, glossary, translate, judge, inpaint, typeset, export, run, serve, reference`.
    Each stub prints `"<command>: not implemented yet"` to stderr and exits with code 2.
    (Note: `filter` and `slice` shadow Python builtins — name the Python functions `cmd_filter`, `cmd_slice`, etc.
    and register them with `@app.command("filter")` / `@app.command("slice")`.)

## Definitions (exact behaviour of each check)
Every check returns exactly one `CheckResult`. `name` values are exactly: `python`, `torch_gpu`, `rocm`, `rocjpeg`,
`ollama_local`, `ollama_models`, `ollama_cloud`, `secrets`, `paths`, `codec`.

1. **python**: OK if `sys.version_info[:2] == (3, 14)`, detail `"3.14.x"` (full version). Otherwise FAIL.
2. **torch_gpu**: import torch inside the function. FAIL if import fails, or `"rocm" not in torch.__version__`,
   or `torch.cuda.is_available()` is False. Else OK with detail
   `f"{torch.__version__} | {name} | {arch} | {free_gib:.1f}/{total_gib:.1f} GiB free"` where `name` =
   `torch.cuda.get_device_properties(0).name`, `arch` = `getattr(props, "gcnArchName", "?")`,
   free/total from `torch.cuda.mem_get_info(0)` divided by 2**30.
3. **rocm**: run `["rocminfo"]` with `subprocess.run(..., capture_output=True, text=True, timeout=30)`.
   FAIL if the executable is missing (FileNotFoundError) or return code != 0. OK if the output contains `gfx1201`
   (detail `"gfx1201 agent found"`); WARN if it runs but no `gfx1201` line (detail = first `Name: gfx...` found or `"no gfx agent"`).
4. **rocjpeg**: look for the library at `/opt/rocm/core-10.0/lib/librocjpeg.so.1`, then `/opt/rocm/lib/librocjpeg.so.1`,
   then `ctypes.util.find_library("rocjpeg")`. Not found → WARN `"librocjpeg not found"`. Call
   `rocJpegCreate(0, 0, &handle)` (backend 0 = HARDWARE). Status 0 → destroy handle, OK `"hardware decoder available"`.
   Any other status → WARN `f"hardware backend unavailable (status {status}); hybrid codec will be used"`.
   (This is WARN, not FAIL — WSL has no VCN access today.)
5. **ollama_local**: `GET {cfg.ollama.local_url}/api/version`. HTTP 200 with JSON `version` → OK `f"ollama {version}"`.
   Any `httpx.HTTPError` or non-200 → FAIL `f"unreachable at {url}: ..."`.
6. **ollama_models**: `GET {cfg.ollama.local_url}/api/tags` → JSON `{"models": [{"name": ...}, ...]}`.
   Missing names from `REQUIRED_OLLAMA_MODELS` → WARN `f"missing: {', '.join(missing)}"`; none missing → OK
   `f"{len(models)} models, all required present"`. HTTP error → FAIL.
7. **ollama_cloud**: if `secrets.ollama_api_key is None` → WARN
   `"OLLAMA_API_KEY not set (cloud models still work through the local signed-in Ollama)"`, and make NO request.
   Else `GET {cfg.ollama.cloud_url}/api/tags` with header `Authorization: Bearer <key>`: 200 → OK `"cloud API key valid"`,
   401/403 → FAIL `"cloud API key rejected"`, other errors → WARN with the error text. Never print the key.
8. **secrets**: WARN listing missing ones among `EXTRACTPICS_API_KEY`, `OMNISCAN_RELAY_CLIENT_TOKEN`
   (detail `f"not set: {...}"`); OK `"all optional secrets set"` if both present. Never print values.
9. **paths**: for `library_root`, `work_root`, `output_root`: report which exist. OK if all exist; WARN
   `f"will be created on first use: {names}"` if some are missing. Also append free disk space of the nearest existing
   parent of `work_root` via `shutil.disk_usage`: `f"; {free_gib:.0f} GiB free"`. Do not create directories.
10. **codec**: OK with detail `f"configured: {cfg.gpu.codec}"`. (The real codec probe comes in card C2.)
