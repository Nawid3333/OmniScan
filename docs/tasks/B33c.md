## Part 2 — `selection.py`
```python
def read_url_list(text: str, *, first_number: int = 1, name_template: str = "Chapter {n}") -> list[ChapterSource]: ...
def select_chapters(sources: Sequence[ChapterSource], spec: str | None, *, by: Literal["auto", "number", "position"] = "auto") -> list[ChapterSource]: ...
```
**`read_url_list`**: `text` is the content of a file or a pasted list, one chapter per line. Blank lines and lines whose first non-blank character is `#` are ignored; surrounding whitespace is stripped. A line is either `URL` or `NAME | URL` (split on the **first** ` | `, both sides stripped). A line without a name gets `name_template.format(n=first_number + k)` where `k` is the 0-based index of the line among the *non-ignored* lines. Validation and errors come from `named_chapters` (so a bad URL raises `ValueError("chapter #3: url must be http(s)")`); an empty result (no usable lines) → `ValueError("no chapter links found")`.

**`select_chapters`**: picks a subset **in the original order**, without duplicates.
- `spec` is `None`, `""`, whitespace or `"all"` (case-insensitive) → all sources.
- Otherwise `spec` is a comma-separated list of tokens (spaces allowed around them): `N`, `A-B` (inclusive), `A-` (A to the end), `-B` (start to B). `N`, `A`, `B` are non-negative integers.
- **Basis:** `by="number"` compares against the chapter number of each source, `core.paths.chapter_number(source.name)` (float; `5` matches `5.0`, `5.5` is matched only by a range that covers it); `by="position"` compares against the 1-based position in `sources`; `by="auto"` uses `number` when **every** source name has a chapter number, else `position`.
- Errors (`ValueError`, message starts with `selection:`): an empty token (`"1,,3"`), a non-numeric token (`"abc"`, `"1-x"`, `"--3"`), a reversed range (`"5-2"`), and a token that matches **no** chapter (`selection: nothing matches '99'`). A range that matches at least one chapter is fine even if part of it is outside the list (`"10-99"` when only 10–20 exist).

## Part 3 — `completeness.py`
```python
@dataclass(frozen=True, slots=True)
class PageInfo:  name: str; width: int; height: int; size_bytes: int; sha256: str
@dataclass(frozen=True, slots=True)
class Finding:  level: Literal["error", "warn"]; code: str; message: str

def inspect_chapter(chapter_dir: Path) -> tuple[list[PageInfo], list[Finding]]: ...
def check_pages(pages: Sequence[PageInfo], *, median_pages: float | None = None, previous_pages: int | None = None) -> list[Finding]: ...
def check_numbering(names: Sequence[str]) -> list[Finding]: ...
def verdict(findings: Sequence[Finding]) -> Literal["ok", "review", "failed"]: ...
```
- `inspect_chapter`: for every image of `list_images(chapter_dir)` (natural order) read the bytes (size, sha256) and the pixel size with Pillow (`Image.open(...).size`, header only). A file Pillow cannot open → no `PageInfo`, and a finding `Finding("error", "unreadable", f"{name}: cannot be decoded")`. An empty/missing directory → `([], [])` (`check_pages` reports the emptiness).
- `check_pages` findings (return them in this order; each code at most once, except `mixed_widths`/`duplicate_pages` which are one finding per chapter):
  1. `no_pages` (**error**): `pages` is empty → return only this finding.
  2. `few_pages` (warn): `len(pages) < 0.5 * median_pages` (when given) **or** `len(pages) < 0.5 * previous_pages` (when given). Message names the count and the reference: `f"{n} pages; the series median is {median:g}"` / `f"{n} pages; the previous chapter had {previous}"` (if both apply, use the median one).
  3. `many_pages` (warn): `len(pages) > 2 * median_pages` (median only).
  4. `mixed_widths` (warn): let `W` be the most common width (ties → the smaller width); count pages whose width differs from `W` by **more than 5 %** (`abs(w - W) > 0.05 * W`); when the count is ≥ 1 → `f"{k} page(s) differ in width from the usual {W} px"`.
  5. `duplicate_pages` (warn): pages sharing a `sha256`; message `f"{k} page(s) are exact duplicates of another page"` where `k` = number of *extra* copies.
- `check_numbering(names)`: parse `chapter_number(name)` for each name; ignore names without a number and non-integer numbers (`5.5`); on the sorted set of distinct integers `n_min..n_max`, every **missing run** becomes one warn `Finding("warn", "numbering_gap", "chapter 5 is missing")` or `"chapters 5–7 are missing"` (en dash `–` U+2013). No numbers at all or a single number → `[]`.
- `verdict`: any `error` → `"failed"`; else any `warn` → `"review"`; else `"ok"`.

## Part 4 — `plan.py`
```python
ACCEPTED_NAME = "accepted.json"

@dataclass(frozen=True, slots=True)
class PlanItem:  source: ChapterSource; state: Literal["todo", "done"]; credits: int
@dataclass(frozen=True, slots=True)
class AcquirePlan:  items: tuple[PlanItem, ...]; mode: Mode; credits_total: int; todo: int; done: int

def chapter_state(chapter_dir: Path) -> Literal["todo", "done"]: ...
def build_plan(sources: Sequence[ChapterSource], series_dir: Path, *, mode: Mode = "basic", force: bool = False) -> AcquirePlan: ...
def write_accepted(chapter_dir: Path, status: Literal["ok", "review"], findings: Sequence[Finding], pages: int, *, source_url: str) -> None: ...
def read_accepted(chapter_dir: Path) -> dict[str, Any] | None: ...
def to_json(plan: AcquirePlan) -> dict[str, Any]: ...
```
- A chapter is **done** when `<chapter_dir>/accepted.json` exists, parses as JSON and its `"status"` is `"ok"` or `"review"`; anything else (missing, invalid JSON, another status) → `todo`. `chapter_dir` for a source is `series_dir / source.name`.
- `build_plan`: one `PlanItem` per source in the given order; `state = chapter_state(...)` unless `force` (then every item is `todo`); `credits = credit_cost(1, mode)` for `todo`, `0` for `done`; `credits_total = sum`, `todo`/`done` counts.
- `write_accepted` writes `accepted.json` atomically (write `accepted.json.tmp` then `os.replace`) with keys `{"status", "pages", "source_url", "accepted_at" (UTC ISO-8601, seconds), "findings": [{"level","code","message"}, ...]}` (indent 2, UTF-8, `ensure_ascii=False`, trailing newline). `read_accepted` returns the parsed dict or `None` when missing/invalid.
- `to_json(plan)` → `{"mode", "credits_total", "todo", "done", "items": [{"name","url","state","credits"}, ...]}` (this is what the GUI reads).

## Acceptance tests (must exist and pass, CPU only, tmp dirs, synthetic Pillow images)
1. **sources**: `template_chapters("https://x.test/c/{n}", 3, 5)` gives 3 sources named `Chapter 3..5` with URLs `…/c/3..5`; custom `name="Ep {n}"`; the same errors as the `[template]` table (first > last, more than 1000, non-http url, unsafe name); `named_chapters` accepts good pairs, rejects a bad URL, an unsafe or duplicate name with the messages/labels of the existing checks.
2. **read_url_list**: mixed named/unnamed lines with comments and blank lines (numbers continue over the *non-ignored* lines, `first_number=10` → `Chapter 10, 11, …`), `NAME | URL` with extra spaces (`  Ch 1   |   https://x.test/1  ` → name `Ch 1`), the split happens on the **first** ` | ` only (`A | https://x.test/a | b` → name `A`, url `https://x.test/a | b`, because only the scheme is validated), a line that is only a name with no URL (`Chapter 1`) → `ValueError` with the `chapter #N` label, Windows line endings, a bad URL → `ValueError` with the `chapter #N` label, only comments → `ValueError("no chapter links found")`.
3. **select_chapters**: on sources named `Chapter 10 … Chapter 20`: `"all"`, `None`, `""`; `"12"`, `"12-14"`, `"18-"`, `"-11"`, `"11, 13-14 ,20"`, overlapping tokens (`"12-14,13"` → no duplicates, original order), `by="position"` (`"1-3"` → chapters 10–12), `by="auto"` falls back to position when a name has no number (`Prologue` in the list), `"10-99"` ok, `"5-2"`/`"1,,3"`/`"abc"`/`"1-x"`/`"--3"`/`"99"` → `ValueError` starting with `selection:`; a decimal chapter `Chapter 5.5` is matched by `"5-6"` but not by `"5"`.
4. **inspect_chapter**: a folder with 3 valid JPEGs (different sizes) and one text file renamed `.jpg` → 3 `PageInfo` (natural order, correct width/height/size/sha256) + one `unreadable` error; a missing folder and an empty folder → `([], [])`.
5. **check_pages**: `no_pages`; `few_pages` by median (4 pages vs median 10) and by previous (4 vs 10) with the exact messages, median message preferred when both; not triggered at exactly 50 %; `many_pages` (21 vs median 10 → yes, 20 → no); `mixed_widths` (9 pages 800 px + 1 page 900 px → warn "1 page(s) differ in width from the usual 800 px"; 830 px is within 5 % → no warn; tie between two widths picks the smaller as usual); `duplicate_pages` (two identical hashes among 5 → "1 page(s) are exact duplicates…"; three identical → "2 …"); clean chapter → `[]`; order of findings as listed.
6. **check_numbering**: `["Chapter 1","Chapter 2","Chapter 5"]` → one finding `chapters 3–4 are missing`; `["Chapter 1","Chapter 3"]` → `chapter 2 is missing`; two gaps → two findings in ascending order; `["Chapter 1","Chapter 1.5","Chapter 2"]` → `[]`; unnumbered names ignored; unsorted input; a single name and an empty list → `[]`.
7. **verdict**: error beats warn beats ok; empty → `ok`.
8. **plan**: `build_plan` with one chapter dir holding a valid `accepted.json` (`status: "review"`) and one holding invalid JSON and one with status `"failed"` → states `done, todo, todo`; credits 1/0 for basic, 2 for advanced; `force=True` makes all `todo`; totals correct; `write_accepted` then `read_accepted` round-trip (keys, findings, `accepted_at` parseable, file ends with a newline, no `.tmp` left); `read_accepted` of a missing or corrupt file → `None`; `to_json` exact dict for a 2-item plan.
9. `uv run pytest -q -m "not gpu"` stays green (existing acquire tests and `tests/unit/test_docs.py` included).
