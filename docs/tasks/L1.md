## Why
Owner wish: every series in the library gets a cover (and basic metadata) automatically, the user can always choose their own image. Decision (PRODUCT_SPEC §7): use the structured **metadata APIs** — no LLM, no web search, no Tavily. Three free APIs, tried in this order: **AniList** (GraphQL), **MangaDex** (REST, covers as `cover_art` relationships), **Jikan** (MyAnimeList, flaky — it answered `504` while probing, so it is only a fallback and its errors must never abort a search). Real response shapes were measured on 2026-09-20 and are saved as fixtures — the wire format in this card is authoritative:
- `tests/fixtures/metadata_anilist_solo_leveling.json` (real): `{"data": {"Page": {"media": [ {"id": 105398, "title": {"romaji": "Na Honjaman Level Up", "english": "Solo Leveling", "native": "나 혼자만 레벨업"}, "format": "MANGA", "countryOfOrigin": "KR", "startDate": {"year": 2018}, "chapters": 201, "status": "FINISHED", "coverImage": {"extraLarge": "https://s4.anilist.co/…", "large": "…", "color": null}, "siteUrl": "https://anilist.co/manga/105398"}, … ]}}}`. Endpoint `POST https://graphql.anilist.co`, JSON `{"query": <query>, "variables": {"search": <title>}}`, response header `x-ratelimit-limit: 30` (per minute) / `x-ratelimit-remaining`.
- `tests/fixtures/metadata_mangadex_solo_leveling.json` (real, trimmed): `GET https://api.mangadex.org/manga?title=<t>&limit=<n>&includes[]=cover_art&order[relevance]=desc` → `{"data": [ {"id": "<uuid>", "attributes": {"title": {"ko-ro": "…"}, "altTitles": [{"ko": "…"}, {"en": "Solo Leveling"}, …], "originalLanguage": "ko", "year": 2018, "status": "completed"}, "relationships": [ {"id": …, "type": "author"}, …, {"id": "<uuid>", "type": "cover_art", "attributes": {"fileName": "<uuid>.jpg", "volume": "2", "locale": "ko", …}} ]} ]}`. The cover file URL is `https://uploads.mangadex.org/covers/<manga id>/<fileName>.512.jpg` (`.256.jpg` and the bare `<fileName>` also exist); **`HEAD` on that host answers 405 — use `GET`**. MangaDex asks for a descriptive `User-Agent`; keep to ≤ 5 requests per second.
- `tests/fixtures/metadata_jikan_solo_leveling.json` (hand-written from the Jikan v4 docs; the key `_note` says so): `GET https://api.jikan.moe/v4/manga?q=<t>&limit=<n>` → `{"data": [ {"mal_id": 121496, "url": "https://myanimelist.net/manga/…", "images": {"jpg": {"image_url", "small_image_url", "large_image_url"}, "webp": {…}}, "title", "title_english", "title_japanese", "titles": [{"type", "title"}], "type": "Manhwa", "status": "Finished", "published": {"prop": {"from": {"year": 2016}}}} ]}`; limits 3 requests/second, 60/minute.
No API key is needed for any of them. The cover images are copyrighted artwork of the series: the tool only stores them in the user's own library folder for that user's display, records where each came from, and never re-distributes anything.

## Interfaces (exact)
```python
Provider = Literal["anilist", "mangadex", "jikan"]
PROVIDERS: tuple[Provider, ...] = ("anilist", "mangadex", "jikan")

@dataclass(frozen=True, slots=True)
class Candidate:
    provider: Provider
    id: str                                # AniList/MAL id as str, MangaDex uuid
    title: str                             # display title (see below)
    titles: tuple[str, ...]                # every name the provider gave (romaji, english, native, alt titles), de-duplicated, order kept
    year: int | None
    country: str | None                    # "KR" | "JP" | "CN" | None
    status: str | None                     # provider wording, lower-cased
    cover_url: str | None
    url: str | None                        # the series page on the provider's site

@dataclass(frozen=True, slots=True)
class SearchResult:
    candidates: tuple[Candidate, ...]      # provider order (anilist, mangadex, jikan), each provider's own order kept
    errors: dict[str, str]                 # provider -> short error text (a failing provider never raises)

class MetadataClient:
    def __init__(self, *, client: httpx.Client | None = None, sleep: Callable[[float], None] = time.sleep, max_retries: int = 2) -> None: ...
    def search(self, title: str, *, providers: Sequence[Provider] = PROVIDERS, limit: int = 5) -> SearchResult: ...
    def close(self) -> None: ...

def match_score(query: str, candidate: Candidate) -> float: ...
def best_match(query: str, candidates: Sequence[Candidate], *, min_score: float = 0.75) -> tuple[Candidate, float] | None: ...
def download_cover(candidate: Candidate, meta_dir: Path, *, client: httpx.Client | None = None, size: Literal["large", "small"] = "large") -> Path: ...
def set_cover_from_file(meta_dir: Path, source: Path) -> Path: ...
def read_series_meta(meta_dir: Path) -> dict[str, Any] | None: ...
def find_cover(meta_dir: Path) -> Path | None: ...
def meta_dir(library_root: Path, series: str) -> Path: ...        # library_root / series / "_meta"
```

## Definitions (exact)
- **Display title** = the first non-empty of: English title, romanised title, native title (AniList: `english`, `romaji`, `native`; MangaDex: the `en` entry of `title` or of `altTitles`, else the first value of `title`, else the first alt title; Jikan: `title_english`, `title`, `title_japanese`). **`titles`** = all of those plus every `altTitles` value / Jikan `titles[].title`, stripped, empty ones dropped, exact duplicates removed.
- **country**: AniList `countryOfOrigin` as is (`KR`/`JP`/`CN`/`TW`…); MangaDex `originalLanguage`: `ko`→`KR`, `ja`→`JP`, `zh`/`zh-hk`→`CN`, else `None`; Jikan `type`: `Manhwa`→`KR`, `Manga`→`JP`, `Manhua`→`CN`, else `None`. **year**: AniList `startDate.year`, MangaDex `year`, Jikan `published.prop.from.year`.
- **AniList query** (send exactly this text, whitespace as you like): `query ($search: String, $perPage: Int) { Page(perPage: $perPage) { media(search: $search, type: MANGA) { id title { romaji english native } format countryOfOrigin startDate { year } chapters status coverImage { extraLarge large color } siteUrl } } }` with variables `{"search": title, "perPage": limit}`. Cover = `coverImage.extraLarge` (size `"large"`) or `.large` (`"small"`); `url` = `siteUrl`; `status` lower-cased.
- **MangaDex**: params `title`, `limit`, `includes[]=cover_art`, `order[relevance]=desc`; cover: the `cover_art` relationship's `attributes.fileName` → `https://uploads.mangadex.org/covers/{id}/{fileName}.512.jpg` (`"large"`) or `.256.jpg` (`"small"`); no cover relationship → `cover_url=None`; `url` = `https://mangadex.org/title/{id}`.
- **Jikan**: params `q`, `limit`; cover = `images.jpg.large_image_url` or, when null, `images.jpg.image_url`; (`"small"`: `small_image_url` then `image_url`); `url` = the item's `url`; `status` lower-cased.
- **Politeness and errors** (`MetadataClient`): every request carries `User-Agent: OmniScan/<omniscan.__version__> (personal manga library tool)` and `Accept: application/json`; HTTP `429` → wait `Retry-After` seconds (integer, capped at 60, default 5) and retry, `5xx` and `httpx.TransportError` → retry after `0.5 * 2**attempt` s, at most `max_retries` retries; then the provider's error text is stored in `SearchResult.errors[provider]` (`"HTTP 504"`, `"timeout"`, `"unexpected response"`, …) and the provider yields no candidates — **`search` never raises**. A `200` whose body is not the documented shape → `errors[provider] = "unexpected response"`. An empty query (after `strip()`) → `ValueError`.
- **`match_score(query, candidate)`**: normalise with `unicodedata.normalize("NFKC", s).casefold()`, keep only letters and digits (any script), so `"Solo-Leveling!"` == `"solo leveling"`; the score is the **maximum** over `candidate.titles` of `difflib.SequenceMatcher(None, nq, nt).ratio()`, except that an exact normalised equality is `1.0` and a candidate title that *starts with* the query and is at most 1.6× as long as it gets at least `0.85`. Empty normalised query → `0.0`.
- **`best_match`**: the candidate with the highest `match_score`; ties → the earlier provider in `PROVIDERS`, then the earlier position; returns `None` when the best score `< min_score`. (Score the *candidates of all providers together*.)
- **`download_cover(candidate, meta_dir, client=None, size)`**: `cover_url` None → `ValueError("candidate has no cover")`. `GET` (follow redirects, timeout 30, the same User-Agent) with a hard limit of **10 MB** (stream and abort beyond it → `ValueError`), the response must be `2xx` and decodable by Pillow as JPEG/PNG/WEBP (`ValueError` otherwise, nothing written). The file is written to `meta_dir/cover.<jpg|png|webp>` (extension from the decoded format; remove any previous `cover.*` first; write to `.part` then rename), `meta_dir` is created; then `meta_dir/series.json` is written (atomic, UTF-8, indent 2, `ensure_ascii=False`, trailing newline) with `{"provider", "id", "title", "titles", "year", "country", "status", "url", "cover_url", "cover_file": "cover.jpg", "cover_source": "<provider name>", "fetched_at": <UTC ISO seconds>, "credit": "Cover and metadata: <AniList|MangaDex|MyAnimeList (via Jikan)>"}`. Returns the cover path.
- **`set_cover_from_file(meta_dir, source)`**: the file must decode with Pillow as JPEG/PNG/WEBP (else `ValueError`); copy to `meta_dir/cover.<ext>` (same replace rules); update `series.json` (create it if missing) with `"cover_file"`, `"cover_source": "user"`, `"fetched_at"`, keeping other keys; returns the path. **`find_cover`**: the first existing `cover.jpg|png|webp` in `meta_dir` or `None`. **`read_series_meta`**: parsed `series.json` or `None` when missing/invalid.

## CLI (`omniscan library …`)
- `cover SERIES [--title TITLE] [--provider anilist|mangadex|jikan|all] [--pick N] [--file PATH] [--size large|small] [--json]`:
  - `--file PATH` → `set_cover_from_file(meta_dir(cfg.paths.library_root, SERIES), PATH)`; prints `cover set from <file>`; errors → message on stderr, exit 2. (No network.)
  - otherwise search for `--title` (default: the series name) in the chosen providers (default `all`), print the numbered candidate list (`#`, provider, title, year, country, score against the query) and any provider errors (`anilist: HTTP 429` …). `--pick N` (1-based) chooses that candidate; without it the best match (`min_score` 0.75) is chosen automatically; no candidate above the threshold and no `--pick` → print `no confident match — choose one with --pick N` and exit 1 (nothing written). The chosen candidate's cover is downloaded (`download_cover`) and `cover saved: <path> (<provider>)` is printed; a candidate without cover or a failed download → message, exit 1. The series folder does not need to exist (the `_meta` folder is created under the library root).
  - `--json`: one object `{"series", "query", "candidates": [{provider,id,title,year,country,score,cover_url}], "errors": {...}, "chosen": {...}|null, "cover": "<path>"|null}` on stdout.
- `info SERIES [--json]`: prints `series.json` fields (title, provider, year, country, status, credit, cover path) or `no metadata for <SERIES>` (exit 1).
- The HTTP client is created in the command (`follow_redirects=True`) and closed at the end; tests monkeypatch a module-level factory `make_http_client()` in `omniscan.library.cli` (create it) so no test touches the network.
