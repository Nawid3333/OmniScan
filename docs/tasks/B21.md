# B21 — Local import (folders/loose files → library layout)

**Owner:** GLM builder · **Branch:** `B21` · **Worktree:** `~/projects/omniscan-wt/B21`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Goal
The second acquisition path, for raws the user already has on disk instead of pulling them over the network:
`omniscan import <path>` figures out how a folder is organised (one chapter, a folder-of-chapter-folders, or a
loose flat dump of images) and copies the files into `library_root/<Series>/Chapter N/` — the exact layout every
other stage already expects (`core/paths.py`). This card **only places raw files**; it does not run JPEG
normalisation itself — that is the already-built `ingest` stage's job the next time the pipeline touches that
chapter (`raw_dir` is read-only to every stage except acquisition, per `docs/ARCHITECTURE.md`, and `import` is
an acquisition path).

## Interfaces (exact — do not rename or change signatures)
`src/omniscan/importer/plan.py`:
```python
class ImportPlanError(RuntimeError):
    """Raised when a source can't be unambiguously planned, or a destination conflict is found at execute time."""


@dataclass(frozen=True, slots=True)
class ImportPlanItem:
    chapter: str  # destination chapter folder name, e.g. "Chapter 12" or "Chapter 12.5"
    files: list[Path]  # absolute source file paths, in destination order


@dataclass(frozen=True, slots=True)
class ImportPlan:
    series: str
    items: list[ImportPlanItem]
    warnings: list[str]  # e.g. "skipped non-image file: notes.txt"


def plan_import(source: Path, *, series: str | None = None, chapter: str | None = None) -> ImportPlan:
    """Read-only inspection of `source`; never touches the filesystem outside of listing it. See Definitions
    for the three supported shapes and their exact rules."""
```

`src/omniscan/importer/execute.py`:
```python
@dataclass(frozen=True, slots=True)
class ImportResult:
    chapters_written: list[str]  # plan.items chapters, in plan order
    files_copied: int
    files_skipped_duplicate: int


def execute_import(plan: ImportPlan, library_root: Path, *, move: bool = False) -> ImportResult:
    """Apply `plan` under `library_root / plan.series / <chapter>`. See Definitions for the copy/move/conflict
    rules. Fail-fast: stops at the first unresolvable conflict and raises ImportPlanError; files already
    written before that point are left in place (not rolled back)."""
```

## Definitions (no interpretation needed)
**`plan_import` — exactly one of these three shapes, decided by inspecting `source`'s immediate children:**
- If `source` does not exist, or has no entries at all → raise `ImportPlanError` naming `source`.
- **Case A — single chapter folder:** every immediate child of `source` is a file (no subdirectories) with a
  suffix in `IMAGE_SUFFIXES` (case-insensitive), sorted via `natural_key`. Non-image files present are skipped
  and recorded in `warnings`, not an error. `series` must be given (raise `ImportPlanError` if `None` — a bare
  folder of images has no series name to infer). `chapter` = the `chapter` parameter if given, else
  `chapter_number(source.name)` formatted as `f"Chapter {n:g}"` if that parses, else raise `ImportPlanError`
  asking for `--chapter`. Produces exactly one `ImportPlanItem`.
- **Case B — folder-of-folders:** every immediate child of `source` that is a directory has
  `chapter_number(child.name) is not None`, **and there are no loose image files directly inside `source`**.
  `chapter` must be `None` (raise `ImportPlanError` if given — it's ambiguous when every subfolder already
  names its own chapter). `series` = the `series` parameter if given, else `source.name`. Reuse
  `list_chapters(source)` for subfolder ordering and `list_images(subdir)` for each subfolder's files (skips
  non-image files the same way `list_images` already does — no separate warning needed here since
  `list_images` silently filters, which matches its existing behaviour elsewhere in the codebase). One
  `ImportPlanItem` per subfolder, `chapter` = the subfolder's own name unchanged (do not reformat it).
- **Case C — flat dump:** every immediate child of `source` is a file (no subdirectories), same as Case A,
  but **not every file's name parses as one shared chapter** — i.e. this case applies when `chapter` is not
  given and `chapter_number(source.name)` doesn't resolve a single chapter for the whole folder, or (more
  commonly) when files clearly belong to different chapters. Detection rule: try `chapter_number(f.name)` on
  every image file in `source`; if **every** file gets a non-`None` value, treat this as a flat dump grouped by
  that per-file value (round-trip through Case A logic isn't used here — this always wins over Case A when
  `chapter`/folder-level chapter is absent and per-file numbers are present). If **any** file's
  `chapter_number(f.name)` is `None` while others aren't, raise `ImportPlanError` listing every filename that
  failed to parse (don't guess a grouping for them). Group files by their parsed number, one `ImportPlanItem`
  per distinct number with `chapter = f"Chapter {n:g}"`, files within a group ordered by `natural_key`, groups
  ordered by the numeric value ascending. `series` must be given (same reasoning as Case A).
- Any child that is a directory **and** loose image files also exist directly in `source` → raise
  `ImportPlanError` describing the conflict (mixed shape, not automatically resolvable).
- `%g` formatting: `12.0` → `"12"`, `12.5` → `"12.5"` (Python's `f"{n:g}"` already does this).

**`execute_import`:**
- For each `ImportPlanItem`, destination dir = `library_root / plan.series / item.chapter`, created if absent.
- For each source file, destination path = `dest_dir / source_file.name`.
  - If the destination doesn't exist: copy it there (`shutil.copy2` preserves mtime; if `move=True` use
    `shutil.move` instead of copy2), increment `files_copied`.
  - If the destination exists and `hash_file(dest) == hash_file(source_file)`: skip it (no-op — this is what
    makes re-running the same import idempotent), increment `files_skipped_duplicate`. With `move=True`, still
    delete the now-redundant source file (it's already present at the destination with identical content).
  - If the destination exists with **different** content: raise `ImportPlanError` naming both paths and
    stating how many files were already written in this call before the conflict. Do not overwrite.
- `ImportResult.chapters_written` = `[item.chapter for item in plan.items]`, always in plan order, regardless
  of how many of that chapter's files were duplicates.

## CLI (`src/omniscan/cli.py`)
Add (not via `_register_stubs`):
```python
def cmd_import(
    source: Annotated[Path, typer.Argument(exists=True, file_okay=False)],
    series: Annotated[str | None, typer.Option("--series")] = None,
    chapter: Annotated[str | None, typer.Option("--chapter")] = None,
    move: Annotated[
        bool, typer.Option("--move", help="Move instead of copy; delete source after import.")
    ] = False,
    dry_run: Annotated[
        bool, typer.Option("--dry-run", help="Print the plan without writing anything.")
    ] = False,
) -> None:
    """Import raw chapter images from a local folder into the library."""
```
registered with `app.command("import")(cmd_import)` (the string name can be `"import"` even though it's a
Python keyword — only the function name `cmd_import` needs to be a valid identifier). On `ImportPlanError`,
print `f"import: {exc}"` to stderr and exit 2. On success, print each chapter written and the final
`files_copied` / `files_skipped_duplicate` counts; `--dry-run` prints the plan (series, each chapter and its
file count) and exits 0 without calling `execute_import`. `library_root` comes from `get_config().paths`.

## Acceptance tests
`tests/unit/test_importer_plan.py` (build folder trees under `tmp_path`):
1. Case A: a folder with 5 plain images (unordered filenames like `"3.jpg", "1.jpg", "10.jpg", ...`) → one
   `ImportPlanItem` with `files` in natural order (`1.jpg, 3.jpg, 10.jpg, ...`).
2. Case A with `chapter=None` and a source folder name that doesn't parse (e.g. `"raws"`) → raises
   `ImportPlanError`.
3. Case A with `series=None` → raises `ImportPlanError` even when `chapter` is derivable.
4. Case A skips a non-image file (e.g. `"readme.txt"`) and records a warning; it is not in `files`.
5. Case B: subfolders `"Chapter 1"`, `"Chapter 2"`, `"Chapter 10"` (each with 2 images) → 3 items in the order
   1, 2, 10 (not lexicographic), `series` defaults to the source folder's own name when not passed.
6. Case B with `chapter` given → raises `ImportPlanError`.
7. Case C: files `"S_Ch1_01.jpg", "S_Ch1_02.jpg", "S_Ch2_01.jpg"` with no `chapter`/`series`-implying folder
   name → 2 items, `"Chapter 1"` (2 files) and `"Chapter 2"` (1 file), correctly grouped and ordered.
8. Case C where one filename doesn't parse a chapter number → raises `ImportPlanError` whose message includes
   that exact filename.
9. Mixed shape (a subfolder *and* a loose image both directly in `source`) → raises `ImportPlanError`.
10. Nonexistent source path → raises `ImportPlanError`.
11. Empty source folder (exists, no children) → raises `ImportPlanError`.

`tests/unit/test_importer_execute.py`:
12. Executing a Case-A-style plan copies every file into `library_root/<series>/<chapter>/`, byte-identical
    (verify via `hash_file`), and the original source files still exist (`move=False`).
13. `move=True`: after execution, source files no longer exist and destination files do, with matching hashes.
14. Executing the same plan twice: the second run has `files_copied == 0` and
    `files_skipped_duplicate == len(files)`; the destination directory's file set is unchanged (no
    `file (1).jpg`-style renames).
15. A destination file pre-seeded with **different** content than the source than raises `ImportPlanError`
    naming both the source and destination paths.
16. `ImportResult.chapters_written` lists every chapter in `plan.items` order even when all of that chapter's
    files were skipped as duplicates.
