# B24 — Wire `ingest` and `slice` into resumable stages + CLI

**Owner:** GLM builder · **Branch:** `B24` · **Worktree:** `~/projects/omniscan-wt/B24`
Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first (especially "Stages" and "JPEG codec").

## Goal
`ingest_chapter` (B3), the JPEG codec (B2) and `slice_strip` (B4) all exist but nothing connects them, and
`omniscan ingest` / `omniscan slice` are still stubs. This card adds the two `Stage` classes that
`core/stage.py`'s runner expects, the strip-building glue between them (decode every page straight into one
preallocated strip tensor, resizing off-width pages), a small codec factory, and the two CLI commands. After
this card `omniscan slice <Series>` produces real `ingest.json` + `slices.json` per chapter (resumable — a second
run is a no-op), which the B5 web viewer can display.

`src/omniscan/ingest/strip.py`:
```python
def jpeg_paths(ingest: IngestArtifact, raw_dir: Path, cache_dir: Path) -> list[Path]:
    """The JPEG file to decode for every entry of ingest.files, in order: raw_dir / file.name when
    file.converted_from is None, else cache_dir / f"{file.index:04d}_{Path(file.name).stem}.jpg"."""


def build_strip(ingest: IngestArtifact, paths: Sequence[Path], codec: JpegCodec) -> torch.Tensor:
    """Allocate torch.empty((3, ingest.strip_height, ingest.strip_width), dtype=torch.uint8, device=codec.device)
    and fill it: every file with file.width == ingest.strip_width is decoded in ONE codec.decode_into call
    (bytes read with Path.read_bytes, y_offsets = each such file's y0); every other file is decoded with
    codec.decode(data) and resized to (file.y1 - file.y0, ingest.strip_width) with
    torch.nn.functional.interpolate(x.unsqueeze(0).float(), size=(h, w), mode="bilinear", antialias=True,
    align_corners=False), then .round().clamp(0, 255).to(torch.uint8).squeeze(0), and written into
    strip[:, file.y0:file.y1, :]. len(paths) must equal len(ingest.files) (ValueError otherwise). Returns the
    strip; performs no disk writes."""
```

`src/omniscan/slicer/stage.py`:
```python
class SliceStage:
    name = "slice"
    version = 1
    gpu_group = None  # no models; the strip is decoded on cfg.gpu.device by the codec
    # inputs(ctx)       -> [ctx.paths.artifact("ingest.json")]
    # outputs(ctx)      -> ["slices.json"]
    # config_subset(cfg)-> cfg.slicer.model_dump()
    # run(ctx, models)  -> 1. load IngestArtifact from ctx.paths.artifact("ingest.json") (raise
    #                         FileNotFoundError("ingest.json missing — run the ingest stage first") if absent)
    #                      2. codec = get_codec(ctx.cfg); strip = ctx.lazy("strip", lambda: build_strip(
    #                         ingest, jpeg_paths(ingest, ctx.paths.raw_dir, ctx.paths.work_dir / "converted"),
    #                         codec)); then close the codec in a finally block (call its close() if it has one)
    #                      3. slices = slice_strip(strip, ctx.cfg.slicer, ingest.files); save to
    #                         ctx.paths.artifact("slices.json")
    #                      4. return {"slices": n, "blank": n_blank, "forced": n_forced_cut, "bands":
    #                         n_bands, "strip_height": H} (all values float(...)).
    # The strip stays in ctx's memo (via ctx.lazy) so later stages can reuse it; the runner clears the memo.
```
Both classes are plain classes with these class attributes and methods (they satisfy `core.stage.Stage`; add
type annotations `ClassVar[...]` exactly like the Protocol does so pyright sees them as conforming).

## CLI (`src/omniscan/cli.py`)
Replace the two stubs with (register with `app.command("ingest")(cmd_ingest)` / `app.command("slice")(cmd_slice)`
in the same style as the other real commands, and delete both names from `_STUB_COMMANDS`):
```python
def cmd_ingest(
    series: Annotated[str, typer.Argument()],
    chapter: Annotated[list[str] | None, typer.Option("--chapter", "-c", help="Chapter folder name; repeatable. Default: all.")] = None,
    force: Annotated[bool, typer.Option("--force", help="Re-run even if up to date.")] = False,
) -> None:
    """Normalise raw chapter images to JPEG and record the strip layout (ingest.json)."""

def cmd_slice(...same three parameters...) -> None:
    """Cut chapter strips into slices (slices.json). Runs ingest first if needed."""
```
Both: `cfg = get_config()`; if the series has no chapters (`SeriesPaths.from_config(cfg, series).chapters()` is
empty and no `--chapter` was given) → print `f"{name}: no chapters found for series {series!r}"` to stderr, exit
2. Otherwise `results = run_series(stages, cfg, series, chapter, force=force)` where `stages` is
`[IngestStage()]` for `ingest` and `[IngestStage(), SliceStage()]` for `slice`. For every chapter and stage
outcome print one line `f"{series}/{chap} {outcome.stage}: {outcome.status} ({outcome.seconds:.2f}s)"`, and for
a failed outcome an extra indented line with `outcome.error`. Exit code 1 if any outcome failed, else 0.
`get_config` is already imported in `cli.py`; import the stage classes at the top of the function bodies, not at
module level (keeps `omniscan --help` from importing torch-heavy modules — `cli.py` already imports several
things at module level, so only do this for the new torch-dependent imports: `IngestStage`, `SliceStage`,
`run_series`).

## Definitions (no interpretation needed)
- All new tests run on the CPU: build `Config` objects with `GpuConfig(device="cpu")` and tmp-path
  `PathsConfig(library_root=..., work_root=..., output_root=..., promo_examples=..., models_dir=...)`. Do not mark
  anything `gpu`. (`TurboCodec` already falls back to CPU, but be explicit in tests.)
- Test images are plain solid-colour JPEGs written with `tests/fixtures/images.py`'s `plain_jpeg` (or PIL
  directly) — no real manga. For a page that gets uniform-band cuts, stack solid white bands and noisy "art"
  rows using PIL (random pixel noise via `numpy.random.default_rng(0)` is fine) so `slice_strip` finds real cuts;
  tests only need to assert the slices tile `[0, strip_height)` contiguously and that `blank`/`forced_cut`
  flags are booleans — do not assert exact cut positions (that's B4's territory).
- `SliceStage.config_subset` returns exactly `cfg.slicer.model_dump()` so that changing any slicer setting
  invalidates only the `slice` stage, not `ingest`.
- Idempotency comes entirely from `run_stage`'s manifest logic — do not add your own "skip if file exists" checks.

## Acceptance tests (`tests/unit/test_stages_ingest_slice.py`)
1. `jpeg_paths`: for an `IngestArtifact` whose file 0 has `converted_from=None` and file 1 has
   `converted_from=".png"` (name `"page2.png"`) → `[raw_dir/"page1.jpg", cache_dir/"0001_page2.jpg"]`.
2. `build_strip` on CPU with 3 same-width solid-colour JPEGs (different colours, different heights) →
   shape `[3, sum(heights), W]`, dtype `uint8`, and each file's row-range mean colour is within 3 of its source
   colour.
3. `build_strip` with one file of a different width (e.g. widths `[400, 400, 300]`, strip_width `400` from
   `dominant_width`): the odd file's segment has height `y1 - y0` from `stack_layout`, spans the full strip
   width, and its mean colour is within 3 of the source colour.
4. `build_strip` raises `ValueError` when `len(paths) != len(ingest.files)`.
5. `get_codec`: `cfg.gpu.codec` in `"auto"` and `"turbo"` → a `TurboCodec` with `.device.type == "cpu"` (test
   config uses cpu); `"hybrid"` and `"rocjpeg"` → `CodecUnavailableError`.
6. `IngestStage` via `run_stage` on a synthetic 3-page chapter: outcome `done`, `ingest.json` loads as a valid
   `IngestArtifact` with 3 files and correct `strip_height`; running again → `skipped`; overwriting one raw file
   with different bytes → `done` again (input hash changed); `force=True` → `done`.
7. A chapter containing a PNG page: ingest metrics report `converted == 1`, the converted JPEG exists under
   `work_dir/"converted"` with the documented name, and a subsequent `SliceStage` run decodes it (strip built
   without error).
8. `run_chapter([IngestStage(), SliceStage()], ctx)` on a chapter with noisy art pages separated by white bands:
   both `done`; `slices.json` loads as a valid `SlicesArtifact`; `slices[0].y0 == 0`,
   `slices[-1].y1 == strip_height`, and `slices[i].y1 == slices[i+1].y0` for every adjacent pair; every
   `Slice.source_files` entry is a valid file index.
9. Re-running `run_chapter([IngestStage(), SliceStage()], ...)` → both `skipped`. Changing
   `cfg.slicer.target_height` (build a second `Config` with a different value) → `ingest` `skipped`, `slice`
   `done`.
10. `SliceStage` run on a chapter where `ingest.json` does not exist → outcome `failed` whose `error` mentions
    `ingest.json` (via `run_stage` on `SliceStage` alone).
11. CLI (`typer.testing.CliRunner`, monkeypatching `omniscan.cli.get_config` to return the tmp `Config`):
    `omniscan ingest <series>` → exit 0, output has an `ingest: done` line per chapter, `ingest.json` exists;
    `omniscan slice <series> --chapter "Chapter 1"` → exit 0, both artifacts exist; a second identical
    invocation prints `skipped`; `omniscan slice NoSuchSeries` → exit 2 with the "no chapters found" message.
