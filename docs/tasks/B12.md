## Goal
Add a fourth view, **Reader**, to the web debug tool: it shows a chapter's finished English output images
(`<output_root>/<Series>/<Chapter>/0001.jpg …`, produced later by the export stage) as one continuous vertical strip,
either alone (`final`) or side by side with the raw pages (`raw | final`) with linked scrolling, so a reviewer can read
the result the way a reader would and compare it with the original. The export stage does not exist yet, so this is
built and tested against hand-made images, like B5/B7/B10. Read-only.

## Part 1 — Backend (`src/omniscan/web/app.py`)
1. `GET /api/series/{series}/chapters/{chapter}/output` → JSON `list[str]`: file names (not paths) of
   `list_images(paths.output_dir)`; `[]` if the directory does not exist.
2. `GET /api/series/{series}/chapters/{chapter}/output/{name}` → the image bytes (`FileResponse`,
   `media_type=mimetypes.guess_type(name)[0] or "application/octet-stream"`). `404` when: `name` contains `/`, `\` or
   `..`; the suffix (lower-cased) is not in `IMAGE_SUFFIXES`; the file does not exist; or the resolved file is not
   inside the resolved `output_dir` (a symlink pointing elsewhere must 404).

`webui/src/reader.ts` — pure helpers, exact signatures:
```typescript
export interface ScrollMetrics { scrollTop: number; scrollHeight: number; clientHeight: number; }
export const MIN_COLUMN_WIDTH = 200;
export const MAX_COLUMN_WIDTH = 1600;
export const DEFAULT_COLUMN_WIDTH = 720;
export const COLUMN_GAP = 16;
export type ReaderMode = "final" | "compare";

/** 0 at the top, 1 at the bottom of the scrollable range, clamped to [0, 1];
 *  0 when there is nothing to scroll (scrollHeight <= clientHeight). */
export function scrollRatio(m: ScrollMetrics): number;

/** The scrollTop that puts `target` at `ratio` of its scrollable range: Math.round(ratio * max(0, scrollHeight - clientHeight)).
 *  `ratio` is clamped to [0, 1] first. */
export function scrollTopForRatio(ratio: number, target: Pick<ScrollMetrics, "scrollHeight" | "clientHeight">): number;

/** Non-finite -> DEFAULT_COLUMN_WIDTH; otherwise Math.round then clamp to [MIN_COLUMN_WIDTH, MAX_COLUMN_WIDTH]. */
export function clampColumnWidth(px: number): number;

/** Width of each column for the viewport: "final" -> min(requested, viewportWidth); "compare" ->
 *  min(requested, Math.floor((viewportWidth - COLUMN_GAP) / 2)); the result goes through clampColumnWidth
 *  (so it is never below MIN_COLUMN_WIDTH even on a tiny viewport). `requested` is clamped first. */
export function fitColumnWidth(mode: ReaderMode, requested: number, viewportWidth: number): number;
```

`webui/src/ReaderView.svelte` — props `{ series: string; chapter: string }`. On mount / prop change fetch `listOutput`;
if it fails or is empty show `no output yet — the export stage has not produced images for this chapter` and nothing
else. Controls above the reader: a mode toggle (`final only` / `raw | final`), a width slider (`<input type="range">`
from `MIN_COLUMN_WIDTH` to `MAX_COLUMN_WIDTH`, step 20, default `DEFAULT_COLUMN_WIDTH`, showing the current value in px)
and a one-line summary `{n} output image(s)`. The actual column width is `fitColumnWidth(mode, sliderValue, window.innerWidth)`
(keep `window.innerWidth` in `$state`, updated on `resize`).
- **final only:** one scroll container (`overflow-y: auto; height: calc(100vh - 140px)`), centred, width = the fitted
  width, containing one `<img>` per output name in order (`display: block; width: 100%; height: auto`,
  `src = outputImageUrl(...)`, `alt` = the file name).
- **raw | final:** two such containers side by side (gap `COLUMN_GAP`px). Left = the raw pages: fetch `getIngest` and
  render `pageImageUrl(series, chapter, file.index)` for every file with `filtered === false`, in order. If `getIngest`
  fails, show `raw pages unavailable (no ingest.json) — showing final only` and fall back to the final-only layout.
  Right = the final images. **Linked scrolling:** on the `scroll` event of either container, set the other container's
  `scrollTop` to `scrollTopForRatio(scrollRatio(sourceMetrics), targetMetrics)`; avoid feedback loops (only write when
  the target's current `scrollTop` differs from the computed value by more than 1px, and ignore the resulting echo
  event). Do not use `loading="lazy"` (lazy images change scroll heights while scrolling and break the ratio).
- Images are only read via the two API routes above; no image is ever written or modified.

## Acceptance tests

**Backend** (append to `tests/unit/test_web_app.py`; reuse its helpers; write real tiny JPEG/PNG files with Pillow into
`tmp_path/"out"/SERIES/CHAPTER/`):
1. `output` lists image names in natural order (`1.jpg`, `2.jpg`, `10.jpg`) and ignores a `notes.txt` and a
   sub-directory; `[]` when the output directory is absent; `..` in the series or chapter value → clean 404.
2. `output/{name}` returns the exact file bytes with the right content type (`image/jpeg`, `image/png`).
3. 404 for: a missing file; `name="notes.txt"` although the file exists; `name="..%2F..%2Fsecret.jpg"`; a name with a
   backslash; a symlink `escape.jpg` inside the output dir that points at a real image OUTSIDE the output dir.

**Frontend** (vitest, pure functions only):
4. `scrollRatio`: top → 0, bottom (`scrollTop == scrollHeight - clientHeight`) → 1, middle → 0.5, unscrollable
   (`scrollHeight <= clientHeight`) → 0, `scrollTop` beyond the range → clamped to 1, negative → 0.
5. `scrollTopForRatio`: `(0.5, {scrollHeight: 2000, clientHeight: 1000})` → 500; ratio `1.5` behaves as 1, `-1` as 0;
   unscrollable target → 0; result is an integer (`(0.3333, {scrollHeight: 1001, clientHeight: 0})` → 334).
6. `clampColumnWidth`: `NaN` and `Infinity` → 720; `50` → 200; `5000` → 1600; `333.6` → 334.
7. `fitColumnWidth`: `("final", 720, 500)` → 500; `("final", 720, 2000)` → 720; `("compare", 720, 1000)` → 492;
   `("compare", 720, 300)` → 200 (MIN wins); `("compare", 100, 2000)` → 200 (requested clamped up first).
