# OmniScan

GPU end-to-end manhwa/manga translator (Korean / Chinese / Japanese → English) for AMD ROCm on WSL2.

Pipeline: acquire → ingest → slice → promo filter → detect → OCR → glossary → translation runs → judge → inpaint → typeset → export.

See [docs/PLAN.md](docs/PLAN.md) for the full build plan and [CLAUDE.md](CLAUDE.md) for contributor/agent rules.
