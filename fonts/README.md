# Fonts

Open-source fonts (SIL Open Font License 1.1) used by the tests, the synthetic Korean pages and the typesetter defaults.
Each family's licence text sits next to it as `OFL-<Family>.txt`. Source: <https://github.com/google/fonts> (`ofl/`), fetched 2026-09-19.

| File | Use |
|---|---|
| `NanumGothic-Regular.ttf`, `NanumGothic-Bold.ttf` | Korean text for synthetic test pages (Hangul + Latin) |
| `Gaegu-Regular.ttf` | Korean handwriting style for synthetic pages (harder OCR case) |
| `ComicNeue-Regular.ttf`, `ComicNeue-Bold.ttf` | English dialogue lettering default |
| `PatrickHand-Regular.ttf` | English thought / narration lettering |
| `Bangers-Regular.ttf` | English shout / SFX lettering |

Commercial lettering fonts are supplied by the user and are never committed (question E2 in `docs/OPEN_QUESTIONS.md`).
